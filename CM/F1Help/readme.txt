Introduction
============
 F1Help is the application to generate windows help files,
 HtmlHelp or html documents from any Delphi source file. It
 is handy for component writers that want to document their
 components and source code with an integrated help in the
 Delphi environment and don't want to struggle with several
 different environments to document their sources. F1Help
 is also able to generate HTML documentation so complete
 description of all library functions may be published on
 web sites.

 For a list of changes in this version, see the what's new on
 the homepage.
  http://www.geocities.com/SiliconValley/Vista/5524/


Installation
============
 If you received this version of F1Help in a ZIP file (f1help.zip),
 you can install it as follows:

  You can install F1Help by unzipping the file in a separate directory.
  Before the first generation of a hlp file, please set your
  preferences under File|Options in the Environment tab page.


Upgrade Instructions
====================
 Follow the installation instructions above.  You can install
 this version of F1Help to the same location as a previously
 installed copy of F1Help. You may have to remove your f1help.gid
 file which containt full text search information of the help file.


Requirements
============
 This version requires Windows 95 or Windows NT 3.51 or later
 and the Windows Help Compiler or a web browser.

 NOTE: This application will also run under Windows 3.1 with
       Win32s 1.3 or later.


Documentation
=============
 For full documentation, including context sensitive help,
 select press the F1 key or click Help.
