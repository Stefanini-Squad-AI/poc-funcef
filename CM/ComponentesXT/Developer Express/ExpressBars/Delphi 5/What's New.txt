What's New in the ExpressBars 4.1

A New Visual Display Style: Bring MS Office 10 toolbars style into your application right now - even before MS releases Office 10.  ExpressBars now provides three display styles, available via the TdxBarManager's Style property: the original bmsEnhanced and bmsStandard plus the new bmsFlat. The latter is patterned after MS Office 10 (yet unreleased).

Margin Bar: The TdxBarSubItem type (i.e. that used for generating classical hierarchical menus) now has a BarSize property. This represents the width (default = 0) of the Bar area displayed to the left of the sub-menu.

Greatly Enhanced Docking Control: The docking support from Borland is based at the TForm level, i.e. you can only drop items on one of the four sides of a form. ExpressBars now enhances that functionality by adding docking support to other container controls like frames and panels (i.e. components which include csAcceptsControls within their ControlStyle).

This extended functionality is provided by the new standalone TdxBarDockControl component. This can be dropped on to a container control to provide docking along one of its sides. You can, of course, drop four TdxBarDockControls to provide support for the sides. 

Container Item: Allows you to place any VCL control onto toolbars and menus.

Detachable Submenus: Allow your users to pull off frequently used menus and leave them floating or docked. 

Toolbar Wrapping: Toolbars can now be displayed across multiple rows when docked.

Status Bar: Use all of the power of ExpressBars and turn the traditional concept of a status bar on its ears.

ICQ Style Expanding Submenus: Further control expansion and collapsing of your menus.  Expanding submenus provide a neat alternative to providing a comprehensive menu system without forcing the user to navigate through many hierarchical levels. Instead, the menus are situated in place and the user can collapse/expand as desired. 

All very nice you say, but what's the point? Persistence, that's what! When you return to the menu, the collapsed/expanded state is how you left it. It provides a means of tucking menu items out of sight, thus reducing clutter while keeping all options readily available.

Logical Groups: Set the Enabled and/or Visible properties of a group instead of having to do it for each individual toolbar item.  A Group contains a list of toolbar items and Logical Groups represent a collection of Groups. Any toolbar item managed by a TdxBarManager may be placed in a Group, irrespective of its Category property.

Rather than setting the properties of individual toolbar items, Groups make it possible to set the Enabled and/or Visible properties of a TdxBarGroup instead. 

Other Enhancements

- Design time customization of container items. The TdxBarContainerItem (which holds other toolbar items) now has an ItemLinks property which makes it far easier to use within the IDE.
- Progress Bars. Native progress bar support is provided by the TdxBarProgressItem toolbar item type.
- MRU Lists. Most recently used item support is provided by the new TdxBarMRUListItem toolbar item type.
- Toolbar wrapping is now provided by the new Boolean MultiLine property, which is set False by default. You do have to change its value to benefit, but this prevents nasty surprises when upgrading existing applications. 
- Caption and ShowCaption properties are now available for all toolbar item types.
- MDI-child system menu on main menu. When an MDI-child is maximized and the child menu is merged into the main menu, the latter now displays the system menu icon.
