Depending your needs and Delphi configuration you might want to customize the designtime MULTILIZER package.

Customizing the MULTILIZER Package

Customizing means removing and/or adding unit(s) to the package. Choose File | Open and browse <mldir>\Delphi5\Ml42NDDE50.dpk (e.g. c:\Program Files\Multilizer\Delphi5\Ml42NDDE50.dpk) to open the MULTILIZER package.

  • To remove an item from the package: select the node (e.g. IvOldReg) and press the Del key.
  • To add an item to the package: Press the Add button. The Add dialog box appears. Press the Browse button. Select the unit (e.g. IvChaMod.pas) and press the Open button. Press the OK button to close the Add dialog box.

You can customize the package in the following ways.

  • Previous MULTILIZER versions contained TIvExtendedTranslator, TIvFileDictionary, TIvEmbeddedDictionary, TIvUnicodeDictionary, TIvEmbeddedBinaryDictionary and multilingual common dialog components. The TIvTranslator, TIvTextDictionary, TIvBinaryDictionary and TIvDialogModule components replace these component in the current version. If your application does not use the old components, you can remove IvOldReg and IvDlgReg from the package.
  • If you use TeeChart, add IvChaReg.pas to the package. This installs TIvChartModule.
  • If you use Raize Components II, add IvRzReg.pas to the package. This installs TIvRaizeModule.
  • If you use 1stClass, add Iv1stReg.pas to the package. This installs TIv1stClassModule.
  • If you use InfoPower, add IvIPReg.pas to the package. This installs TIvInfoPowerModule.
  • If you use ExpressTree, add IvExTreeReg.pas adn IvExDBTreeReg.pas to the package. These install TIvExpressTreeModule and TIvExpressDBTreeModule modules..
  • You do not have to use the multilingual components any more to add bidirectional support to your application. The standard VCL components now include support for bidirectional languages. However if you are porting a Delphi 2 or 3 application where you have used the multilingual components, and you do not want the change the multilingual components back to the standard VCL components, you can add the multilingual components as well. Add IvBidReg.dcu (or IvBidReg.pas if you have the source code) to the package.

After you have customized the package remove the old MULTILIZER package from the Component Palette and install the new package:

  1. Choose Component | Install Packages
  2. Choose Multilizer Components and press the Remove button.
  3. In the Package window press the Install button to compile and install the customized package. If you do not have the MULTILIZER source code you have to rebuild the ML42ND50.dpk package first. Otherwise you will get compiler errors.
