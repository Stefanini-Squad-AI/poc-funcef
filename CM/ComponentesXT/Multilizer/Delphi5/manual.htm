Delphi 5 uses packages to add componets to the Component Palette. MULTILIZER contains two desing packages called Ml42NDDE50 and Ml42DBDE50. You have to compile and install it. Follow the instructions below:

Compile and install the MULTILIZER package

  1. Close all project by choosing File | Close All.
  2. Choose File | Open Project. The Open Project dialog box appears.
  3. Browse to the MULTILIZER's Delphi5 subdirectory. (e.g. C:\Program Files\Multilizer\Delphi5)
  4. Change the Files of type combo box to Delphi package (*.dpk). Select Ml42NDDE50.dpk.
  5. Press the Open button to open the package. The Package window appears.
  6. Press the Install button to compile and install the package. Delphi compiles the package before installing it. Close the Package project.
  7. If you have Delphi 5 Professional or Enterprise you can also install the data aware package: Ml42DNDE50.dpk.
  8. Choose Tools | Environment Options. The Environment Options dialog box appears.
  9. Select the Library tab.
  10. Add the path to the Multilizer's Delphi5 subdirectory to the Library Path.
  11. Choose OK to close the Environment Options dialog box.

You have now added MULTILIZER's to the Component Palette. The next step is to merge MULTILIZER's online help to Delphi's online help.

Add MULTILIZER help to Delphi's help system

  1. Choose Help | Cuztomize to open OpenHelp application.
  2. Choose the Contents tab.
  3. Choose Edit | Add Files.
  4. Select <Multilizer>\Delphi5\mld5.cnt.
  5. Choose OK
  6. Choose the Index tab.
  7. Choose Edit | Add Files.
  8. Select <Multilizer>\Delphi5\mld5.hlp.
  9. Choose OK
  10. Choose the Link tab.
  11. Choose Edit | Add Files.
  12. Select <Multilizer>\docs\ivmulti.hlp.
  13. Choose OK
  14. Choose File | Save Project to update Delphi's help file.

MULTILIZER has been fully installed.
