Open a sample application

MULTILIZER contains several sample applications. Let's open and compile one of them.

  1. Start Delphi.
  2. Choose File | Open Project. The Open Project dialog box appears.
  3. Browse to the MULTILIZER's Delphi5\Samples\Dcalc subdirectory. Select dcalc and press the Open button.
  4. Press F9 to compile and run the application.
  5. The Dcalc application appears. If the locale settings of your system is not Finnish, the initial user interface language will be English.
  6. Change the language by choosing File | Language (or Tiedosto | Kieli if you have Finnish active). The Language dialog box appears. It shows all the available language of Dcalc. They are English, English (United States), and Finnsh. Choose any of them and press OK. Dcalc changes the user interface language.

There is no limit how many languages you can include to your application. You can also add sub languages (e.g. US English, and UK English), if the spelling of one sub language differs from the rest.

You have now tried a sample application. The next logical step is to make your own application multilingual. However, before that it is a good idea to take a look at the way MULTILIZER works.
