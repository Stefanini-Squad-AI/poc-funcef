Readme.txt - Release 2 (Aug 29, 2001)

This zip file contains some miscellaneous Delphi modules that I have 
released into the public domain for you to use at your own risk.  Also
included are some demo programs which show how to use some of the units.
The files are as follows:

Dxfgrph.pas - defines a class for reading in and drawing .DXF files
Dxfview.dpr - demo project using dxfgrph.pas
Dxfview.exe - binary version of demo project using dxfgrph.pas
Dxfvmain.pas/dfm - main form for above demo
QSort.pas - unit with simple quick sort procedure like C's qsort
Strlib.pas - unit full of miscellaneous string routines
XMLReader.pas - unit for reading well-formed XML files
XMLWriter.pas - unit for writing well-formed XML files
XMLTest.dpr - project demoing XMLReader & XMLWriter
XMLTest.exe - binary version of project demoing XMLReader & XMLWriter
XMLTestMain.pas/dfm - main form for above demo

In addition, ing. Roberto Gerola (roberto.gerola@speedtech.it) 
contributed modified versions of the XMLReader and XMLWriter units
that do not use method overloading and therefore compile under
Delphi versions 2 & 3:

D23\XMLReader.pas - unit for reading well-formed XML files
D23\XMLWriter.pas - unit for writing well-formed XML files
