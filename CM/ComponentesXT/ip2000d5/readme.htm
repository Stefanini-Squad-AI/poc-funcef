Installing the InfoPower help file into Delphi 5 or Builder 5– The install program will automatically install the InfoPower online help file into Delphi 4 or Builder 4.  However, if you are using Delphi 5 or Builder 5, you will need to run the OpenHelp utility by clicking on Help | Customize from the Delphi 5 IDE.  From there, click on Edit | Add Files to add the ip50d5.hlp (Delphi 5) or ip50c5.hlp (C++ Builder 5) file to the list of help files in the index and link tab pages. Do not add ip50d5.hlp or ip50c5.hlp to the contents tab page. After adding the ip50d5.hlp or ip50c5.hlp file, click on File | Save Project to save your changes.

 

Warning – Delphi 5’s default help indexing is near the limits of Microsoft’s WinHelp.  As a result, you may need to remove any indexes you do not regularly use do stay within the capabilities of WinHelp.  If you experience an empty list on the Index tab page of WinHelp, this indicates you need to remove some .hlp files using OpenHelp.

 

Demo Applications

For an overview of the IP functionality, we suggest you compile the main demonstration program for InfoPower 2000. This demo is located at \ip2000\demos\maindemo\prjdemo.dpr.

 

Note to Delphi 5 users who are using the InfoPower 2000 TwwDBRichEditMSWord component:

Borland has issued Delphi 5 update pack 1. If you install Delphi 5 update pack 1, you will need to recompile your project afterwards. In addition, if you install the office 2000 automation package (Dcloffice2k50.bpl) you should use the IP50WORD2000_D5 design-time package, instead of IP50WORD_D5. You will also need change your uses clause in your Pascal source so that it references wwrichedspell2000 instead of wwrichedspell .

 

We also recommend omitting IP50WORD_D5 and IP50WORD2000_D5 from your list of runtime packages for your project, as this removes the requirement to distribute both the corresponding ip50word package as well as the office automation package. Omitting the IP50WORD_D5 runtime package from your project will add about 10K to your executable size.

 

C++ Builder 5 notes: The TwwDBRichEditMSWord component is not supported in C++ Builder 4 or C++ Builder 5.
