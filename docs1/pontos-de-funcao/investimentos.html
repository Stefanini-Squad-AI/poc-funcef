3. Inventário de Processos Elementares (PE)

Processos elementares identificados a partir do menu principal (INVESTIMENTOS/FontesProducao/FPrincipal.dfm / FPrincipal.pas — 318 handlers OnClick) e dos relatórios. Os 199 PE distribuem-se em 22 áreas funcionais: PE-001–PE-018 são renda fixa (rf); PE-019–PE-040 são renda variável (rv / ações / bolsa); PE-041–PE-050 são direitos (rv); PE-051–PE-055 são empréstimo de ações; PE-056–PE-073 são fundos de investimento (fdo); PE-074–PE-078 são fundos — direito creditório (fdc); PE-079–PE-083 são fundos — imobiliário / estruturado / ações (fac/fif); PE-084–PE-093 são bm&f (bolsa de mercadorias & futuros); PE-094–PE-100 são opções de índice; PE-101–PE-107 são custódia; PE-108–PE-112 são boletas (transversal); PE-113–PE-116 são provisão; PE-117–PE-123 são emissores / setor / origem capital; PE-124–PE-132 são carteira / gestores / custodiantes / corretoras / bolsas; PE-133–PE-137 são parâmetros / configuração do sistema; PE-138–PE-144 são ordens de movimentação; PE-145–PE-151 são fechamentos (transversal); PE-152–PE-169 são consultas / relatórios / mapas; PE-170–PE-179 são importações / exportações; PE-180–PE-186 são integração contábil; PE-187–PE-192 são impostos (cpmf / ir / iof); PE-193–PE-199 são gerencial / caixa / cota / operações virtuais. Cada PE é a menor unidade de atividade funcional significativa para o usuário — sem subclassificação em entradas, saídas ou consultas e sem nível de complexidade.
