PF-01 — Preparo da Folha

Objetivo: selecionar patrocinadoras/planos/benefícios e aplicar reajustes/eventos antes da prévia.

Gatilho: usuário aciona o botão Preparo em FPreparo.dfm.

Pré-condições: lote aberto; patrocinadoras/planos cadastrados; benefícios ativos.

Entradas: tipo de folha, lote, patrocinadoras, planos, benefícios, mês/ano.

Passo-a-passo:

  1. MontaListaPatro → MontaListaPlano → MontaListaBenef (FPreparo.pas:1030/1042/1075)
  2. InicializaProcessoBeneficio (:1755) → InicializaContadores (:1812)
  3. Loop: PassoProcessoBeneficio (:1901) → ExecutaRegraProcessoBeneficio (:1943) → IncrementaTotais (:1837)
  4. GravaHstBeneficio (:2375) → InsereHstBfciario (:1383) → GravaProcessoBeneficio (:2678)
  5. CalculaProRata (:2931) → CalculaEnviaContribuicaoPensionista (:2958)

Validações: tipo de folha selecionado; listas não vazias. Regras: FOLHA-RN010 (duplicidade de lotes). Saídas: HSTBENEFBFCIARIO, PROCESSOBENEF, HSTCONTRIBPREV. Resultado: benefícios preparados para prévia. Evidência: FOLHA/Fontes/FPreparo.pas:1015-2958 · COMPROVADO

[FPreparo] --> MontaListas --> InicializaProcessoBeneficio --> loop(PassoProcessoBeneficio --> ExecutaRegra --> GravaHstBeneficio) --> CalculaProRata --> CalculaEnviaContribuicaoPensionista --> [HSTBENEFBFCIARIO/PROCESSOBENEF]

PF-02 — Prévia (Cálculo da Folha)

Objetivo: calcular a prévia de pagamento por recebedor/rubrica (motor central).

Gatilho: botão processar em FFolhaNormalPrevia.dfm ou fFolhaExtra.dfm.

Pré-condições: preparo concluído (PF-01); lote com benefícios preparados; parâmetros globais em FParametroFolha.

Entradas: lote, mês/ano, abono, modo automático, ETL, divide lista, prévia geral/individual.

Passo-a-passo (motor dFolhaPrevia.pas):

  1. ProcessaPrevia (:24781) — orquestra; abre transação (:25386)
  2. Para cada recebedor: CriaRecebedor (:19243) → ProcessaRubricaProvento (:24378)
  3. ProcessaRubrica (:17697) → ExecutaRegraRubrica (:16865) → ClassificaRubricaBase (:15076)
  4. DeterminaBasesIRRF (:7180) → CaluloIRRF (:13493)
  5. VerificaMargemDesconto (:7496) → CalculaMargemDesconto (:7676)
  6. CalculaCPMF (:16764) → CalculaBeneficioMinimo (:8298) → CalculaCorrecaoBeneficio (:8615) → CaluloSalarioFamilia (:9555)
  7. InsereRubrica (:15183) → IncluiPrevia (:4096) — commit (:4138)
  8. ProcessaFechamentoRecebedor (:23310) → ProcessaRateioRubricas (:22816) → ProcessaReinf (:19882)

Validações: margem consignável (FOLHA-RN008); benefício mínimo (RN009); líquido negativo (RN006). Cálculos: CPMF (RN007), IRRF normal/regressivo, salário-família, correção. Saídas: PREVIA, BASEDEPAGAMENTO, BITRIBUTACAO, HSTBITRIBUTACAO, CTRLINTERFACE. Resultado: prévia pronta para conferência/efetivação. Evidência: FOLHA/Fontes/dFolhaPrevia.pas:4096-25405 · COMPROVADO

[FFolhaNormalPrevia] --> ProcessaPrevia(:24781) --> CriaRecebedor --> ProcessaRubricaProvento --> ProcessaRubrica --> ExecutaRegraRubrica --> ClassificaRubricaBase --> DeterminaBasesIRRF --> CaluloIRRF --> VerificaMargemDesconto --> CalculaCPMF --> CalculaBeneficioMinimo --> CalculaCorrecaoBeneficio --> CaluloSalarioFamilia --> InsereRubrica --> IncluiPrevia --> Commit --> ProcessaFechamentoRecebedor --> ProcessaReinf --> [PREVIA/BASEDEPAGAMENTO/BITRIBUTACAO]

PF-03 — Efetivação de Versão de Pagamento

Objetivo: consolidar a prévia em histórico definitivo e gerar arquivos de pagamento.

Gatilho: botão efetivar em fFolhaNormalEfet.dfm após seleção de lote (FSelecionaLoteEF).

Pré-condições: prévia conferida (PF-02); lote selecionado; conta bancária e parâmetros contábeis/financeiros válidos.

Passo-a-passo (fFolhaNormalEfet.pas):

  1. Valida lote, conta bancária (RN012), parâmetros contábeis/financeiros (RN013)
  2. Verifica_Critica_ETL → Executa_ETL (:8722) com 3 datas de pagamento
  3. VerificaEfeticaoETL (:8928) → Monitoramento (:9006)
  4. Gera histórico: HSTFOLHABENEF / HSTFOLHABENEFCAP / HISTRUBSAL
  5. atualizaBasePagamento (:8328) → atualizaHstCalculoPMPFolha (:8405) → atualizaHstPrazoAcumulacaoFolha (:8449)
  6. processaIRRegressivo (:8212) → PreparaContribuicaoPatro (:8605)
  7. GeraArquivoPagamentoLeiauteCNAB150 (:9346) / CNAB240 (:9468) → Set*ArqPagamento (:9584-9728)
  8. GeraArquivoSIACC (:9806) / CargaContraChequeMongo (:9844)

Validações: críticas ETL abortam (RN011); conta bancária do lote (RN012); parâmetros CF (RN013). Saídas: HSTFOLHABENEF, HSTFOLHABENEFCAP, ARQUIVOPAGTO, arquivos CNAB em disco. Resultado: versão de pagamento efetivada. Evidência: FOLHA/Fontes/fFolhaNormalEfet.pas:8158-9844 · COMPROVADO

[fFolhaNormalEfet] --> Valida(Lote/Conta/ParamCF) --> Executa_ETL --> VerificaEfeticaoETL --> [HSTFOLHABENEF/HSTFOLHABENEFCAP] --> atualizaBasePagamento --> processaIRRegressivo --> GeraArquivoCNAB150|CNAB240 --> [ARQUIVOPAGTO + arquivo CNAB] --> GeraArquivoSIACC --> CargaContraChequeMongo

PF-04 — Estorno de Folha

Objetivo: desfazer folha individual ou por lote preservando histórico.

Gatilho: botão processar em festornafolha.dfm (:4576).

Pré-condições: versão efetivada; usuário com permissão; motivo de estorno informado.

Passo-a-passo (festornafolha.pas):

  1. VerificaStatusDocumentosVersao (:900) → HabilitaEstornoIndividual (:939)
  2. VerificaTmpDesc (:2030) → DesfazRubricaIndividual (:1843)
  3. GeraAlterador (:1183) → GeraCAP (:1523) → GeraCAR (:1654)
  4. GravaMotivoEstorno (:1709) → ProcessaCompensacao (:1739)
  5. Exec_SP_ExcessoDebito (:1801) → EstornoFolhaCompleto (:2062)

Exceções: estorno de pagamento pendente (:2384), erro de processo (:2455), novo CAP (:2911), reprocessamento (:3013). Saídas: estorna HSTFOLHABENEFCAP, HISTRUBSAL, RUBRICAINDIV, ARQUIVOPAGTO; gera CAP/CAR. Evidência: FOLHA/Fontes/festornafolha.pas:624-3013 · COMPROVADO

[festornafolha] --> VerificaStatus --> DesfazRubricaIndividual --> GeraAlterador --> GeraCAP --> GeraCAR --> GravaMotivoEstorno --> ProcessaCompensacao --> Exec_SP_ExcessoDebito --> EstornoFolhaCompleto --> [estorna HSTFOLHABENEFCAP/HISTRUBSAL/RUBRICAINDIV + CAP/CAR]

PF-05 — Pagamento / Fita de Crédito / Remessa Bancária

Objetivo: gerar arquivos de remessa (CNAB), simular e bater retorno.

Gatilho: fGeraArquivoRemessa.dfm (bbtnProcessarClick :342), FAberturaFitaCredit.dfm, FRemessaEletronica.dfm, fGeraArquivoRemessaPrevia.dfm.

Pré-condições: versão efetivada (PF-03); conta bancária/portador configurados; leiaute CNAB selecionado.

Passo-a-passo: abertura da fita por plano → seleção de versão → geração do arquivo CNAB (150/240) → gravação em disco + ARQUIVOPAGTO → simulação (prévia) → batimento de retorno (SOL 207789/KINTANA 554287).

Saídas: arquivo de remessa em disco, ARQUIVOPAGTO. Evidência: FOLHA/Fontes/fGeraArquivoRemessa.pas:342, fGeraArquivoRemessaPrevia.pas, FRemessaEletronica.pas · COMPROVADO

[FAberturaFitaCredit] --> [fGeraArquivoRemessa] --> GeraArquivoCNAB150|CNAB240 --> [arquivo disco + ARQUIVOPAGTO] --> (simulação) --> BatimentoRetorno

Passo-a-passo: apura rubricas por plano contábil → InstanciaDtmLocal (dFolhaPrevia.pas:19438) instancia dContabil.pas → gera lançamentos contábeis. Saídas: lançamentos contábeis (tabela destino não identificada em FOLHA/ — PENDENTE). Evidência: dFolhaPrevia.pas:19438, dContabil.pas · COMPROVADO (chamada); destino PENDENTE

PF-08 — IRRF (Compensação, Exceções, Ação Judicial)

Objetivo: calcular IR normal, regressivo, abono, judicial; compensar IR.

Gatilho: cálculo automático na prévia (PF-02) + cadastros FCadExcessoesIR, FCadDepJudicial, FCadCompensaIRRF, FHistCompSalContri.

Passo-a-passo (dentro de CaluloIRRF, dFolhaPrevia.pas:13493):

  1. DeterminaBasesIRRF (:7180) separa bases FUND/INSS
  2. AtualizaFlgIsento (:10302) → VerificaCompensacaoIRRF (:10254)
  3. Decisão: IR normal (CalculaLancaIRNormal :12380) ou regressivo (CalculaLancaIRRegressivo :12123, tipo 0=vitalício/1=abono/7=reserva)
  4. LancaIRCompensado (:12005) → LancaRubricaDEP_IDADE_IR (:10569) → BuscaOutros_IRMensal (:11982)
  5. Atualiza BITRIBUTACAO/HSTBITRIBUTACAO (transações :15679-16030)

Regras: FOLHA-RN004 (natureza de rendimento), RN005 (proventos somam à base), RN015 (IR regressivo por tipo). Saídas: BITRIBUTACAO, HSTBITRIBUTACAO, HSTDEDIDADEBITRIB. Evidência: dFolhaPrevia.pas:7180-13493 · COMPROVADO

[CaluloIRRF] --> DeterminaBasesIRRF --> AtualizaFlgIsento --> VerificaCompensacaoIRRF --> {IR normal|IR regressivo(0/1/7)} --> LancaIRCompensado --> LancaRubricaDEP_IDADE_IR --> [BITRIBUTACAO/HSTBITRIBUTACAO]
