5. Sequência Operacional e Ações

JF002 (PF-02) — Prévia (Cálculo da Folha)

Objetivo: calcular a prévia de pagamento por recebedor/rubrica (motor central).

Gatilho/Ator: botão processar em FFolhaNormalPrevia.dfm ou fFolhaExtra.dfm.

Pré-condições: preparo concluído (JF001); lote com benefícios preparados; parâmetros globais em FParametroFolha.

Pós-condições: PREVIA, BASEDEPAGAMENTO, BITRIBUTACAO, HSTBITRIBUTACAO, CTRLINTERFACE populados; prévia pronta para conferência/efetivação.

Sequência operacional (motor dFolhaPrevia.pas):

  1. ProcessaPrevia (:24781) — orquestra; abre transação (:25386) [RS022]
  2. Para cada recebedor: CriaRecebedor (:19243) → ProcessaRubricaProvento (:24378) [RS029]
  3. ProcessaRubrica (:17697) → ExecutaRegraRubrica (:16865) → ClassificaRubricaBase (:15076)
  4. DeterminaBasesIRRF (:7180) → CaluloIRRF (:13493) [RS004] [RS005] [RS015] [RS017]
  5. VerificaMargemDesconto (:7496) → CalculaMargemDesconto (:7676) [RS008] [TRT010]
  6. CalculaCPMF (:16764) → CalculaBeneficioMinimo (:8298) → CalculaCorrecaoBeneficio (:8615) → CaluloSalarioFamilia (:9555) [RS007] [RS009] [RS020] [RS021] [TRT011]
  7. InsereRubrica (:15183) → IncluiPrevia (:4096) — commit (:4138) [RS006] [TRT005]
  8. ProcessaFechamentoRecebedor (:23310) → ProcessaRateioRubricas (:22816) → ProcessaReinf (:19882) [RS018] [RS019]

6. Regras de Negócio da Jornada

As regras de negócio aplicáveis a esta jornada são apresentadas abaixo com seu texto completo, sem necessidade de acessar outra página.

RS004 (FOLHA-RN004) — Rubrica de IR exige natureza de rendimento

Descrição: toda rubrica que compõe a base de IRRF deve ter natureza de rendimento informada.

Campos de dados:

  • PROVDESC.natureza — [obrigatório] — domínio: código de natureza de rendimento
  • PROVDESC.FLGIRRF — [obrigatório] — indica se rubrica compõe base de IR (S/N)
  • BITRIBUTACAO — [condicional] — tributação calculada

Condição: rubrica marcada como base de IR sem natureza de rendimento → não soma à base.

Tratamento (TRT): TRT004 → MSG004 → Não soma à base de IRRF

Rotina: TobjRecebedor.DeterminaBasesIRRF. Origem: FOLHA/Fontes/dFolhaPrevia.pas:7180. Evidência: COMPROVADO · Severidade: média · Jornada: JF002, JF008 · Relacionadas: RS005

RS005 (FOLHA-RN005) — Proventos somam à base de IRRF

Descrição: os proventos tributáveis são acumulados na base de IRRF por fonte pagadora e tipo de base.

Campos de dados:

  • PREVIA.VALORPROVENTO — [obrigatório] — valor do provento
  • BITRIBUTACAO — [obrigatório] — base de IRRF por fonte/tipo
  • fonte — [obrigatório] — fonte pagadora
  • tipo — [obrigatório] — domínio: normal, regressivo

Fórmula: BaseIRRF[fonte,tipo] = Σ proventos tributáveis.

Rotina: DeterminaBasesIRRF → AlocaBase. Origem: FOLHA/Fontes/dFolhaPrevia.pas:7180,15010. Evidência: COMPROVADO · Severidade: alta · Jornada: JF008 · Relacionadas: RS004, RS015

RS006 (FOLHA-RN006) — Líquido negativo zera e transfere desconto

Descrição: quando o líquido do recebedor fica negativo após descontos, o valor é zerado e o desconto excedente é transferido/tratado.

Campos de dados:

  • lrvalorliquido — [obrigatório] — valor líquido calculado
  • lrvalordesc — [obrigatório] — total de descontos
  • excedente — [condicional] — desconto excedente transferido

Condição: if lrvalorliquido - lrvalordesc < 0 → ação de zera/transfere. Fórmula: líquido = proventos − descontos; se líquido < 0 → líquido := 0 (e excedente tratado).

Tratamento (TRT): TRT005 → MSG005 → Zera líquido e transfere desconto

Rotina: TobjRecebedor.EfetivaRubricas / processamento de líquido. Origem: FOLHA/Fontes/dFolhaPrevia.pas:7269 (e :8000). Evidência: COMPROVADO · Severidade: alta · Jornada: JF002 · Relacionadas: RS008

RS007 (FOLHA-RN007) — CPMF = valor × (percCPMF − 1)

Descrição: o CPMF é calculado sobre o valor base pelo fator (prmPercCPMF − 1).

Campos de dados:

  • arvalor — [obrigatório] — valor base (parâmetro de entrada)
  • prmPercCPMF — [obrigatório] — percentual global do CPMF (parâmetro do sistema)
  • CPMF — [opcional] — resultado calculado

Fórmula: CPMF = arvalor × (prmPercCPMF − 1).

Rotina: TobjRecebedor.CalculaCPMF. Origem: FOLHA/Fontes/dFolhaPrevia.pas:16764-16766. Evidência: COMPROVADO (fórmula literal) · Severidade: média · Jornada: JF002 · Relacionadas: RS016

RS008 (FOLHA-RN008) — Margem de desconto consignável

Descrição: o total de descontos consignáveis não pode ultrapassar a margem disponível do recebedor; rubricas que excedem são bloqueadas/ajustadas.

Campos de dados:

  • rliquidototal — [obrigatório] — líquido total do recebedor
  • renda — [obrigatório] — renda do recebedor
  • percMargem — [obrigatório] — percentual de margem consignável
  • descontosConsignaveis — [obrigatório] — soma dos descontos consignáveis
  • margemDisponivel — [condicional] — margem restante

Condição: if rliquidototal <= 0.009 → margem esgotada. Fórmula: margemDisponivel = renda × percMargem − Σ descontosConsignaveis.

Tratamento (TRT): TRT010 → MSG010 → Bloqueia/ajusta rubrica

Rotina: VerificaMargemDesconto → CalculaMargemDesconto → DeterminaTipoMargem. Origem: FOLHA/Fontes/dFolhaPrevia.pas:7496,7440,7676,14922. Evidência: COMPROVADO · Severidade: alta · Jornada: JF002 · Relacionadas: RS006

RS009 (FOLHA-RN009) — Benefício mínimo por concessão

Descrição: se o valor previado ficar abaixo do benefício mínimo da concessão, o valor é ajustado ao mínimo.

Campos de dados:

  • valorPrev — [obrigatório] — valor previado
  • valorBenefMin — [obrigatório] — benefício mínimo (regra/concessão)
  • lspercentual — [opcional] — percentual decimal

Condição: valorPrev < valorBenefMin → ajusta. Fórmula: valorPrev = max(valorPrev, valorBenefMin).

Tratamento (TRT): TRT011 → MSG011 → Ajusta ao mínimo

Rotina: TobjRecebedor.CalculaBeneficioMinimo. Origem: FOLHA/Fontes/dFolhaPrevia.pas:8298. Evidência: COMPROVADO · Severidade: média · Jornada: JF002 · Relacionadas: —

RS015 (FOLHA-RN015) — IR regressivo por tipo de base (0/1/7)

Descrição: o IR regressivo é calculado conforme o tipo de base: 0=vitalício, 1=abono, 7=reserva.

Campos de dados:

  • aiTipoBase — [obrigatório] — domínio fechado: 0 (vitalício), 1 (abono), 7 (reserva)
  • base por tipo — [obrigatório] — base de IR apurada por tipo
  • tabela regressiva — [obrigatório] — tabela de IR regressiva

Condição: plano com opção de IR regressivo → CalculaLancaIRRegressivo(aiTipoBase). Fórmula: apura base por tipo → aplica tabela regressiva → lanca rubrica de IR.

Rotina: CalculaLancaIRRegressivo / CalculaLancaIRRegressivoValor. Origem: FOLHA/Fontes/dFolhaPrevia.pas:12123,12254. Evidência: COMPROVADO · Severidade: alta · Jornada: JF008 · Relacionadas: RS005

RS017 (FOLHA-RN017) — Compensação de IRRF respeita saldo

Descrição: a compensação de IRRF só lanca até o saldo de compensação disponível.

Campos de dados:

  • valorIRRF — [obrigatório] — valor de IRRF a compensar
  • saldoComp — [obrigatório] — saldo de compensação disponível
  • valorCompensado — [opcional] — valor efetivamente compensado

Fórmula: valorCompensado = min(valorIRRF, saldoComp).

Rotina: VerificaCompensacaoIRRF → LancaIRCompensado. Origem: FOLHA/Fontes/dFolhaPrevia.pas:10254,12005. Evidência: COMPROVADO · Severidade: média · Jornada: JF008 · Relacionadas: RS005, RS015
