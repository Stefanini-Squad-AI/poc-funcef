💡 Em linguagem simples (enriquecido — PFC-42)

O que esta aba mostra: os fluxogramas dos principais processos da folha: a sequência de rotinas que o sistema executa em cada etapa, do preparo ao estorno.

Por que isso importa: um fluxograma mostra a ordem das coisas e onde estão as decisões. Ajuda a entender o que acontece por trás de um clique e onde um problema pode surgir.

Como ler esta página: leia cada diagrama como um mapa de metrô, de cima para baixo. Retângulo é um passo; losango é uma decisão; cilindro é uma tabela onde o dado fica guardado. O número depois de “!” é a linha do código onde o passo está (ex.: “!1755” = linha 1.755). Abaixo de cada diagrama há um parágrafo “💡 Em outras palavras” com o mesmo fluxo em linguagem comum. 💡 Em outras palavras: na efetivação, a folha não é gravada pelo próprio programa: ele deixa um “bilhete” (arquivo-gatilho) numa pasta para a rotina de ETL e fica perguntando, a cada 10 segundos, se o trabalho terminou. Se o ETL avisar falha, a efetivação é interrompida e a equipe de monitoramento é avisada.

👔 Para o analista de negócios

  • A espera não tem limite de tempo no código (fFolhaNormalEfet.pas:8772-8775) COMPROVADO. Num dia de folha, uma parada do ETL deixa a efetivação aguardando. Defina um tempo máximo aceitável e um plano de contingência.
👔 Para o analista de negócios — síntese (PFC-42)

Os fluxos mostram que a folha é uma linha de montagem: preparo → prévia → conferência → efetivação → pagamento, com o estorno como caminho de correção. Os pontos de decisão mais relevantes para o negócio são a conferência (humana), o perfil de investimento (bloqueio automático), o ETL (dependência externa) e a escolha do leiaute bancário.

Validações sugeridas

  • Confirmar com a área contábil onde os lançamentos da folha são gravados (PF-06).
  • Confirmar se o “Preparo - SP” substitui o preparo tradicional ou se convive com ele.
  • Formalizar quem aprova a passagem da conferência para a efetivação.
