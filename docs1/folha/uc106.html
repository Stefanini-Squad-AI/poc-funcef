2. Descrição Resumida

Importação/exportação de arquivos de convênio e desconto de financiamento habitacional na folha. Este caso de uso reúne 2 jornada(s) funcional(is) do módulo Folha de Benefícios:

  • JF011 — Convênio (Importação/Exportação): importar/exportar convênios e gerar documentos para entidades conveniadas.
  • JF018 — Financiamento Habitacional: processar financiamento habitacional (rubrica de desconto).
3. Pré-condições

Gerais do módulo:

  • O módulo FOLHA deve estar compilado e disponível (entry point FOLHA/Fontes/Folha.dpr).
  • O banco Oracle (schema CM.) deve estar acessível.
  • Os parâmetros globais da folha devem estar carregados (FParametroFolha).
  • Patrocinadoras, planos e benefícios devem estar cadastrados.
  • O usuário deve ter permissão de acesso ao módulo.

Por jornada:

  • JF011: mês/ano, layout de entrada/saída, destino informados [RS002] [TRT002].
  • JF018: —
4. Pós-condições
  • JF011: arquivos de convênio importados/exportados; documentos gerados para entidades.
  • JF018: —

JF011 (PF-11) — Convênio (Importação/Exportação)

Objetivo: importar/exportar convênios e gerar documentos para entidades conveniadas.

Gatilho/Ator: fImportaTxt.dfm, fTratamentoConvenio.dfm, FExportaTxT.dfm, FExecGeraDocConvenio.dfm.

Pré-condições: mês/ano, layout de entrada/saída, destino informados [RS002] [TRT002].

Pós-condições: arquivos de convênio importados/exportados; documentos gerados para entidades.

Sequência operacional:

  1. Importa TXT (layout de entrada)
  2. Tratamento de convênio
  3. Exporta (layout de saída) [RS002] [RS003] [TRT003]
  4. Gera documentos/arquivos para entidades [RS026] [RS027] [TRT012] [TRT013]

RS002 (FOLHA-RN002) — Layout de entrada/saída e destino obrigatórios na exportação

Descrição: a exportação exige ano, mês, layout de entrada, layout de saída e destino informados.

Campos de dados:

  • edAno — [obrigatório] — inteiro positivo
  • cboxMes — [obrigatório] — domínio: 1–12
  • dblcmbLayout — [obrigatório] — identificador do layout de entrada
  • dblcmblayoutsaida — [obrigatório] — identificador do layout de saída
  • destino — [obrigatório] — caminho/identificador de destino
  • TMPDESC — [condicional] — dados temporários de descritivo

Condição: edAno, cboxMes, dblcmbLayout, dblcmblayoutsaida, destino não informados → bloqueia.

Exceção: raise EValidacao em :508/:511/:514/:517/:522; raise Exception em :234 (falha ao gravar log).

Tratamento (TRT): TRT002 → MSG002 → Bloqueia execução

Rotina: validação inline. Origem: FOLHA/Fontes/FExportaTxT.pas:508-522. Evidência: COMPROVADO · Severidade: alta · Jornada: JF011 · Relacionadas: RS003

RS003 (FOLHA-RN003) — Seleção mínima de versão da folha

Descrição: a geração de documentos/arquivos para convênios exige pelo menos uma versão da folha selecionada.

Campos de dados:

  • molVersaoPagto.lstVersao — [obrigatório] — pelo menos 1 item selecionado
  • LOTEXHSTFOLHABENEF — [condicional] — lote/versão da folha

Condição: nenhuma versão selecionada em molVersaoPagto.lstVersao → bloqueia.

Exceção: raise EValidacao em :1223/:1248/:1254/:1261/:2627.

Tratamento (TRT): TRT003 → MSG003 → Bloqueia execução

Rotina: validação inline. Origem: FOLHA/Fontes/FExecGeraDocConvenio.pas:1214-1261. Evidência: COMPROVADO · Severidade: alta · Jornada: JF011 · Relacionadas: RS002

RS026 (FOLHA-RN026) — Geração de documentos para convênios exige mês/ano/previsão

Descrição: a geração de documentos/arquivos para entidades conveniadas exige mês, ano e previsão de pagamento informados (além da versão — RS003).

Campos de dados:

  • mês — [obrigatório] — domínio: 1–12
  • ano — [obrigatório] — inteiro positivo
  • previsão de pagamento — [obrigatório] — identificador da previsão

Exceção: raise EValidacao em :1214 (mês), :1217 (ano), :1220 (previsão).

Tratamento (TRT): TRT012 → MSG012 → Bloqueia execução

Origem: FOLHA/Fontes/FExecGeraDocConvenio.pas:1214-1220. Evidência: COMPROVADO · Severidade: alta · Jornada: JF011 · Relacionadas: RS003

RS027 (FOLHA-RN027) — Saída cadastral de entidades exige mês/ano/versão

Descrição: a geração de saída cadastral para entidades exige mês, ano e pelo menos uma versão da folha.

Campos de dados:

  • mês — [obrigatório] — domínio: 1–12
  • ano — [obrigatório] — inteiro positivo
  • versão da folha — [obrigatório] — pelo menos 1 selecionada

Tratamento (TRT): TRT013 → MSG013 → Bloqueia execução
