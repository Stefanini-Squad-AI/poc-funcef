5. Sequência Operacional e Ações

JF003 (PF-03) — Simulação / Memória de Cálculo

Objetivo: Simular a elegibilidade e o valor previsto dos benefícios de um participante, sem gravar dados, e consultar a memória de cálculo.

Ator / gatilho: Analista de benefícios ou atendimento, na tela Simulação de Benefício.

Pré-condições: Participante com plano e regras de data de elegibilidade e de valor previsionado cadastradas no benefício.

Pós-condições: Nenhuma gravação; resultado exibido na tela (memResult).

Sequência operacional:

  1. Abrir a simulação (assistente em 4 etapas) e selecionar participante, plano e benefícios.
  2. O sistema calcula a data de elegibilidade de cada benefício e mostra “Elegível” ou “Bloqueado”. [RS004]
  3. O sistema calcula o valor previsionado ou mostra “Indefinido”. [RS005]
  4. Consultar a memória de cálculo (DETCALCULO), se necessário.

RS004 (BENEF-RN004) — Elegibilidade por data na simulação
Na simulação, a data de elegibilidade é obtida pela regra de data do benefício; se essa data já chegou, o benefício aparece como “Elegível”, senão como “Bloqueado”.

Campos de dados:

  • Regra de data de elegibilidade (IDRGDATAELEG) — [condicional] — sem regra, o benefício é tratado como elegível
  • Dados do participante (ELEGPATRO, PARTPREVPLAN) — [obrigatório]

Tratamento de erro: — (regra de seleção/cálculo, sem crítica ao usuário)

Jornada: JF003

Nota de verificação: Sem IDRGDATAELEG o código atribui “Elegível” diretamente (FSimulaBeneficio.pas:243).

Descrição original: Simulação: elegibilidade por data via regra string.

Condições: RegraString(IDRGDATAELEG) → data ≤ date

Dados envolvidos: ELEGPATRO, PARTPREVPLAN

Resultado/Exceção: 'Elegível' ou 'Bloqueado'

📂 Origem: BENEFICIOPREV/Fontes/FSimulaBeneficio.pas:235-239 | Evidência: COMPROVADO
RS005 (BENEF-RN005) — Valor previsionado por regra numérica
Na simulação, o valor previsto do benefício é calculado pela regra numérica cadastrada; sem regra, o valor aparece como “Indefinido”.

Campos de dados:

  • Regra de valor previsionado (IDRGVALORPREV) — [condicional] — sem regra → “Indefinido”
  • Dados do participante (ELEGPATRO, PARTPREVPLAN) — [obrigatório]

Tratamento de erro: — (regra de seleção/cálculo, sem crítica ao usuário)

Jornada: JF003

Descrição original: Simulação: valor previsionado por regra numérica.

Condições: RegraNumerica(IDRGVALORPREV) sobre SQL

Dados envolvidos: ELEGPATRO, PARTPREVPLAN

Resultado/Exceção: Valor estimado ou 'Indefinido'

📂 Origem: BENEFICIOPREV/Fontes/FSimulaBeneficio.pas:246-249 | Evidência: COMPROVADO
