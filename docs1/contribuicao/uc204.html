2. Descrição Resumida

O salário de participação (SALPARTICIPACAO) é o salário usado como base para o cálculo das contribuições previdenciárias do participante. O salário mantido (SALMANTIDO) é o salário de manutenção do participante no plano. Neste caso de uso, o analista de cadastro previdenciário reajusta o salário de manutenção dos participantes ativos (aplicando um índice de correção) e altera em lote, por planilha Excel, o salário mantido e/ou o salário de participação. Quando o participante troca de cargo/função (evolução funcional), o sistema encerra o registro anterior na véspera do início do novo. O resultado é que a base salarial usada no cálculo de contribuições em UC201 fica atualizada. Este caso de uso reúne 1 jornada(s) funcional(is) do módulo Contribuição Previdenciária:

  • JF004 — Salário de participação / manutenção: O analista reajusta o salário de manutenção dos participantes mantidos e altera em lote, por planilha Excel, o salário mantido e o salário de participação.
3. Pré-condições

Gerais do módulo:

  • Módulo disponível (entry point CONTRIBUICAOPREV/Fontes/ContribuicaoPREV.dpr) e usuário com permissão de acesso às telas — o sistema é desktop (Delphi 5 / VCL) e exige login e permissão.
  • Banco Oracle acessível e parâmetros do módulo carregados.
  • Patrocinadoras, planos previdenciários, contribuições (CONTRIBUICAO) e participantes (PARTPREVPLAN, CONTRIBPREVPARTP) cadastrados.
  • Integrações configuradas quando a jornada as usa: Folha, Contas a Receber/CAP, Contabilidade/PGA — ver 🔗 Integrações.
  • Período contábil aberto para as datas usadas em lançamentos.

Por jornada:

  • JF004: Participantes com plano (PARTPREVPLAN) cadastrados; para a alteração em lote, uma planilha Excel no layout esperado, contendo as colunas IDPESSOA (identificador do participante), IDPLANOPREV (plano previdenciário), SALMANTIDO (salário de manutenção) e SALPARTICIPACAO (salário de participação).
4. Pós-condições
  • JF004: O cadastro de participante por plano (PARTPREVPLAN) é atualizado com os novos valores de salário mantido (SALMANTIDO) e/ou salário de participação (SALPARTICIPACAO); o log de auditoria (LOGTOTALPREV) é gravado registrando a alteração. A base salarial fica atualizada para o cálculo de contribuições em UC201.

JF004 (PF-04) — Salário de participação / manutenção

Objetivo: Reajustar o salário de manutenção dos participantes mantidos (aplicando um índice de correção) e alterar em lote, por planilha Excel, o salário mantido (SALMANTIDO) e/ou o salário de participação (SALPARTICIPACAO, a base de cálculo das contribuições). Quando o participante troca de cargo/função, o sistema encerra o registro de evolução funcional anterior na véspera do início do novo. O resultado é que a base salarial usada no cálculo de contribuições fica atualizada.

Ator / gatilho: Analista de cadastro previdenciário, nas telas Reajusta Salário de Manutenção e Alterar Salário de Manutenção e Participação.

Pré-condições: Participantes com plano (PARTPREVPLAN) cadastrados; para o lote, planilha Excel com IDPESSOA, IDPLANOPREV, SALMANTIDO e SALPARTICIPACAO.

Pós-condições: PARTPREVPLAN é atualizado com os novos salários; o log de auditoria (LOGTOTALPREV) é gravado.

Sequência operacional:

  1. Reajuste: o analista informa as opções de seleção e seleciona os participantes mantidos. [TRT017]
  2. O analista processa o reajuste; o sistema aplica o índice ao salário de manutenção. Em caso de erro em um participante, o sistema pergunta se o analista deseja continuar com os demais. [TRT018]
  3. O analista confere o resultado e confirma a efetivação; o sistema grava o log de auditoria. [TRT053]
  4. Alteração em lote: o analista seleciona o arquivo Excel e quais salários alterar (mantido e/ou participação); o sistema lê a planilha via OLE (Object Linking and Embedding, tecnologia de integração com o Excel). [RS025] [TRT019]
  5. O sistema atualiza o salário em PARTPREVPLAN e grava o log de auditoria. [RS025]

RS023 (CONTRIB-RN023) — Evolução funcional fecha o cargo anterior
Ao registrar novo cargo/função do participante, o registro anterior é encerrado na véspera do início do novo.

Campos de dados:

  • EVOLFUNCPREV.DATAINICIO — [obrigatório] — data do novo cargo
  • EVOLFUNCPREV.DATAFINAL — [obrigatório] — anterior recebe DATAINICIO − 1

Tratamento de erro: não se aplica — regra de seleção/cálculo, sem mensagem ao usuário.

Jornada: JF004

Nota de verificação: Regra de objeto de controle (CtrlObjects), associada à jornada de salário por afetar a base salarial do participante.

Descrição original: Inserção/edição de EVOLFUNCPREV atualiza DATAFINAL do cargo anterior.

Condições: Troca de cargo/função

Dados envolvidos: EVOLFUNCPREV

Resultado/Exceção: UPDATE SET DATAFINAL=DATAINICIO-1

RS025 (CONTRIB-RN025) — Alteração de salários em lote via Excel
A planilha atualiza o salário mantido e/ou o salário de participação do participante no plano, com registro em log.

Campos de dados:

  • IDPESSOA, IDPLANOPREV — [obrigatório] — chaves do participante no plano
  • SALMANTIDO — [condicional] — se “salário mantido” marcado
  • SALPARTICIPACAO — [condicional] — se “salário de participação” marcado

Tratamento de erro: TRT019 → MSG033, MSG034 → Bloqueia a alteração em lote

Jornada: JF004

Descrição original: Alteração em lote de salário via Excel atualiza PARTPREVPLAN.

Condições: Arquivo Excel com IDPESSOA, IDPLANOPREV, SALMANTIDO, SALPARTICIPACAO

Dados envolvidos: PARTPREVPLAN

Resultado/Exceção: UPDATE SET SALMANTIDO=..., SALPARTICIPACAO=... + GravaLogTotalPrev
