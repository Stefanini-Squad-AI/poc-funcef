2. Descrição Resumida

As regras de negócio do módulo Contribuição Previdenciária são 28 regras de jornada (RS001–RS028) que governam a manutenção, cobrança, recebimento, reservas, tributação, portabilidade, benefício saldado/FAB, provisão para perdas e tratamento de divergências. Cada regra preserva o código original CONTRIB-RN, a evidência file:linha e a classificação COMPROVADO/INFERIDO/PENDENTE do PFC-21. As regras estão organizadas por jornada funcional — ver ⚙️ Funcionalidades.

3. Pré-condições
  • O módulo CONTRIBUIÇÃO deve estar compilado e disponível.
  • O banco Oracle (schema CM.) deve estar acessível.
  • Os DataModules (dtmAPrev, dtmIntegraCAPCAR, dtmPreparaContrib) devem estar instanciados.
  • Patrocinadoras, planos e participantes cadastrados (via CMPrevMT50/CMAdmPrev).
4. Pós-condições
  • Cada regra validada garante a integridade do processamento de contribuições.
  • Validações bloqueantes impedem a execução quando dados obrigatórios estão ausentes ou inconsistentes.
  • Cálculos e atualizações produzem valores corretos persistidos em HSTCONTRIBPREV, CONTRIBPREVPARTP, PORTABILIDADEPREV, BITRIBUTACAO, etc.
  • O log de auditoria (LOGTOTALPREV / HSTATRASOCONTRIB) registra as operações.
6. Regras de Negócio da Jornada (RS001–RS028)
COMPROVADO — identificado diretamente no códigoINFERIDO — interpretação plausívelPENDENTE — depende de validação

Cada regra abaixo apresenta: código RS (com link para o código CONTRIB-RN original), título, descrição em linguagem de negócio, campos de dados classificados como [obrigatório], [opcional] ou [condicional] com valores permitidos, tratamento de erro (TRT), evidência (file:linha + classificação) e jornada relacionada. O código original e a evidência de cada regra continuam visíveis.

RS001 (CONTRIB-RN001) — Mês de vínculo da portabilidade válido

Descrição: o mês de vínculo informado no cadastro de contribuição portada deve estar entre 0 e 11.

Campos de dados:

  • EdtMesReferencia — [obrigatório] — domínio: 0–11
  • PORTABILIDADEPREV.MESVINCULO — [obrigatório] — gravado com o valor informado

Categoria: validação de entrada · Gatilho: cadastro/alteração de contribuição portada

Condição: se EdtMesReferencia < 0 OU > 11 → bloqueia. Fórmula: n/a (validação de intervalo).

Exceção: MessageDlg('Mêses de Vinculo Inválido...' + 'Informe o mês entre 0 e 11', mtError) + Abort.

Tratamento (TRT): TRT001 → MSG001 → Bloqueia execução

Origem: CONTRIBUICAOPREV/Fontes/FCadContribuicaoPortada.pas:799-800. Evidência: COMPROVADO · Severidade: alta (bloqueante) · Jornada: JF006
