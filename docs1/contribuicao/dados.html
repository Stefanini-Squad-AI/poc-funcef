💡 Em linguagem simples (enriquecido — PFC-42)

O que esta aba mostra: quais “planilhas” (tabelas) do banco de dados o módulo usa, como elas se ligam e quem inclui, altera ou apaga dados em cada uma.

Por que isso importa: os dados são o patrimônio do negócio: é deles que saem extratos, contabilidade, cobrança e cálculo de benefícios. Saber qual tela grava em qual tabela ajuda a investigar diferenças e a planejar migrações.

Como ler esta página: a primeira tabela lista as entidades e seu papel; o diagrama mostra as ligações (uma seta significa “este registro aponta para aquele”); a tabela CRUD mostra quantas vezes o código Cria (INSERT), Lê, Altera (UPDATE) ou Deleta cada tabela; por fim, os campos-chave do livro-caixa HSTCONTRIBPREV.

👔 Para o analista de negócios — síntese (PFC-42)

Os dados do CONTRIBUIÇÃO são a fonte oficial da situação de cada contribuição e da reserva de cada participante.

  • Dono dos dados: HSTCONTRIBPREV, CONTRIBPREVPARTP e as tabelas de reserva são dados de negócio do plano; PESSOA, PLANPREV e DOCUMENTO pertencem a outros módulos e só são lidos ou complementados aqui.
  • Status padronizado: SITRECEBIMENTO (0–9) é o campo-chave para relatórios de inadimplência, divergência e recebimento.
  • Mesmo nome, significados diferentes: FLGDESCFOLHA tem domínios diferentes em tabelas diferentes (ponto a validar acima).
  • Exclusões físicas: o desfazer apaga registros; a trilha de auditoria depende do log de operações.

Perguntas para levar ao responsável de negócio:

  1. Quais relatórios oficiais (contábeis, atuariais, regulatórios) são extraídos diretamente de HSTCONTRIBPREV e das tabelas de reserva?
  2. Existe política de retenção ou de auditoria para registros apagados pelo “desfazer”?
  3. Quem é o responsável por manter os parâmetros CONTRIBUICAO / CONTPREV (fórmula, tolerância de divergência, ordem de cálculo)?
