  • Identificação das 5 tabelas com dupla contagem (PESSOA, BENEFBFCIARIO, PROCESSOBENEF, HSTCONTRIBPREV, HISTRUBSAL) e das 5 tabelas externas com confirmação pendente (🔍 Lacunas).
  • Explicações em linguagem simples e blocos para o analista de negócios em todas as abas técnicas.
👔 Para o analista de negócios — síntese (PFC-73)

A documentação do CADASTROPREV cobre 96% do módulo (atendendo ao critério AC5 de ≥ 95%). A cobertura é completa em DBObjects (100%), CtrlObjects (100%) e ALs (91%). A cobertura parcial em PEs (62,5% comprovado + 37,5% inferido) deve-se aos 27 PEs que abrem forms externos — o item de menu é comprovado, mas a implementação está em outros módulos (CM, CMAdmPrev, PARAMPREV, GLOBALCM).

Como usar esta cobertura em decisões

  • Para entender processos e telas internas: a documentação é confiável (alto grau de COMPROVADO).
  • Para os 27 PEs com forms externos: valide com os responsáveis pelos módulos CM, CMAdmPrev, PARAMPREV e GLOBALCM.
  • Para mudar ou migrar regras de saldamento: o motor USaldamento.pas (8.861 lin) foi analisado em alto nível — profundar antes de decidir.
  • Para a contagem de pontos de função: validar a dupla contagem das 5 tabelas compartilhadas antes de usar os 57 ALs como base.

Perguntas para o responsável de negócio

  • Os 27 PEs com forms externos são responsabilidade do CADASTROPREV ou dos módulos externos?
  • Qual é a fronteira entre os cinco módulos previdenciários?
