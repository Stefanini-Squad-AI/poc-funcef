Calendário

 

Esta tela lhe ajudará a selecionar uma data:

Utilize as setas para navegar pelos meses de cada ano.

Para alterar o mês, clique sobre o mês listado na tela e selecione o desejado.

Clique sobre o ano informado na tela, para selecionar o ano desejado.

Para selecionar a data de hoje, clique na data em negrito, localizada na parte inferior do calendário.

 Ao clicar sobre o dia, o sistema fecha a tela e preenche o campo com a data indicada no calendário.
