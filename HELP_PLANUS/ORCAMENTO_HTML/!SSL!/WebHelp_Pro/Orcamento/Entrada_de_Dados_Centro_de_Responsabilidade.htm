Entrada de Dados - Centro de Responsabilidade

Neste item, informe o valor orçado para cada centro de responsabilidade cadastrado no sistema.

 

Os centros de responsabilidade são cadastrados no sistema GlobalCM.

 

 Clique na seta à direita do campo Centro de Responsabilidade, para selecionar o centro de responsabilidade desejado.

 Indique o exercício da entrada de dados do centro de responsabilidade.

 Clique no botão Pesquisar, para o sistema disponibilizar os dados, de acordo com o preenchimento dos campos anteriores.

Utilize o campo Fonte, para aumentar ou diminuir o tamanho da letra utilizada no resultado da pesquisa.

Utilize o campo Colunas Fixas, para selecionar a coluna cujo valor você deseja incluir.

Digite o valor orçado desejado.

 Clique no botão Ok, para o sistema efetivar a entrada de dados do centro de responsabilidade.
