Consultas - Relatórios - Gerenciais - Composição dos Demonstrativos Orçamentários

Através deste relatório, faça a impressão da composição dos demonstrativos orçamentários.

 

Ele pode ser impresso, de acordo com a definição do filtro de seleção:

 

Relatório Customizável

Selecione o relatório, clicando na seta à direita do campo. Para imprimir todos os relatório, não preencha este campo.

 

Após definir o filtro de seleção, clique no botão Ok.

 

Obs.: Repita este processo toda vez que você quiser definir outro relatório.

 

Campos apresentados no relatório:

 

Nome do Relatório

Disponibiliza o nome do relatório configurável.

 

Demonstrativo

Mostra o nome complementar do relatório.

 

Conta Orçamentária

Disponibiliza o código e o nome da conta orçamentária.

 

Número Decimais

Mostra o número de decimais de cada conta.

 

Indentação

Disponibiliza o código da indentação utilizada.

 

Tipo de Linha Separadora

Mostra o tipo de linha separadora.
