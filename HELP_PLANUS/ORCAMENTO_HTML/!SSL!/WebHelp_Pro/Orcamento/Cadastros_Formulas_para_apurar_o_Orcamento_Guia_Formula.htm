Cadastros - Fórmulas para apurar o Orçamento - Guia Fórmula

 Clique no botão Inserir para inserir um registro de detalhe para a fórmula.

 Clique no botão Alterar para alterar um registro de detalhe da fórmula.

 Clique no botão Excluir para excluir um registro de detalhe da fórmula.

 

Informe os seguintes campos:

 

Data Cadastramento

Informe a data de cadastramento da fórmula.

 

Período Destino

Informe os períodos "Inicial" e "Final" para apuração da fórmula.  Quando, na apuração da fórmula, informarmos os períodos Destino, o sistema validará se os mesmos estão dentro dos limites estabelecidos aqui.  O sistema não projetará os valores para os períodos fora do limite.

Percentual a aplicar s/ Forma Apuração

Indique um percentual a ser aplicado sobre a Forma de Apuração indicada anteriormente, quando da apuração da fórmula.

 Acumula Percentual - Indique se o percentual deve ser acumulado ao longo dos meses.  É semelhante ao conceito de  "juros compostos".

 

Moeda

Indique uma moeda para conversão/atualização da Forma de Apuração indicada anteriormente, quando da apuração da fórmula.

 Acumula Moeda - Indique se o valor atualizado deve ser acumulado ao longo dos meses.  É semelhante ao conceito de  "juros compostos" e deve ser "marcado" quando indicamos um índice financeiro como moeda.  Ex.  Correção pelo IGPM.
