Processos - Transferência Orçamentária - Especial

Neste item, proceda a transferência de valores entre contas orçamentárias distintas.

 

Caso o parâmetro Permite transferências entre contas orçamentárias de grupos diferentes não esteja marcado, somente será possível transferências orçamentárias entre contas de mesmo Grupo.

 

A transferência orçamentária deve ser utilizada, quando os responsáveis pela gestão do orçamento da empresa entenderem que há a necessidade de aumentar o saldo de uma conta, normalmente em situações inesperadas, utilizando-se do saldo de outra conta.

 

Existe uma diferença fundamental entre Transferência e Ajuste (Suplementação/Dedução) Orçamentário.  O Ajuste Orçamentário normalmente ocorre uma vez no ano, com participação/aprovação dos Conselhos, e visa ajustar os saldos do orçamento vigente em função de problemas extraordinários inesperados, como catástrofes, fenômenos meteorológicos, cenário político ou coisas do gênero.  Normalmente nas empresas, o departamento responsável pela gestão do orçamento não tem autonomia para ajustar valores do orçamento vigente e sim transferí-los quando julgar necessário.  Na Transferência Orçamentária o saldo final orçado não se altera, já que sai de uma conta e entra em outra.  No Ajuste Orçamentário há alteração no saldo final do orçamento.

 

Este ítem só deve ser utilizado por quem cadastrou o Plano de Contas Orçamentário através do ítem Cadastros - Contas Orçamentárias por Grupo ou Cadastros - Contas Orçamentárias por Grupo e Centro de Responsabilidade.

 

Neste ítem o usuário não leva em conta as diversas contas orçamentárias cadastradas internamente pelo sistema, e para as quais faz-se necessário informar valores, mas sim, o Grupo da conta orçamentária.

 

Através de um filtro para seleção das contas, baseado em Grupo, Centro de Responsabilidade, Patrocinadora e/ou Plano Previdenciário, o sistema faz o cadastramento das transferências para um determinado conjunto de contas por "centro de custo".

 

Preencha os campos da tela conforme explicações a seguir:

 

 

GRUPO DE ORIGEM / GRUPO DE DESTINO

 

Aqui cadastre os dados referentes aos grupos de contas de onde partirão e para onde irão as transferências.

 

Grupo Orçamentário

Clique no botão a direita do campo, para selecionar o Grupo de contas orçamentárias que se deseja filtrar.

 

Plano de Trabalho

Clique na seta a direita do campo, para informar o Plano de Trabalho ao qual está amarrado o Centro de Responsabilidade do conjunto de contas orçamentárias que se deseja filtrar.

 

Patrocinadora

Clique na seta a direita do campo, para informar a Patrocinadora do conjunto de contas orçamentárias que se deseja filtrar.

 

Plano Previdenciário

Clique na seta a direita do campo, para informar o Plano Previdenciário do conjunto de contas orçamentárias que se deseja filtrar.

 

Período

Clique na seta a direita do campo, para informar o período no qual desejamos fazer transferências.  

 

Exercício

Digite o exercício no qual desejamos fazer as transferências.

 

 Clique no botão Selecionar Contas Orçamentárias para efetuar a filtragem.  Caso existam contas orçamentárias cadastradas por centro de custo, para os mesmos filtros informados acima, o sistema retornará esse conjunto de contas para que sejam cadastradas as transferências.

 

MONTAGEM DA TRANSFERÊNCIA

 

 Indique Centro de Custo, Período e Exercício das contas de Origem/Destino.

 Indique, caso desejado, uma observação para o registro de transferência em andamento.

 Indique a Data de Referência da Transferência.  A data de referência é a data na qual se está comprometendo os saldos orçados para as contas.

 Indique o Valor das Transferência.

 Clique no botão Incluir, para inserir no "grid" os registros de transferência, para o centro de custo informado, na data e valor informados.

 Clique no botão Excluir para retirar os registros do "grid".

 Assinale a caixa de verificação "Manter observações", para que a observação digitada para um registro da transferência em vigor, se repita para os demais registros.

 

 

 Clique no botão Excluir para excluir transferências efetuadas para um grupo de contas.

 Clique no botão Ok para efetivar o cadastramento das transferências efetuadas para um grupo de contas.
