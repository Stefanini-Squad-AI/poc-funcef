Cadastros - Contas Orçamentárias por Grupo

Em Cadastro - Contas Orçamentárias, as contas são vinculadas a um Grupo Orçamentário, que tem a finalidade de ser uma estrutura gerencial mais sintética do que a conta orçamentária e, assim, propiciar uma visão gerencial mais consolidada das contas.

 

Este ítem deve ser utilizado por quem elaborou o cadastro de Grupos Orçamentários como sendo as próprias contas orçamentárias.

 

Este cadastro é utilizado para replicar as contas (Grupos) entre as estruturas de Atividade/Projeto, Centro de Custo, Plano e Patrocinadora.

 

Internamente, a partir deste ítem, o sistema criará diversas estruturas que convencionaremos chamar de contas orçamentárias, porém, as contas orçamentárias de verdade, são definidas na estrutura de Grupos, sendo as contas criadas aqui, uma segregação dos Grupos por Atividade/Projeto, Centro de Custo, Plano e Patrocinadora.

 

Observe, abaixo, um exemplo de contas orçamentária cadastradas como Contas Orçamentárias (Cadastros - Contas Orçamentárias) e outro delas cadastradas como Grupos (Cadastros-Contas Orçamentárias por Grupo).

 

Como Conta:

 

05 - Programa Administrativo (Grupo)

05.02 - Pessoal (Grupo)

05.02.01.01.0101.02.03 - Folha de Pagamento (0502 - Pessoal + 01 - Folha de Pagamento + 01 - Atividade Padrão + 0101 C.C. Tesouraria + 02 - Plano CD + 03 Patrocinadora Comum) - (Conta)

 

Como Grupo:

 

05 - Programa Administrativo (Grupo)

05.02 - Pessoal (Grupo)

05.02.01 - Folha de Pagamento (Grupo)

05.02.01.0101.02.03 - Folha de Pagamento (0502 - Pessoal + 01 - Folha de Pagamento + 01 - Atividade Padrão + 0101 C.C. Tesouraria + 02 - Plano CD + 03 Patrocinadora Comum) - (Conta)

 

Para cadastrar uma conta orçamentária, clique no botão Inserir e preencha os seguintes campos:

 

Grupo

Clique no botão Seleciona, para informar o Grupo (Conta)

 

Nome da(s) Conta(s) Orçamentária(s)

Nome preenchido automaticamente pelo sistema, com o nome do Grupo escolhido.  Pode ser alterado.

 

Centro de Responsabilidade

Indique o centro de responsabilidade que está associado a esta conta, ou seja, qual o centro de responsabilidade que terá autonomia para indicar o valor orçado para esta conta ou para fazer processos (reserva, compromisso, transferência, suplementação e dedução) para a mesma.

Os usuários cadastrados no sistema deverão ser associados a um ou vários centros de responsabilidade.

O sistema só permitirá que o usuário faça orçamento das contas que estiverem associadas a centros de responsabilidades, que estejam habilitados para ele.

A correlação entre usuários e centros de responsabilidade é feita através do item Cadastros - Usuários x Centro de Responsabilidade.

 

Tipo de Cálculo do Orçado

Informe como será apurado o valor orçado da conta, quando da geração através do ítem de menu Geração de Dados.  Existem as seguintes opções de cálculo para o orçado:

 Valor Informado Manualmente – Este tipo de cálculo fará com que, o valor orçado da conta, seja aquele que foi digitado, manualmente, através do ítem de menu Entrada de Dados - Por Período e Entrada de Dados - Diária.

 Valor Fixo Informado – Este tipo de cálculo fará com que o valor orçado desta conta seja o valor que estiver indicado na guia Valor Fixo Informado. Neste caso, este valor será constante e não precisará ser lançado.

 Fórmula – Este tipo de cálculo fará com que o valor orçado desta conta seja o valor resultante da fórmula matemática, montada na guia Fórmulas/Acumulado.

 Composição de Outras Contas – Este tipo de cálculo fará com que o valor orçado desta conta seja o somatório dos valores (ou percentuais destes valores), de outras contas orçamentárias indicadas na guia Contas Orçado.

 Valor Acumulado – Este tipo de cálculo fará com que o valor orçado desta conta seja o valor acumulado de outra(s) conta(s), indicada(s) na guia Fórmulas/Acumulado.

 Título – Esta opção não faz nenhum tipo de cálculo. Deve ser indicada apenas em contas orçamentárias, utilizadas como título de uma parte do plano orçamentário.

 Condicional – Este tipo de cálculo fará com que o valor orçado desta conta seja o que estiver indicado como resultado (valor ou saldo de outra conta), de acordo com a condição estabelecida para a conta orçamentária. Esta definição de condições e respectivos resultados é feita através da guia Condicionais.

 

Tipo de Cálculo do Realizado

Informe como será apurado o valor realizado da conta, quando da geração através do ítem de menu Geração de Dados.  Existem as seguintes opções de cálculo para o realizado:

 

 Valor Informado Manualmente – Este tipo de cálculo fará com que, o valor realizado da conta, seja aquele que foi digitado, manualmente, através do ítem de menu Entrada de Dados - Por Período e Entrada de Dados - Diária.

 Contabilidade – Este tipo de cálculo utilizará os parâmetros definidos na guia Contabilidade ,para apurar os valores realizados da conta quando da geração da mesma através do ítem Geração de Dados.  

 Fluxo de Caixa – Este tipo de cálculo utilizará os parâmetros definidos na guia Fluxo de Caixa ,para apurar os valores realizados da conta quando da geração da mesma através do ítem Geração de Dados.

 Arquivos Genéricos – Este tipo de cálculo fará com que o valor realizado desta conta seja o resultante da consulta feita ao banco de dados, conforme a query (consulta) montada na guia Arquivos Genéricos.

 Valor Fixo Informado – Este tipo de cálculo fará com que o valor realizado desta conta seja o valor que estiver indicado na guia Valor Fixo Informado.  Neste caso, este valor será constante e não precisará ser lançado.

 Fórmula – Este tipo de cálculo fará com que o valor realizado desta conta seja o valor resultante da fórmula matemática, montada na guia Fórmulas/Acumulado.

 Composição de Outras Contas – Este tipo de cálculo fará com que o valor realizado desta conta seja o somatório dos valores (ou percentuais destes valores), de outras contas orçamentárias, indicadas na guia Contas Realizado.

 Valor Acumulado – Este tipo de cálculo fará com que o valor realizado desta conta seja o valor acumulado de outra(s) conta(s), indicada(s) na guia Fórmulas/Acumulado.

 Título – Esta opção não faz nenhum tipo de cálculo. Deve ser indicada apenas em contas orçamentárias, utilizadas como título de uma parte do plano orçamentário.

 Condicional – Este tipo de cálculo fará com que o valor realizado desta conta seja o que estiver indicado como resultado (valor ou saldo de outra conta), de acordo com a condição estabelecida para a conta orçamentária. Esta definição de condições e respectivos resultados é feita através da guia Condicionais.

 

Tipo de Cálculo dos Valores Acumulados

Selecione o tipo de cálculo para o valor acumulado, da conta que está sendo cadastrada. Você tem as seguintes opções:

 Calcula o valor quando emite – Esta opção permite que o resultado da conta seja calculado no momento de sua emissão, seguindo a mesma fórmula do cálculo mensal.

 Soma as parcelas por período – Esta opção permite que o resultado da conta seja o somatório dos períodos anteriores.

 Repete o valor da última parcela – Esta opção permite que o resultado da conta seja igual ao último período apurado.

 Calcula quando emite pela fórmula do orçado – Utiliza a mesma lógica da opção Calcula o valor quando emite, porém usa a fórmula do orçado, para calcular o orçado e o realizado.

 Calcula quando emite pela fórmula do realizado – Utiliza a mesma lógica da opção Calcula o valor quando emite, porém usa a fórmula do realizado, para calcular o orçado e o realizado.

 Acumula com o valor do período anterior – Este item permite que o resultado apresentado seja o resultado do saldo atual somado ao saldo do período anterior.

 

Sinal da Conta

Indique o sinal da conta. O sistema considera como padrão, o sinal que foi definido para o grupo de contas orçamentárias, ao qual a conta que está sendo cadastrada foi associada.

Este sinal refere-se à natureza da conta. Toda vez que você consultar (em tela ou relatórios) informações sobre esta conta, o sistema mostrará o sinal negativo, se o saldo da conta for contrário à natureza indicada em seu cadastro.

 

Data Inativa

Informe a data a partir da qual esta conta ficará inativa, de forma a não ser possível efetuar movimentações na mesma. Utilize o botão Calendário.

 

Data Reativação

Indique a data de reativação da conta, se ela tiver permanecido “inativa” por algum tempo.

 

Grupo Orçamentário Inativo?

Selecione este campo, para tornar a(s) conta(s) inativa(s), a partir da data informada. As contas inativas não poderão ser utilizadas.

 

Conta Monetária

Marque este campo, para cadastrar uma conta orçamentária monetária, ou seja, uma conta que deverá ser “convertida” para outra moeda, quando você desejar converter seu orçamento para outra moeda. Exemplo: Despesas com salários.

Se a conta orçamentária não for monetária, ou seja, não deva sofrer conversão (exemplo: número de funcionários do departamento administrativo), desmarque este campo.

 

Transfere Saldos entre Exercícios

Marque este campo, para que o saldo final da conta seja transferido entre exercícios, ou seja, que o saldo inicial de um exercício seja “transportado” para o exercício seguinte.

 

Nas guias abaixo, você deverá indicar os parâmetros da conta orçamentária que está sendo cadastrada. Estes parâmetros estão relacionados ao tipo de cálculo (orçado/realizado), que foi escolhido para a conta em questão.

 

Lembre-se que o sistema só habilitará a inserção de dados, na guia correspondente ao tipo de cálculo escolhido.

 Guia Plano Previdenciário – Selecione o(s) plano(s) previdenciário(s) para o(s) qual(is) deseja criar relacionamento deste Grupo.
