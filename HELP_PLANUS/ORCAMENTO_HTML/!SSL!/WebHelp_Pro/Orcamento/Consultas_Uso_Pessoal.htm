Consultas - Uso Pessoal

Função disponível apenas para os clientes que possuem os sistemas de RH integrados ao sistema Orçamento.

 

Nesta tela o usuário poderá acessar todas as informações referentes ao seu cadastro na empresa.

 

O acesso à tela de consultas de uso pessoal está atrelado ao que o usuário mestre configurou nos Parâmetros do Sistema, do Módulo Básico.

 

Assim, se foi permitido o acesso pela Senha do Usuário, a tela de cadastro do usuário será apresentada automaticamente. Caso o acesso tenha sido permitido Pela Informação de Alguns Dados Pessoais, o sistema apresentará a tela Sua Identificação Pessoal, para que o usuário se identifique pelo preenchimento dos seguintes campos:

 

Sobrenome

Digite seu último nome no cadastro.

 

Matrícula

Digite sua matrícula.

 

CPF

Digite seu CPF (apenas os números).

 

Data de Nascimento

Clique no botão Calendário e informe sua data de nascimento.

 

Estado Civil (S, C, D, V, O)

Digite a letra correspondente ao seu estado civil (Solteiro, Casado, Divorciado, Viúvo ou Outros).

 

Após entrar na tela de Uso Pessoal, o sistema apresentará várias guias.

 

Dependendo da forma e das autorizações  de acesso, o funcionário poderá, nessas guias, alterar alguns dados pessoais, como: endereço, telefone, estado civil, etc. Outras informações estarão disponíveis apenas para consulta, como: cursos, benefícios, prontuários, últimos empregos, etc.
