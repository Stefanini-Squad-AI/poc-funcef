Entrada de Dados - Por Período

Neste item, informe o valor orçado para cada conta orçamentária.

 

Você pode indicar, manualmente, o valor orçado e/ou o valor realizado da conta. Isto depende de como a conta orçamentária foi cadastrada.

 

No cadastro das contas orçamentárias, existem dois campos onde são definidos, respectivamente, o tipo de cálculo do orçado e o tipo de cálculo do realizado.

 

Dentre as opções de cálculo disponíveis no sistema, uma delas é o valor informado manualmente. As contas que foram associadas a este tipo de cálculo, deverão ter o orçamento digitado através do menu Entrada de Dados.

 

Esta categoria de cálculo está presente tanto no cálculo do orçado quanto no do realizado, portanto através deste item, é possível lançar apenas o orçado, apenas o realizado ou ambos.

 

Para fazer a entrada de dados nas contas orçamentárias, siga os procedimentos abaixo:

 

 Informe o exercício, clicando sobre as setas à direita do campo.

 Clique no botão Seleciona, para informar a conta orçamentária cujos valores serão informados.  Atenção:  somente serão mostradas as contas cujo parâmetro para cálculo do orçado/realizado, definido no cadastro da conta, seja Valor Informado Manualmente.

 Indique se a entrada de dados será dos valores orçados, realizados ou de ambos.

 Indique se o valor será indicado por período ou por dia.

 Se você selecionar por período, o valor digitado nos campos Valor Orçado e/ou Valor Realizado, será gravado exatamente como foi digitado.

 Se você selecionar por dia, o valor digitado nos campos Valor Orçado e/ou Valor Realizado, será multiplicado pelo número de dias do período em questão e, desta forma, será gravado.

 Informe o período referente aos dados que serão digitados.

 Digite o valor orçado, realizado ou ambos, dependendo da sua definição anterior.

 O sistema mostrará o Sinal da Conta de acordo com o que foi definido para o grupo de contas orçamentárias, ao qual a conta selecionada foi associada. Este sinal refere-se à natureza da conta.

 Clique no botão Ok, para o sistema efetivar a entrada de dados no período selecionado.

 Repita o passo anterior para os demais períodos do exercício. Observe que o valor digitado no primeiro período, será repetido nos demais períodos. Altere, se for necessário.

 Após fazer a entrada de dados de todos os períodos do exercício selecionado, clique no botão Ok para finalizar. O sistema mostrará uma mensagem, perguntando se deseja-se continuar com a entrada de dados nos períodos do próximo exercício.
