Sistema - Configuração - Parâmetros do Sistema

Você pode configurar o sistema Planejamento e Orçamento, de acordo com suas necessidades de trabalho. Para isso, é necessário que você forneça informações que dependem exclusivamente da forma de operação de sua empresa.

 

A seguir serão explicados todos os parâmetros do sistema, assim como o resultado obtido a partir de cada uma das possibilidades de parametrização.

 

Para alterar os parâmetros do Orçamento, clique no botão Alterar. Assim, você poderá realizar as alterações e atualizações necessárias.
