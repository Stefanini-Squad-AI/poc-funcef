Grupos - Novo

Para cadastrar um grupo de usuários no sistema, clique com o botão direito do mouse e acesse o item Novo ou pressione a tecla Insert.

 

 Preencha os seguintes campos:

 

Nome

Digite o nome do grupo de usuários.

 

Descrição

Digite a descrição do grupo, se houver.

 

Criar/Atualizar como

Clique neste botão, para que todos os direitos de acesso do grupo selecionado sejam replicados ao grupo que está sendo cadastrado.

 

Membros

Indique os usuários que pertencem a este grupo.

 

 Selecione o usuário, na listagem Não Membros.

 Clique no botão Associa.

 

Botão Direitos

Clique neste botão, para consultar e/ou editar os Direitos do Grupo.

 

 Clique com o mouse no botão Ok ou pressione a tecla Enter.
