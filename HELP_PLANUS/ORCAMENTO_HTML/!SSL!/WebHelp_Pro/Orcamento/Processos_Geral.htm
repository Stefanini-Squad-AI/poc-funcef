Processos - Geral

Processos são movimentações realizadas utilizando-se o saldo orçado para as contas.  Podem ser Reservas, Compromissos, Transferências, Suplementações ou Deduções Orçamentárias.  São sensibilizados, principalmente, pelas despesas administrativas ocorridas na empresa.

 

Alguns parâmetros do sistema têm influência direta sobre o tratamento de processos.  Para conhecê-los melhor consulte Parâmetros do Sistema - Guia Geral.

 

No cadastro de Tipo de Desembolso existe um parâmetro chamado "Obriga indicação de compromisso orçamentário".  Caso o mesmo esteja marcado, no sistema Contas a Pagar, ao apropriarmos uma despesa utilizando-se um desses Tipos de Desembolso, no rateio do documento será necessário indicar um compromisso orçamentário.

 

Respeitando-se o parâmetro do Tipo de Desembolso, no sistemas Compras, ao se fazer uma Solicitação de Compras e/ou Investimentos (SCI), faz-se necessário indicar o número de uma Reserva Orçamentária criada previamente no sistema Planejamento e Orçamento, o que significa que, só poderemos prever uma despesa se tivermos saldo para a mesma e, portanto, devemos comprometer a verba sempre que necessário.  No mesmo sistema, ao gerarmos uma Ordem de Compras (OC), o sistema criará automaticamente, no sistema Planejamento e Orçamento, um Compromisso Orçamentário, efetivando a reserva criada anteriormente e, garantindo que a partir desse momento, a verba orçada estará efetivamente comprometida.  No sistema Almoxarifado, no recebimento da mercadoria, deveremos indicar o número do compromisso criado pelo sistema de Compras, efetivando o mesmo pelo recebimento da mercadoria.
