Guia - Detalhe

Nesta guia, preencha os seguintes campos:

 

Número Linha

O número da linha será sugerido pelo sistema, de acordo com o valor que foi definido no campo Número de Incrementos. Para cadastrar uma linha entre as linhas já cadastradas, digite o número da linha que você deseja inserir, no relatório demonstrativo.

 

Separador das Linhas

Informe o tipo de separador das linhas, ou seja, indique como o sistema irá separar a linha que está sendo cadastrada da linha anterior.

Existem quatro opções:

 Com espaçamento entre as linhas.

 Desenha uma linha fina.

 Desenha uma linha grossa.

 Desenha uma linha dupla.

 

Indentação

Indique o nível de Indentação da linha. Este campo define a tabulação das linhas. Clique na seta à direita do campo, para visualizar as indentações possíveis.

 

Código da Conta

Clique no botão Seleciona, para informar a conta orçamentária que fará parte do relatório.

 

Conta para 100%

Utilize este campo, para indicar uma conta que será utilizada para cálculo de proporcionalidade. Por exemplo: contas A + B + C + D = F. Assim, a conta de 100% para as contas A, B, C e D é a conta F.  Essa conta será considerada para efeito de análise vertical da coluna do relatório.

 

 

Essa operação deverá ser repetida até terem sido incluídas todas as linhas do relatório.
