Sistema - Fluxo de Operação

Através do item Fluxo de Operação, é possível definir uma rotina de abertura de telas que facilitará a execução de suas tarefas diárias.

 

Clicando no subitem Montar, o usuário cria um fluxo de operação seqüencial. Para executá-lo, você deve clicar no subitem Executar (somente serão abertas as telas do sistema definidas na montagem).

 

O Fluxo de Operação obriga que o usuário percorra todas as telas do fluxo montado, uma vez que sua navegação se dá, necessariamente, pelos botões Anterior e Seguinte.
