Entrada de Dados - Diária

Neste item, informe o valor orçado para cada dia.

 

Quando a entrada de dados é feita por período, o sistema divide o valor orçado pelo número de dias do período e calcula o valor orçado diariamente, igual para todos os dias do período.

 

Este tipo de entrada de dados só deverá ser utilizado, se você quiser estipular valores diferentes para cada dia , ou seja, fazer um orçamento mais detalhado do que o orçamento por período.

 

 Informe o exercício, clicando sobre as setas à direita do campo.

 Selecione a data da entrada dos dados, clicando no botão Calendário.

 Clique no botão Seleciona, para informar a conta orçamentária cujos valores serão informados.

 O campo Nome da Conta Orçamentária será preenchido automaticamente.

 Digite o valor orçado e realizado.

 Clique no botão Ok, para o sistema efetivar a entrada de dados diária.

 Repita os passos anteriores para o próximo dia.
