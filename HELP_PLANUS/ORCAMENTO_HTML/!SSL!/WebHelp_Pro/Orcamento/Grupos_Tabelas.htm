Grupos - Tabelas

O item Tabelas foi elaborado para que você possa controlar o acesso do grupo às informações do sistema (banco de dados).

 

Através dele, faça a definição das tabelas e campos que o grupo poderá utilizar nas consultas do Gerador de Relatórios.

 

Exemplo: Se você especificar a tabela Cotacoes do sistema Compras para um determinado grupo, este grupo só poderá criar consultas utilizando a tabela Cotacoes.

 

Para acessá-lo, clique com o botão direito do mouse e acesse o item Tabelas ou pressione as teclas de atalho Ctrl+T.

 

Para especificar as tabelas:

 

 Selecione a tabela, na listagem Não Selecionados, à direita da tela.

 Clique no botão Associa.

 

Para especificar os campos:

 

 Selecione a tabela cujos campos você deseja associar.

 Clique no botão Colunas.

 Selecione o campo, na listagem Não Selecionados.

 Clique no botão Ok ou pressione a tecla Enter, para confirmar a associação.

 

Obs.: Se nenhuma tabela for especificada, o grupo terá direito de utilizar todas as tabelas do banco.
