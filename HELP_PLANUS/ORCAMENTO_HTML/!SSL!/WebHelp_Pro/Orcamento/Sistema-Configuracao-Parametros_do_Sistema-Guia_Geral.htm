Sistema - Configuração - Parâmetros do Sistema - Guia Geral

Preencha os seguintes parâmetros:

 

Moeda para Cadastro do Orçamento

Informe em qual índice ou moeda seu orçamento será cadastrado. Esta moeda deverá ter sido, previamente, cadastrada no sistema GlobalCM.

 

Plano Orçamentário

Selecione o plano orçamentário que será utilizado pela sua empresa. Cadastre os planos orçamentários no item Cadastros – Plano Orçamentário.

 

Máscara dos Grupos Orçamentários

Campo preenchido automaticamente pelo sistema a partir do Plano Orçamentário indicado anteriormente.  Esta máscara será a estrutura hierárquica, na qual serão inseridos os grupos de contas orçamentárias.

 

Tratamento do Saldo para Processos

São considerados processos: Reserva, Compromisso, Transferência, Dedução e Suplementação Orçamentária.

No cadastramento da rubrica (conta) orçamentária é informado o "tipo de cálculo para o orçado" da conta.  Para as contas cujo tipo de cálculo seja "Valor Informado Manualmente", posteriormente será necessário fazer o "input" das dotações orçamentárias.  Para maiores informações consulte o ítem Entrada de Dados.  

A partir do "input" das dotações orçamentárias, o que é feito para cada período do exercício, os saldos das rubricas começam a ser sensibilizados pelos processos (reserva, compromisso, transferência, dedução e suplementação) feitos.  

Entenda, a seguir, como o parâmetro aqui escolhido altera a forma como o sistema controla o saldo das rubricas.

 Por Período – Nesse caso, para efeito de processos, o sistema considera apenas o valor orçado para o período.  O saldo será tratado como na coluna "Por Período" da tabela acima.  Se o saldo disponível não for utilizado integralmente em um período, não poderá mais ser utilizado nos períodos subsequentes.

 

 Acumulado do Exercício – Nesse caso, para efeito de processos, o sistema considera o valor orçado acumulado do exercício.  O saldo será tratado como na coluna "Acumulado do Exercício" da tabela acima.  O saldo total disponível para o exercício poderá ser utilizado integralmente em qualquer período, porém, feito isso, não restará saldo para processos nos períodos subsequentes.

 

 Acumulado até o período – Nesse caso, para efeito de processos, o sistema considera o valor orçado acumulado até o período.  O saldo será tratado como na coluna "Acumulado até o Período" da tabela acima.  Se o saldo disponível não for utilizado integralmente em um período, poderá ser utilizado nos períodos subsequentes até o limite acumulado do período em questão.

 

Permite processos com valores acima do saldo

Se este parâmetro estiver marcado, será possível comprometer o orçamento com processos maiores do que o saldo disponível para as rubricas. Caso contrário, não será possível comprometer verba além da que foi orçada.

 

Permite transferências entre contas orçamentárias de grupos diferentes

Selecione este campo, para que sejam permitidas transferências entre contas orçamentárias de diferentes grupos. As transferências orçamentárias permitem migrar saldos de contas orçamentárias, que possuem saldo disponível, para aquelas onde há maior necessidade. Se este parâmetro não estiver marcado, o sistema só permitirá transferências orçamentárias entre contas do mesmo grupo.
