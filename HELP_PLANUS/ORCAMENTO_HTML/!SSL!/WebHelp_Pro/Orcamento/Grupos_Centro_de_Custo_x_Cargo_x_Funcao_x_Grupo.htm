Grupos - Centro de Custo x Cargo x Função x Grupo

Através deste item, faça o controle de acesso dos funcionários por cargo, função, centro de custo e grupo de usuários.

 

Esse controle é feito a partir do cadastro de grupos, que valida os direitos a serem atribuídos a cada usuário, desde que ele seja um funcionário.

 

Para acessá-lo, clique com o botão direito do mouse e acesse o item Centro de Custo x Cargo x Função x Grupo ou pressione as teclas de atalho Ctrl+F.

 

 Indique o centro de custo desejado, clicando na seta à direita do campo.

 Selecione o cargo.

 Informe a função.

 No campo Grupos, dê um duplo clique naqueles que terão seus acessos limitados.

 Clique no botão Ok, para o sistema validar o controle de acesso.
