Sistema - Alterar Senha

O item de menu Alterar Senha permite que o usuário altere sua senha para entrar no sistema, se necessário.

 

Toda vez que um novo usuário for cadastrado no sistema, é recomendado que se faça um login.

 

Ao executar o login, o usuário deve alterar a senha, já que a atual é a senha gerada pelo sistema e é utilizada toda vez que um usuário é cadastrado.

 

 Para alterá-la, digite a senha atual.

 Pressione a tecla Tab para o cursor ir ao próximo campo.

 Digite a nova senha.

 Pressione novamente a tecla Tab e digite a nova senha para confirmação.

 

Obs.: Configure o tamanho (número mínimo de dígitos) e a composição (letras e/ou números) da senha, nos parâmetros do sistema GlobalCM.
