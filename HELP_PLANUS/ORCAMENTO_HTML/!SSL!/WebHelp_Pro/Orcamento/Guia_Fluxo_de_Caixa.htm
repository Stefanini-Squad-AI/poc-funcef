Guia - Fluxo de Caixa

Nesta guia, faça a definição dos tipos de desembolsos/recebimentos que compõem a conta orçamentária que está sendo cadastrada. Esta guia só estará disponível, se o tipo de cálculo do realizado for fluxo de caixa. Esta categoria de cálculo está presente apenas no tipo realizado.

 

Poderá ser indicado apenas o tipo de desembolso/recebimento desejado. Neste caso, o sistema “buscará” todos os lançamentos do tipo de desembolso/recebimento selecionado, independente da Atividade/Projeto, Centro de Responsabilidade, Centro de Custo, Patrocinadora e Plano Previdenciário que tenham sido utilizadas no lançamento.

 

Se for indicado um tipo de desembolso/recebimento em conjunto com qualquer outra estrutura, o sistema “buscará” do Financeiro, os lançamentos feitos para o tipo de desembolso/recebimento e para as demais estruturas cadastradas.

 

A conta orçamentária pode ser formada por vários tipos de desembolso/recebimento. Para isso, inclua várias linhas nesta guia, uma para cada tipo de desembolso/recebimento desejado.

 

Nesta guia, preencha os seguintes campos:

 

Atividade

Selecione a atividade/projeto desejada. Se você não indicá-la, o sistema buscará todos os lançamentos do tipo de desembolso/recebimento. Se você indicar uma atividade/projeto específica, o sistema só buscará os lançamentos do tipo de desembolso/recebimento selecionado, que estiverem associados à atividade/projeto indicada neste campo.

 

Centro de Responsabilidade

Selecione o centro de responsabilidade desejado. Se você não indicá-lo, o sistema buscará todos os lançamentos do tipo de desembolso/recebimento. Se você indicar um centro de responsabilidade específico, o sistema só buscará os lançamentos do tipo de desembolso/recebimento selecionado, que estiverem associados ao centro de responsabilidade indicado.

 

Tipo de Recebimento/Desembolso

Clique na seta à direita do campo, para informar o tipo de desembolso/recebimento cujos lançamentos formarão o valor realizado, da conta orçamentária.

 

Centro de Custo

Selecione o centro de custo desejado. Se você não indicá-lo, o sistema buscará todos os lançamentos do tipo de desembolso/recebimento. Se você indicar um centro de custo específico, o sistema só buscará os lançamentos do tipo de desembolso/recebimento selecionado, que estiverem associados ao centro de custo indicado.

 

Patrocinadora

Selecione a patrocinadora desejada. Se você não indicá-la, o sistema buscará todos os lançamentos do tipo de desembolso/recebimento. Se você indicar uma patrocinadora específica, o sistema só buscará os lançamentos do tipo de desembolso/recebimento selecionado, que estiverem associados à patrocinadora indicada.

 

Plano

Selecione o plano previdenciário desejado. Se você não indicá-lo, o sistema buscará todos os lançamentos do tipo de desembolso/recebimento. Se você indicar um plano previdenciário específico, o sistema só buscará os lançamentos do tipo de desembolso/recebimento selecionado, que estiverem associados ao plano previdenciário indicado.

 

A conta orçamentária pode ser formada por vários tipos de desembolso/recebimento, Atividade/Projeto, Centro de Responsabilidade, Centro de Custo, Patrocinadora e Plano Previdenciário. Para isso, inclua várias linhas nesta guia, uma para cada combinação das estruturas que se deseja que façam parte do cálculo do valor realizado, da conta orçamentária que está sendo cadastrada.
