Guia - Valor Fixo Informado

Nesta guia, estabeleça um valor fixo para o realizado e/ou para o orçado, da conta orçamentária que está sendo cadastrada. Esta guia só estará disponível, se o tipo de cálculo do realizado ou do orçado for “valor fixo informado”.

 

Preencha os seguintes campos:

 

Realizado

Digite o valor fixo da conta orçamentária para o realizado. Nesta categoria de cálculo, o valor da conta é fixado, previamente, e será repetido para todas as gerações de dados subseqüentes. Utilize este cálculo, para contas orçamentárias que guardam valores constantes ou que raramente variam.

 

Ex.: Número de metros quadrados de um prédio, que usado em conjunto com o valor do aluguel por metro quadrado, daria o valor do aluguel.

 

Orçado

Digite o valor fixo da conta orçamentária no orçado. Nesta categoria de cálculo, o valor da conta é fixado, previamente, e será repetido para todas as gerações de dados subseqüentes. Utilize este cálculo para contas orçamentárias que guardam valores constantes ou que raramente variam.

 

Geração de Dados

Informe se a geração de dados será por período ou por dia. Se você indicar “por período”, o sistema considera que o valor indicado nos campos anteriores refere-se ao total do período. Se você indicar “diário”, o sistema multiplicará o valor indicado nos campos anteriores pelo número de dias do período, para calcular o valor orçado e/ou realizado da conta em questão.
