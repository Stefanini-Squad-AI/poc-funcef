Usuários - Atualização de E-mail

Neste item, faça a inclusão/alteração dos e-mails dos usuários.

 

Para acessá-lo, primeiramente selecione o usuário desejado.

 

Clique com o botão direito do mouse e acesse o item Atualização de e-mail ou pressione as teclas de atalho Ctrl+E.

Digite o e-mail do usuário.

Clique com o mouse no botão Ok ou pressione a tecla Enter, para confirmar.
