Sistema - Utilitários - Correio CM - Opções

Através deste subitem, configure o recebimento de mensagens nos sistemas CMNet.

 

Indique o tipo de verificação de mensagens que será utilizado toda vez que houver um login no sistema.

 

Parâmetros:

 

Sempre verificar e exibir a tela de mensagens se houver novas

Marque este campo, para que logo após o login, o sistema verifique se há novas mensagens e, caso existam, a tela do correio CM seja mostrada.

 

Sempre verificar e informar se houver novas

Selecione este campo, para que logo após o login, o sistema verifique se há novas mensagens e, caso existam, uma mensagem de aviso seja mostrada.

 

Nunca verificar e sempre exibir a tela de mensagens

Marque este campo, para que não seja verificada a existência de novas mensagens logo após o login e que a tela do correio CM sempre seja mostrada.

 

Nunca verificar

Marque este campo, para que não haja verificação de mensagens na entrada do sistema.

 

Habilita verificação automática de mensagens a cada

Indique o período de tempo (em minutos), que o sistema utilizará para detectar as novas mensagens.
