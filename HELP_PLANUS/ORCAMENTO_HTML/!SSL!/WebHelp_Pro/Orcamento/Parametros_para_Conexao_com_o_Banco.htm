Parâmetros para Conexão com o Banco

Nesta opção, configure os parâmetros para conexão do Planejamento e Orçamento com o banco de dados:

 

Alias - Localização do banco de dados na rede

 Clique com o mouse sobre a opção Alias.

 Digite o alias na caixa de texto à direita.

 

Driver - Tipo do banco de dados, com o qual você conecta o sistema

 Informe o tipo do banco, clicando sobre o círculo ao lado do tipo desejado.

 

Nome do Servidor ou DSN ODBC

 Digite o nome do servidor de banco de dados ou do DSN ODBC.

 

Tipo de Conexão - Tipo de conexão que é utilizado com o banco de dados

 Informe o tipo de conexão, clicando sobre o círculo ao lado do tipo desejado.

 

Obs.: Se você não tiver conhecimento sobre essas informações, consulte o administrador de rede da sua empresa.
