Fluxo de Operação - Montar

No subitem Montar, determine a seqüência de telas necessárias às rotinas do seu trabalho.

 

Clique no botão Inserir e preencha o seguinte campo:

 

Descrição do Fluxo de Operação

Digite o nome da operação que deseja criar. Esse nome será utilizado para selecionar o fluxo que será executado. É permitido criar várias seqüências de execução para o seu trabalho, salvando cada qual com um nome específico.
