Lista Mensagens - Guia Caixa de Entrada

Nesta guia são mostradas todas as mensagens recebidas pelo usuário logado no sistema.

 

As mensagens que aparecem em cor amarela, na caixa de listagem à esquerda da tela, ainda não foram lidas. Para ler seu conteúdo, basta selecionar a mensagem desejada.

 

 Clique nos botões Próximo e Anterior, para navegar pelas mensagens recebidas.

 Para responder a uma mensagem, faça sua seleção e clique no botão Responder.

 Clique no botão Lida, para que a mensagem recebida não seja mais exibida no próximo acesso ao sistema.

 Utilize o botão Não Lida, para que a mensagem recebida volte a ser exibida na entrada do sistema.

 Clique no botão Atualizar, para atualizar a caixa de entrada.

 Para imprimir uma mensagem, clique no botão Imprimir.

 Clique no botão Excluir, para apagar a mensagem selecionada.
