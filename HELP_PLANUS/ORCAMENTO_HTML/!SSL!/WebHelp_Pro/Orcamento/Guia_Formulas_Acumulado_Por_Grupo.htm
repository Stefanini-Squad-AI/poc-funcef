Guia - Fórmulas/Acumulado

Nesta guia, indique a fórmula que será usada no cálculo do valor do Grupo (conta) orçamentário. Esta guia só estará disponível, se o tipo de cálculo do realizado ou do orçado for “fórmula” ou “valor acumulado”.

 

O valor do Grupo será obtido, através de uma fórmula que pode compor outros Grupos orçamentários e constantes numéricas.

 

Exemplo:

 

O valor do Grupo orçamentário 05.01 é obtido pela soma entre os Grupos orçamentários 05.02 e 05.03, dividido por 100. A fórmula resultante seria: (G0502 + G0503) / 100.

 

Sintaxe da Fórmula: Indique um “G” antes de um número, que seja referente a um Grupo orçamentário, ou seja, sempre que você quiser indicar na fórmula um Grupo orçamentário, indique “G” + o número do Grupo.

 

Fórmula do Orçado

Clique no botão Seleciona, para indicar um Grupo para compor a fórmula do orçado. Lembre-se de usar a letra G, antes do número do Grupo orçamentário que compõe a fórmula. Este campo só será habilitado, se o “tipo de cálculo do orçado” for “fórmula” ou “valor acumulado”.

 

Fórmula do Realizado

Clique no botão Seleciona, para indicar um Grupo para compor a fórmula do realizado. Lembre-se de usar a letra G, antes do número do Grupo orçamentário que compõe a fórmula. Este campo só será habilitado, se o “tipo de cálculo do realizado” for “fórmula” ou “valor acumulado”.
