Guia - Arquivos Genéricos

Nesta guia, efetue a integração entre uma conta orçamentária e qualquer outro sistema da Solução Integrada, através de consultas feitas diretamente no banco de dados. Esta guia só estará disponível, se o “tipo de cálculo do realizado” for “arquivos genéricos”.

 

Para fazer estas querys (consultas no banco de dados), você deverá conhecer, mesmo que superficialmente, comandos SQL. As variáveis DATA e VALOR são obrigatórias e deverão ser utilizadas exatamente nesta ordem.

 

Para obter os valores de um dia específico (geração de dados diária):

 

SELECT SUM(LACVALOR) AS VALOR

FROM LANCAMENTO L, PLANILHA P

WHERE P.PLNCODIGO = L.PLNCODIGO

AND P.PLNDATDIA = :DATA

 

Para obter os valores por período (geração de dados por período):

 

SELECT SUM(LACVALOR) AS VALOR

FROM LANCAMENTO L, PLANILHA P

WHERE P.PLNCODIGO = L.PLNCODIGO

AND TO_CHAR(P.PLNDATDIA, 'YYYYMM' ) = :DATA

 

Certifique-se de manter o parâmetro :DATA como o tipo data ou realizar a conversão para caracter, de acordo com o demonstrado no segundo exemplo. Qualquer outra forma de estabelecer os parâmetros pode causar erros ou não trazer os valores desejados durante a geração dos dados.

 

O Planejamento e Orçamento realizará uma consulta ao banco de dados, que ficará arquivada para a conta orçamentária que está sendo cadastrada.
