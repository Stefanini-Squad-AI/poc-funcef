Utilizando o Teclado ou o Mouse

TECLAS

AÇÃO

Tab

Avança o cursor para o campo/botão seguinte dentro de uma tela.

Shift + Tab

Retorna o cursor para o campo anterior de uma ficha ou de uma tabela. Retorna o cursor para o botão anterior dentro de uma ficha.

Delete

Apaga um caracter à direita do cursor dentro de um campo. Se o conteúdo estiver todo selecionado (em preto), apaga todo o conteúdo do campo.

Ctrl + Delete

Apaga o conteúdo de um campo editável ou de uma linha inteira da tabela.

Backspace

Apaga o caracter à esquerda do cursor.

Em campos editáveis, avança o cursor um caracter para à direita. Em tabelas, avança uma célula para à direita.

Em campos editáveis, avança o cursor um caracter para à esquerda. Em tabelas, retorna uma célula à esquerda.

Em campos editáveis, sobe o cursor para a linha imediatamente acima. Em tabelas, sobe uma linha na mesma coluna.

Em campos editáveis, desce o cursor para a linha imediatamente abaixo. Em tabelas, desce uma linha na mesma coluna.

Shift +

Em campos editáveis, avança o cursor à direita, selecionando-o. Em tabelas, avança uma célula para à direita.

Shift +

 Em campos editáveis, retorna o cursor um caracter para à esquerda, selecionando-o. Em tabelas, retorna uma célula para à esquerda.

Shift +

Em campos editáveis, avança uma linha acima, selecionando-a. Em tabelas, avança uma célula acima, selecionando-a.

Shift +

 Em campos editáveis, avança uma linha abaixo, selecionando-a. Em tabelas, avança uma célula abaixo, selecionando-a.

Ctrl +

Em campos editáveis, avança o cursor uma palavra para à direita. Em tabelas, salta para a última coluna à direita.

Ctrl +

Em campos editáveis, avança o cursor uma palavra para à esquerda. Em tabelas, salta para a última coluna à esquerda.

Ctrl +

Em campos editáveis, avança o cursor uma célula para à direita, percorrendo todas as células . Em tabelas, salta para a última linha na mesma coluna.

Ctrl +

 Em campos editáveis, avança o cursor uma célula para à direita, percorrendo todas as células . Em tabelas, salta para a última linha na mesma coluna.

Ctrl + Shift +

Em campos editáveis, avança o cursor uma palavra para à direita, selecionando-a. Em tabelas, salta para a última coluna à direita.

Ctrl + Shift +

Em campos editáveis, avança o cursor uma palavra para à esquerda, selecionando-a. Em tabelas, salta para a última coluna à esquerda.

Ctrl + Shift +

Em campos editáveis, avança o cursor uma palavra para à esquerda, selecionando-a. Em tabelas, salta para a última linha da mesma coluna.

Ctrl + Shift +

 Em campos editáveis, avança o cursor uma palavra para à direita, selecionando-a. Em tabelas, salta para a primeira linha da mesma coluna.

Home

Em campos editáveis, avança o cursor para o início do texto. Em tabelas, salta para a primeira coluna à esquerda.

End

 Em campos editáveis, avança o cursor para o fim do texto. Em tabelas, salta para a última coluna à direita.

Ctrl + Home

Em tabelas, salta para a primeira linha na mesma coluna.

Ctrl +End

Em tabelas, salta para a última linha na mesma coluna.

Insert

Em tabelas, abre uma nova linha em branco para preenchimento, acima da linha atual.

F1

Chama a ajuda de contexto relativa à tela onde se encontra o cursor.

Alt + F4

Sai do sistema.
