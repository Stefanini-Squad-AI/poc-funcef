Cadastros - Grupo de Contas Orçamentárias

Neste item, cadastre os Grupos de Contas Orçamentárias.

 

Esses grupos existem para permitir o agrupamento das contas orçamentárias numa mesma estrutura hierárquica, permitindo a vizualização das mesmas em conjunto, o que facilita o uso gerencial e operacional do sistema.

 

Os grupos de contas orçamentárias serão cadastrados seguindo a estrutura hierárquica (máscara), que foi previamente definida em Cadastros - Plano Orçamentário, portanto poderão existir grupos sintéticos e analíticos.

 

Ao cadastrar uma conta orçamentária, será necessário associá-la a um grupo de contas orçamentárias analítico, previamente, cadastrado nesta opção.

 

Para cadastrar os grupos de contas orçamentárias, clique no botão Inserir e preencha os seguintes campos:

 

Código

Digite o código do grupo. Um grupo de contas pode ser dividido em vários subgrupos. Isto dependerá da máscara (estrutura hierárquica) que foi definida no parâmetro do sistema.

 

Descrição

Digite o nome do grupo ou subgrupo de contas orçamentárias.

 

Botões Analítico e Sintético

Informe o grau do grupo de contas orçamentárias. Se você cadastrar um código de grupo de contas que ocupe menos graus do que o tamanho máximo permitido pela máscara, o sistema irá sugerir sintético. Se o código ocupar toda a estrutura, o sistema irá sugerir analítico.

 

Sinal do Grupo

Indique o sinal do grupo. Este sinal refere-se à natureza da conta. Toda vez que você consultar (em tela ou relatórios) informações sobre contas deste grupo, o sistema mostrará o sinal negativo, se o valor da conta for contrário à natureza indicada no grupo da conta.

 

Grupo refere-se a Contas de Resultado

Marque este campo, para Indicar que o grupo se refere a contas orçamentárias de despesas e receitas. O sistema utiliza este campo para simular uma apuração de resultado, no subitem Sistema – Utilitários – Busca Dados Contábeis para Orçamento.

 

Fórmula de Apuração

Indique uma fórmula para apuração do orçado do exercício seguinte, baseado no realizado do exercício atual, através do ítem Entrada de Dados - Execução de Fórmulas de Apuração.
