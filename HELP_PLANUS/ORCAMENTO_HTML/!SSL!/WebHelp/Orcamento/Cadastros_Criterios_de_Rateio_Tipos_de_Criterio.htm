Cadastros - Critérios de Rateio - Tipos de Critério

Para cadastrar os critérios de rateio, clique no botão Inserir e preencha os seguintes campos:

 

Descrição

Digite o nome do critério.

Exemplo: Número de Funcionários.

 

Tipo de Rateio

Indique o tipo de rateio desejado.

 Pré-Definido – O sistema utilizará um critério pré-definido em Cadastros - Critérios de Rateio - Valores Base para Rateio.

 Gerados a partir de pesquisa na base – O sistema fará uma pesquisa na base (query), que servirá para determinar os valores (percentuais) do rateio.

 

Botão Clique para Exemplo de Pesquisa

Clique neste botão, para visualizar dois exemplos de querys que servirão para pesquisa na base de dados. O primeiro exemplo busca no banco de dados, o número de funcionários alocados em cada centro de custo. O segundo busca do banco de dados, o valor dos documentos lançados no Contas a Pagar, em cada centro de custo. Este botão só será habilitado, se o tipo de rateio for “Gerados a partir de pesquisa na base”.

 

Botão Copia Exemplo 1

Este botão copiará o primeiro exemplo, que busca no banco de dados o número de funcionários alocados em cada centro de custo, para o campo Pesquisa.

 

Botão Copia Exemplo 2

Este botão copiará o segundo exemplo, que busca no banco de dados o valor dos documentos lançados no Contas a Pagar, em cada centro de custo, para o campo Pesquisa.

 

Período de Referência

Indique o exercício e o período de referência do tipo de rateio.

 

Pesquisa

Se você clicou no botão Copia Exemplo 1 ou no botão Copia Exemplo 2, o sistema preencherá este campo. Caso contrário, você poderá montar sua própria query (consulta ao banco de dados). Neste caso, a pesquisa no banco de dados deve conter somente um campo, que deverá se chamar Valor e este deverá ser único para cada centro de custo. É obrigatório indicar 2 parâmetros: CODCENTROCUSTO e IDEMPRESA. O parâmetro de data também poderá ser utilizado: DATA, para data completa ou ANOMES, para utilizar o mês/ano no formato AAAAMM.
