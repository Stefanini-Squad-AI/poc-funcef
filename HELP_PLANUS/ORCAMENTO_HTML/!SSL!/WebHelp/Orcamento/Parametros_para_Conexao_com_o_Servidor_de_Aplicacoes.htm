Parâmetros para Conexão com o Servidor de Aplicações

Nesta opção, configure os parâmetros referentes à forma e ao meio pelo qual a sua aplicação acessa o servidor de aplicações.

 

Forma de Conexão

 Indique como é a conexão com o servidor de aplicações. Se a conexão for remota, indique o meio de conexão.

 

Meio de Conexão

 Informe o meio, clicando no círculo ao lado do meio de conexão desejado.

 

Redirecionamento de Conexão

Indique o número de conexões simultâneas que cada servidor suporta para a aplicação ou o percentual de memória mínima disponível, no momento da conexão.

 

Número de Conexões

Nesta verificação, informe quantas tentativas de conexão de uma aplicação-cliente serão realizadas no servidor, antes do redirecionamento para outro servidor.

 

% Memória Livre

Indique o percentual de memória livre da aplicação servidora.

Ex.: Se você indicar 30, as conexões serão redirecionadas no momento da conexão, se o percentual de memória livre no servidor de aplicações for menor ou igual a 30%.

 

Obs.: Antes de constatar a disponibilidade de acesso, é verificada a compatibilidade de versão entre a aplicação-cliente e a aplicação-servidora.
