Usuários - Propriedades

Para consultar e/ou alterar as propriedades de um usuário, primeiramente selecione o usuário desejado.

 

 Clique com o botão direito do mouse e acesse o item Propriedades ou pressione a tecla Enter.

 Realize a consulta/alteração necessária.

 Clique com o mouse no botão Ok ou pressione a tecla Enter.
