Consultas - Relatórios - Configuráveis - Demonstrativo - Colunado Diário

Através deste relatório, faça a impressão do demonstrativo colunado - diário.

 

Ele pode ser impresso, de acordo com a definição dos filtros de seleção:

 

Data

Clique no botão Calendário, para indicar a data do demonstrativo.

 

Relatório

Clique na seta à direita do campo, para selecionar o relatório desejado.

 

Layout

Indique se o layout do demonstrativo será fixo ou livre (configurável).

 

Layout Orçamentário

Informe o layout do demonstrativo orçamentário.

 

Tipo do Layout

Indique o tipo de layout do demonstrativo.

 

Imprimir Linhas com Valores Zerados

Marque este campo, para que as linhas com valores zerados sejam mostradas no demonstrativo.

 

Após definir os filtros de seleção, clique no botão Ok.

 

Obs.: Repita este processo toda vez que você quiser definir outro relatório.
