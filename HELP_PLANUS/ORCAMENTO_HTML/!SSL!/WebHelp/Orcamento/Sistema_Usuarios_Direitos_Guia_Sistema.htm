Direitos - Guia Sistema

Nesta guia, configure o acesso do usuário aos itens do sistema.

 

 Para visualizar todos os itens possíveis, clique no botão Expandir Árvore.

 Posicione, com o ponteiro do mouse, a barra azul sobre o item a ser selecionado e tecle a Barra de Espaços ou dê um clique na caixa de seleção do item desejado.

 Para selecionar todas as autorizações de acesso simultaneamente, clique no botão Marcar Todas.

 Utilize o botão Inverter Seleção, para que o sistema inverta a seleção atual.

 Clique no botão Fechar Árvore, para comprimir a árvore de autorizações.
