Consultas - Relatórios - Configuráveis - Demonstrativo - Elementos - Coluna x Linha

Através deste relatório, faça a impressão do demonstrativo de elementos com coluna x linha.

 

Ele pode ser impresso, de acordo com a definição dos filtros de seleção:

 

Demonstrativo

Indique o modelo de demonstrativo que será utilizado para compor o relatório.

 

Exercício

Selecione o exercício desejado, clicando na seta à direita do campo.

 

Período

Indique o período do demonstrativo orçamentário.

 

Após definir os filtros de seleção, clique no botão Ok.

 

Obs.: Repita este processo toda vez que você quiser definir outro relatório.
