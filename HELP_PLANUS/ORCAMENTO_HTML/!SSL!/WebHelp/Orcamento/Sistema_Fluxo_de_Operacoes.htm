Sistema - Fluxo de Operações

Através do item Fluxo de Relatórios, você pode definir uma ordem de abertura de relatórios para otimizar, como por exemplo, a rotina de impressão de relatórios do fechamento.

 

Clicando no subitem Montar, você cria um fluxo de relatórios seqüencial. Para executá-lo, você deve clicar no subitem Executar (somente serão abertos os relatórios do sistema definidos na montagem).
