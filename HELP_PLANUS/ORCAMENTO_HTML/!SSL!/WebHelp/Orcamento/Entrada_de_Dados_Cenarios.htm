Cenários - Entrada de Dados

Neste item, informe o valor orçado para cada cenário cadastrado no sistema. Os cenários são cadastrados através do item Cenários - Cadastro.

 

 Informe o Exercício, clicando sobre as setas à direita do campo.

 Clique na seta à direita do campo Cenário, para selecionar o cenário desejado.

 Clique no botão Seleciona, para informar o Código da Conta orçamentária cujos valores serão informados.

 Indique o período da entrada de dados do cenário.

 Digite o valor orçado.

 Indique o sinal da conta. O sistema considera como padrão, o sinal que foi definido para o grupo de contas orçamentárias, ao qual a conta selecionada foi associada. Este sinal refere-se à natureza da conta.

 Clique no botão Ok, para o sistema efetivar a entrada de dados do cenário.
