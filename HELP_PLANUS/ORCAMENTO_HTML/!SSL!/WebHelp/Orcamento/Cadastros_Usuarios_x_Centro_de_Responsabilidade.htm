Cadastros - Usuários x Centro de Responsabilidade

Neste item, associe os usuários com os respectivos centros de responsabilidade.

 

No cadastro das contas orçamentárias, cada conta é relacionada a um centro de responsabilidade, que será o responsável pelo orçamento desta conta.

 

Esta correlação entre usuários e centros de responsabilidade é importante, para que se possa definir quais são os centros de responsabilidade que o usuário pode manipular.

 

O sistema só permitirá que o usuário faça o orçamento das contas, que estiverem relacionadas a centros de responsabilidade habilitados para o mesmo.

 

 Para fazer a associação entre usuários e centros de responsabilidade, clique no botão Procurar, para selecionar o usuário.

 Clique no botão Alterar, para efetuar as associações necessárias.

 Utilize o botão Adiciona, para associar o centro de responsabilidade selecionado ao usuário.

 Para associar todos os centros de responsabilidade de uma só vez, clique no botão Adiciona Todos.

 Clique no botão Remove, para desfazer a associação do centro de responsabilidade selecionado.

 Utilize o botão Remove Todos, para excluir todas as associações de centros de responsabilidade do usuário em questão.

 Clique no botão Ok, para confirmar as associações.
