Sistema - Usuários

Através deste item, o sistema permite cadastrar os usuários do sistema, juntamente com seus respectivos direitos de acesso.

 

Para efetuar a manutenção dos usuários do sistema, siga as instruções a seguir:

 

 Clique com o botão esquerdo do mouse sobre a tela.

 Acesse os itens do menu, clicando como o botão direito do mouse ou, simplesmente, pressionando as teclas de atalho.
