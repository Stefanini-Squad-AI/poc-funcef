Processos - Encerramento do Exercício

Neste item, faça o encerramento do exercício, para que o sistema compare o realizado com o orçado, dentro do exercício selecionado.

 

 Selecione o exercício, clicando na seta à direita do campo.

 Clique no botão Encerra, para o sistema iniciar o processo.

 

Obs.: A diferença entre o valor real e o orçado (saldo orçamentário remanescente) poderá ou não ser transferida para o exercício seguinte.
