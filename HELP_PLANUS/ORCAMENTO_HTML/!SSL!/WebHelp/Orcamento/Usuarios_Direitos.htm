Usuários - Direitos

No item Direitos, selecione as ações que poderão ser efetuadas pelo usuário. Estas ações serão somadas aos direitos do grupo.

 

Para acessá-lo, clique com o botão direito do mouse e acesse o item Direitos ou pressione as teclas de atalho Ctrl+D.

 

O sistema exibirá uma tela com o nome do usuário e três guias: Sistema, Relatórios e Consultas Gerais, onde os direitos de acesso do usuário serão configurados.

 

Para selecionar os direitos de acesso do usuário, proceda da seguinte forma:

 

Selecione a guia desejada: Sistema, Relatórios ou Consultas Gerais.

Clique no botão Expandir Árvore, para visualizar todos os itens possíveis da guia.

Posicione, com o ponteiro do mouse, a barra azul sobre o item a ser selecionado e tecle a Barra de Espaços ou dê um clique na caixa de seleção desejada.

Para selecionar todas as autorizações de acesso simultaneamente, clique no botão Marcar Todas.

Utilize o botão Inverter Seleção, para que o sistema inverta a seleção atual.

Clique no botão Fechar Árvore, para comprimir a árvore de autorizações.

Para confirmar a operação, clique no botão OK ou pressione a tecla Enter.
