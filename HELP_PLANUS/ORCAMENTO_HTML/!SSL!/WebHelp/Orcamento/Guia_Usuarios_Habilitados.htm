Guia - Usuários Habilitados

Nesta guia, faça a definição de quem executará o Fluxo de Operação.

 

 Clique no botão Inserir ou Alterar.

 Dê um duplo clique no nome de quem você quer habilitar, na caixa de listagem Usuários Existentes.

 Clique no botão Ok para confirmar.

 

Utilize as setas vermelhas, para selecionar os usuários que terão habilitação neste fluxo.

 

Obs.: Se o usuário não estiver habilitado, ele não poderá executar o fluxo montado.
