Sistema - Configuração - Parâmetros do Sistema - Guia Códigos para Orçado

Esta guia funciona em conjunto com a guia Contas Orçamentárias.

 

Nessa guia poderão ser definidos códigos personalizados para as estruturas de Planos Previdenciários, Patrocinadoras e Atividades/Projetos.

 

Isso é especialmente importante quando desejamos gerar o código da conta com uma formatação diferente do IDentificador definido pelo sistema para as estruturas (plano previdenciário, patrocinadora, atividade/projeto) quando dos respectivos cadastramentos.  São esses IDentificadores:

 

PLANPREV.IDPLANOPREV - Plano Previdenciário

PATRO.IDPATRO - Patrocinadora

UNIDNEGOCIO.UNIDNEGOC - Atividade/Projeto

 

ATENÇÃO:  O termo IDentificador é um termo técnico relativo a Banco de Dados.  Para maior compreensão deste termo, ou mesmo desta guia, sugerimos sua leitura junto a alguém da área de TI de sua empresa.

 

Caso desejemos gerar o código da conta orçamentária, na parte de sua codificação correspondente a Plano Previdenciário e/ou Patrocinadora, com o IDentificador (código interno) gerado pelo sistema, não devemos fazer nada nos "grids" Planos Previdenciais e Patrocinadoras dessa guia.  Caso desejemos gerar com o código SPC definido no cadastro do Plano Previdenciário/Patrocinadora no sistema Global CM, devemos proceder da seguinte forma:

 

Tomando-se como exemplo o Plano Administrativo, cujo IDentificador (código interno) foi definido pelo sistema como 1 e cujo código externo foi definido pelo usuário como 998

 

 Na guia Contas Orçamentárias definimos a quantidade de dígitos para o Plano Previdenciário como 3.

 Nesta guia - Códigos para Orçado - no grid Planos Previdenciais, na coluna Código, na célula correspondente ao Plano Administrativo, digitamos 1.  A célula correspondente ao mesmo plano, porém na coluna Código SPC, virá preenchida com o código SPC (998) para o mesmo Plano Administrativo, definido no cadastro do Plano Previdenciário do sistema Global CM.

 

Essa guia na verdade faz um De/Para, ou seja, informa ao sistema que, no momento da geração automática do código da conta, o código interno do Plano Previdenciário (1) deve ser substituído pelo código externo (998).

 

Os mesmos procedimentos e argumentos acimas, se aplicam ao grid Patrocinadoras.

 

 

Quanto ao grid Atividade/Projeto, algumas considerações se fazem importante:

 

Existe por default (padrão) no cadastro de Atividades/Projetos uma atividade de código interno -1, chamada Atividade Padrão, criada pela CM Soluções.  Quando da implantação do sistema, imaginemos que no sistema Global CM a máscara da estrutura Atividade/Projeto tenha sido definida como 99.99, e que na guia Contas Orçamentárias tenhamos definido a quantidade de dígitos para Atividade/Projeto como 4.  Como o sistema gerará o código da conta orçamentária para a Atividade/Projeto Padrão, já que o código da mesma é -1 e informamos ao sistema que desejamos gerar o código com 4 dígitos para Atividade/Projeto?

 

RESPOSTA: Informaremos no "grid" Atividade/Projeto o código (externo), convencionado pela sua empresa, para a Atividade Padrão.
