RAD - Geral

O menu RAD é anexado à Barra de Menu, quando você possui o sistema RAD+ (Registro de Alçadas e Decisões).

 

Este sistema controla todos os processos existentes em sua empresa, permitindo que cada usuário, de acordo com o nível de autorização que lhe tiver sido concedido, autorize, reprove ou dê qualquer tipo de encaminhamento que for necessário.

 

O RAD+ é um sistema independente, responsável pela orientação, registro e controle das aprovações de etapas dos processos administrativos, existentes na sua empresa.

 

Este menu permite executar as etapas pendentes dos processos que dependem de autorização, gerar novos processos e fazer vários tipos de consultas. Para que as etapas sejam executadas, você precisa fazer os cadastros necessários no próprio sistema RAD+.

 

Ele confere total segurança às informações, pois permite o acesso somente a funcionários autorizados, conforme suas definições e cadastros.
