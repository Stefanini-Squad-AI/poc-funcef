Guia - Parâmetros da Conta

Esta guia se aplica somente ao ítem Cadastros - Contas Orçamentárias por Grupo e Centro de Responsabilidade.  

 

Neste ítem, utilize esta guia apenas para informar uma fórmula para a conta caso desejado.  As fórmulas podem ser informadas para o Grupo da conta ou para a Conta Orçamentária propriamente dita.  Sendo informada aqui, tem prevalescência sobre o Grupo.  Para entender melhor sobre fórmulas, consulte os ítens Cadastros - Fórmulas para Apurar o Orçamento e Entrada de Dados - Execução de Fórmulas de Apuração.

 

Preencha o seguinte campo:

 

Fórmula de Apuração

Clique na seta à direita do campo, para indicar a fórmula de apuração para esta conta.
