Configuração - Relatórios

Neste subitem é possível efetuar alterações nas configurações dos relatórios apresentados.

 

Para realizar estas alterações, clique na seta à direita do campo Relatório e selecione o documento desejado.

 

 Clique no menu Arquivo e selecione o item Sair.

 Ao fechar a tela, aparecerá a janela Configuração de Relatórios para que se nomeie o relatório e confirme ou não as alterações. Em caso afirmativo, clique no botão Ok. Em caso negativo, clique no botão Cancel.

 Se em qualquer momento for necessário voltar às configurações originais dos relatórios, mesmo que estes já tenham sido alterados diversas vezes, selecione o documento e clique no botão Restaurar.

 

Obs.: Para obter maiores informações, consulte a ajuda on-line do sistema Gerador de Relatórios, Consultas e Gráficos.
