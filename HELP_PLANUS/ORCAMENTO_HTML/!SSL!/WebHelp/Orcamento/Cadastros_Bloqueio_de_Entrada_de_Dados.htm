Cadastros - Bloqueio da Entrada de Dados

Neste item, efetue o bloqueio da entrada de dados em "cenários", por cenários e/ou por áreas (centro de responsabilidade e/ou usuários).  A entrada de dados do orçamento vigente deve ser bloqueada em Cadastros - Período Orçamentário.

 

Preencha os seguintes campos:

 

Período

Informe o período para o qual deseja bloquear a entrada de dados.

 

Exercício

Informe o exercício para o qual deseja bloquear a entrada de dados.

 

Botão CENÁRIOS

 

 Assinale a caixa de verificação para os cenários que se deseja bloquear.

 

 

Botão ÁREAS

 

 Guia Centro de Responsabilidade

 Assinale a caixa de verificação para os centros de responsabilidades que se deseja bloquear.

 

 Guia Usuários

 Assinale a caixa de verificação para os usuários que se deseja bloquear.

 

 

Observação 1 - Os cenários selecionados serão bloqueados para entrada de dados, incondicionalmente.

Observação 2 - Quando um centro de responsabilidade é selecionado, todos os usuários do mesmo serão bloqueados.

Observação 3 - É possível bloquear/desbloquear usuários individualmente.

Observação 4 - É possivel bloquear um centro de responsabilidade e liberar usuário(s) do mesmo individualmente.
