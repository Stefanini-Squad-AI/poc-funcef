Sistema - Configuração - Barra de Atalhos

O sistema Orçamento possui uma Barra de Ferramentas ou Atalhos com ícones que foram desenvolvidos para agilizar seu trabalho.

 

Localizados na parte superior da tela, os botões de atalho automatizam alguns itens da Barra de Menu.

 

Para descobrir a função de cada atalho, posicione o ponteiro do mouse sobre o mesmo e uma pequena caixa de texto aparecerá, com o nome de cada botão.

 

Você pode também mover a Barra de Atalhos para o lugar que desejar. Para isso:

 

 Posicione o ponteiro do mouse no canto esquerdo da barra.

 Clique com o botão esquerdo do mouse.

 Com o botão do mouse pressionado, arraste a barra para o lugar que você escolheu.

 

Para acessar a tela referente ao atalho, dê um clique no botão correspondente. São eles:
