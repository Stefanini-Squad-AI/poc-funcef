Ajuda

O help on-line da CM Soluções permite que o usuário procure ajuda das seguintes maneiras:

 

Conteúdo

Utilize esta guia para visualizar o conteúdo do help. Os livrinhos representam os menus do sistema e as interrogações, representam cada item de menu.

 

Índice

Utilize esta guia para procurar palavras ou expressões específicas. Mostra os tópicos da ajuda em ordem alfabética.

 

Pesquisar

Utilize esta guia para realizar consultas através de palavras-chave. Digite a palavra [ou parte dela], para que seja mostrada uma lista dos tópicos que a contém.

 

Textos em laranja

Clicando sobre as palavras em laranja, que aparecem dentro do corpo do texto, o programa apresentará a tela de ajuda referente àquele item.

 

Ocultar/Mostrar

Clique nestes botões, para esconder/visualizar o painel de navegação.

 

Voltar/Avançar

Permitem a movimentação ao longo dos tópicos que o usuário já acessou.

 

Imprimir

Imprime o tópico que está em tela.

 

CM Soluções

Carrega a home page da CM Soluções Informática.

 

Fechar Ajuda

Fecha a tela de ajuda, retornando ao programa.
