Guia - Permissões

Nesta guia, faça a definição de quem executará o Fluxo de Relatórios.

 

Clique no botão Inserir.

Clique no botão Selecionar, para indicar o(s) usuário(s) desejado(s). Essa permissão poderá ser feita por usuário ou pelo grupo de usuários.

Clique no botão Ok, para confirmar.

Utilize a opção Limpar Seleção, para desassociar todos os usuários.

 

Obs.: Se o usuário não estiver selecionado, ele não poderá executar o fluxo montado.
