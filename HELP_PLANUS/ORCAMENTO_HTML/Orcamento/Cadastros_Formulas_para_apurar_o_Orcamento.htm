Cadastros - Fórmulas para apurar o Orçamento

Nesse ítem são cadastradas as fórmulas que serão apuradas em Entrada de Dados - Execução de Fórmulas de Apuração.  

 

Essa funcionalidade permite a elaboração de um orçamento futuro, baseado em uma experiência passada.  Ex.:  É possível cadastrar o orçado do próximo exercício, baseado no realizado do exercício atual.
