Geração de Dados

Os dados orçados serão calculados, de acordo com as fórmulas indicadas no cadastro das contas orçamentárias. As contas cujo tipo de cálculo para o orçado for: fórmula, composição de outras contas, valor acumulado ou condicional, serão calculadas durante a geração dos dados orçados.

 

Os dados realizados serão calculados, de acordo com as fórmulas indicadas no cadastro das contas orçamentárias. As contas cujo tipo de cálculo para o realizado for: contabilidade, fluxo de caixa, arquivos genéricos, fórmula, valor acumulado ou condicional, serão calculadas durante a geração dos dados realizados.

 

Você pode gerar, simultaneamente, os dados orçados e realizados.

 

Para fazer a geração dos dados para o Orçamento, preencha os seguintes campos:

 

Exercício

Clique na seta à direita do campo, para selecionar o exercício cujos dados serão gerados.

 

Período

Clique na seta à direita do campo, para selecionar o período cujos dados serão gerados.

 

Calcula por Período

Este campo já vem marcado. Isto faz com que o sistema gere os dados por período. Se você desmarcá-lo, a geração dos dados será diária e, conseqüentemente, bem mais demorada. Só desmarque este campo, se você tiver a necessidade de gerar os dados do orçamento por dia.

 

Calcula Saldo Anterior

Selecione este campo, para que o sistema calcule o saldo anterior. Esta opção calcula o saldo do exercício anterior, das contas orçamentárias que são compostas por outras contas orçamentárias.

 

Geração dos Dados

Informe os saldos que serão gerados. Você pode gerar somente os dados orçados, somente os dados realizados ou ambos.

 

Cenário

Selecione o cenário cujos dados serão gerados, clicando na seta à direita do campo. Se este campo estiver em branco, o sistema fará a geração de dados do orçamento efetivo. Se você escolher um cenário específico, o sistema fará a geração dos dados para o cenário escolhido.

 

 Calcular as Contas - Posição.

Se este campo ficar em branco, o sistema fará a geração de dados de todas as contas orçamentárias, cujo tipo de cálculo necessite da execução da rotina de geração, como, por exemplo, fórmulas e composição de outras contas.

Para gerar apenas os dados de algumas contas orçamentárias específicas, digite os parâmetros de seleção das contas que serão geradas.

Esse componente possibilita especificar uma cadeia de caracteres específica.  Utilizado quando desejamos proceder a geração apenas para um grupo de contas, por exemplo, do centro de custo ADMINISTRAÇÃO, representado pela cadeia de caracteres 02.06.10 e iniciando a partir da quinta posição.  Procederíamos da seguinte forma:

 

 Inicial - Posição, na cadeia de caracteres, onde se inicia o código correspondente ao centro de custo. No nosso exemplo deve ser preenchido com 5, pois o centro de custo começa na quinta posição.

 Dígitos - A partir da quinta posição, indica quantos caracteres queremos considerar para contemplar o centro de custo.  No nosso exemplo deve ser preenchido com 6, pois, 020610 têm 6 caracteres.

 Conteúdo - Aqui especificamos a cadeia de caracteres exata que representa o centro de custo desejado.  No nosso exemplo, 020610.

 

Resumindo, informamos ao sistema que desejamos proceder a geração para todas as contas que, com seis caracteres iniciando na quinta posição, possuem a cadeia de caracteres 020610.

 

Exemplo de contas que "seriam"/ "não seriam" contempladas nesse processamento:

 

010202062001011 - Não seria

010202061001011 - Seria

 

 

Botão Ok

Clique neste botão, para o sistema iniciar o processo de geração dos dados, conforme os parâmetros estabelecidos.

 

Durante a geração de dados, o sistema verifica se existe alguma conta orçamentária cadastrada de forma indevida e mostra uma mensagem na tela, com o provável erro do cadastro.

 

No campo Contas não Calculadas, o sistema registra todas estas contas orçamentárias, cujos valores não puderam ser calculados, para que você possa, posteriormente, fazer as correções necessárias no cadastro destas contas.
