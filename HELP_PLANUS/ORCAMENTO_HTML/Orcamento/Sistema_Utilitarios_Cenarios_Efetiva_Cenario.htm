Cenários - Efetiva Cenário

Neste subitem, faça a efetivação de um cenário, ou seja, transforme em orçamento efetivo, um orçamento cadastrado para um determinado cenário.

 

Exemplo:

 

Você cadastra seu orçamento normal para o ano 2004.

 

Além do orçamento normal, você cadastra seu orçamento para o ano 2004, em outros dois cenários: otimista e pessimista.

 

A economia e a política do país fazem você acreditar que o orçamento feito no cenário otimista, deverá ficar mais próximo da realidade que o seu orçamento normal.

 

Este subitem permite transformar o orçamento feito para o cenário otimista no orçamento normal, que será acompanhado pelo sistema, ou seja, efetivar um cenário.

 

Para efetivar um cenário, siga as instruções a seguir:

 

 Selecione o exercício no qual o cenário será efetivado, clicando na seta à direita do campo.

 Indique os períodos inicial e final, para efetivação do cenário selecionado.

 Informe o cenário que será efetivado, ou seja, o cenário que, dentro do período selecionado, será considerado como o orçamento efetivo.

 Selecione o cenário onde será gravado o orçamento atual. O sistema gravará as informações do seu orçamento atual, para o cenário que for indicado neste campo. Este cenário deverá ter sido, previamente, cadastrado no item Cadastros – Cenários. Exemplo: Cenário anterior aos ataques terroristas.

 Marque o campo Busca Saldo Anterior, para que o sistema resgate todos os saldos anteriores ao período selecionado. Este campo recalcula as contas orçamentárias calculadas a partir de outras contas e, só faz sentido, para contas que transportam saldo de exercício orçamentário para outro.

 Clique no botão Efetivar, para o sistema iniciar o processo. Ao final, o sistema considerará que o orçamento efetivo é o cenário recém efetivado.
