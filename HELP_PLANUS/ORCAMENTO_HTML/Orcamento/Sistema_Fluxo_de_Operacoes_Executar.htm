Sistema - Fluxo de Operações - Executar

O fluxo de relatórios é acessado através do subitem Executar.

 

Quando você clica nesse subitem, o sistema abre uma tela para que você selecione o fluxo de relatórios.

 

Ao selecioná-lo, o sistema disponibilizará a tela de filtro do primeiro relatório do fluxo.

Utilize os botões Voltar e Continuar, para navegar pelas telas pertencentes ao fluxo.

Clique no botão Finalizar, para terminar a execução do fluxo.

 

Note que ao executar um fluxo de relatórios, todos os menus e a barra de ferramentas ficam desabilitados. Isso acontece porque só será permitida a manipulação dos relatórios, pertencentes ao fluxo que você montou.
