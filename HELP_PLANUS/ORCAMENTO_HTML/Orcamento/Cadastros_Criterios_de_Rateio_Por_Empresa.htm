Cadastros - Critérios de Rateio - Replicar Valores Base

Esta funcionalidade permite copiar critérios de rateios já definidos, para outros exercícios.

 

Proceda conforme segue:

 

 Informe o critério de rateio que se deseja replicar.

 Informe o exercício que se deseja replicar.

 Informe o exercício para o qual se deseja replicar o critério de rateio

 Clique no botão Ok para processar.
