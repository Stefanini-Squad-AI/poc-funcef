Guia Usuários Habilitados

Na guia Usuários Habilitados, o usuário poderá definir quem executará o Fluxo de Operação.

 

 Clique no botão Inserir ou Alterar.

 Dê um duplo clique no nome do usuário que deseja habilitar, na caixa de listagem Usuários Existentes.

 Clique no botão Ok para confirmar.

 

Se o usuário não estiver habilitado, ele não poderá executar o fluxo montado.

 

É possível também, usar as setas vermelhas, para selecionar os usuários que terão habilitação neste fluxo.
