Sistema - Login

O item de menu Login permite bloquear o acesso de outras pessoas ao sistema. Para desbloqueá-lo, digite seu nome e senha. Se outro usuário quiser acessar, é só digitar os respectivos nome e senha, cadastrados no item de menu Usuários.

 

É muito importante utilizar esse recurso, sempre que for se afastar do computador por algum tempo, evitando assim que pessoas não autorizadas utilizem o sistema com a sua senha.

 

O usuário que estiver acessando o sistema pela primeira vez, deverá digitar o nome correspondente no campo Usuário e a senha Mudesuasenha no campo Senha.

 

O sistema mostrará uma caixa de mensagem para que se possa alterar a senha, pois a atual é a que foi gerada internamente.
