Cadastros - Período Orçamentário

Neste item, cadastre os períodos orçamentários no sistema.

 

Geralmente, os períodos de um exercício correspondem aos meses do ano. Mas o sistema permite a definição livre dos mesmos, através da indicação das datas de início e de fim.

 

Preencha os seguintes campos:

 

Exercício

Informe o exercício (ano) ao qual pertence o período orçamentário.

 

Período

Campo preenchido pelo sistema, com o número do período.

 

Data Inicial

Selecione a data inicial do período, clicando no botão Calendário. O sistema sugere a primeira data disponível para o período, que não esteja dentro de outra faixa já escolhida.

 

Data Final

Selecione a data final do período. O sistema sugere a data final do mês, indicado no campo Período.

 

Nome

Digite o nome do período ou aceite a descrição sugerida pelo sistema.

 

Período Bloqueado

Indique se o período orçamentário está bloqueado para lançamentos. Este bloqueio só deverá ser habilitado, após o orçamento do período ter sido lançado ou gerado por completo.
