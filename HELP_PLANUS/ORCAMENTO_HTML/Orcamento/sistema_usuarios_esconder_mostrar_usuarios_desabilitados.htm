Usuários - Esconder / Mostrar Usuários Desabilitados

Utilize o item Esconder Usuários Desabilitados para visualizar apenas os usuários que estiverem ativos, ou seja, os usuários que, efetivamente, estiverem utilizando o sistema.

 

Através do item Mostrar Usuários Desabilitados, o sistema volta a exibir todos os usuários cadastrados, sem restrições.

 

Para acessá-los, clique com o botão direito do mouse e acesse o item correspondente.
