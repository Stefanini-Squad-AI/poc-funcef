Sistema - Sair

O item Sair permite que o usuário deixe o sistema.

 

É possível sair do sistema de cinco formas diferentes:

 

 Clicando no item Sair, no menu Sistema.

 Clicando no botão Sair, da Barra de Ferramentas.

 Clicando no botão Fechar, da Janela Principal.

 Escolhendo o item Fechar, no ícone da Barra de Título.

 Pressionando as teclas de atalho Alt+F4.

 

Obs.: Apesar do sistema permitir várias modalidades de saída, é recomendável fazê-la através do menu Sistema, no item Sair.
