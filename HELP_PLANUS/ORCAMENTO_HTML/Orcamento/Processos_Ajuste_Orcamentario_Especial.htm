Processos - Ajuste Orçamentário - Especial

Ajustar um orçamento é aumentar o valor das dotações orçamentárias através de suplementações ou diminuir o valor das mesmas através de deduções orçamentárias.

 

O Ajuste Orçamentário normalmente ocorre uma vez no ano, com participação/aprovação dos Conselhos, e visa ajustar os saldos do orçamento vigente em função de problemas extraordinários inesperados, como catástrofes, fenômenos meteorológicos, cenário político ou coisas do gênero.  

 

Normalmente nas empresas, o departamento responsável pela gestão do orçamento não tem autonomia para "ajustar" valores do orçamento vigente e sim "transferí-los" quando julgar necessário.  Na Transferência Orçamentária o saldo final orçado não se altera, já que sai de uma conta e entra em outra.  No Ajuste Orçamentário há alteração no saldo final do orçamento.

 

Este ítem só deve ser utilizado por quem cadastrou o Plano de Contas Orçamentário através do ítem Cadastros - Contas Orçamentárias por Grupo ou Cadastros - Contas Orçamentárias por Grupo e Centro de Responsabilidade.

 

Neste ítem o usuário não leva em conta as diversas contas orçamentárias cadastradas internamente pelo sistema, e para as quais faz-se necessário informar valores, mas sim, o Grupo da conta orçamentária.

 

Através de um filtro para seleção das contas, baseado em Grupo, Centro de Responsabilidade, Patrocinadora e/ou Plano Previdenciário, o sistema faz o "input" dos ajustes para um determinado conjunto de contas por "centro de custo".

 

Preencha os campos da tela conforme explicações a seguir:

 

Grupo Orçamentário

Clique no botão a direita do campo, para selecionar o Grupo de contas orçamentárias que se deseja filtrar.

 

Plano de Trabalho

Clique na seta a direita do campo, para informar o Plano de Trabalho ao qual está amarrado o Centro de Responsabilidade do conjunto de contas orçamentárias que se deseja filtrar.

 

Patrocinadora

Clique na seta a direita do campo, para informar a Patrocinadora do conjunto de contas orçamentárias que se deseja filtrar.

 

Plano Previdenciário

Clique na seta a direita do campo, para informar o Plano Previdenciário do conjunto de contas orçamentárias que se deseja filtrar.

 

Período

Clique na seta a direita do campo, para informar o período para o qual desejamos efetuar ajustes.  

 

Exercício

Digite o exercício no qual desejamos efetuar ajustes.

 

Observação

Digite, caso desejado, uma observação para os ajustes.

 

 

 Clique no botão Selecionar Contas Orçamentárias para efetuar a filtragem.  Caso existam contas orçamentárias cadastradas por centro de custo, para os mesmos filtros informados acima, o sistema retornará esse conjunto de contas para que sejam efetuados os ajustes.

 Insira os ajustes diretamente no "grid", na coluna Suplementação (+) / Dedução (-).  Para deduções, insira os valores com o sinal (-) antes do valor.

 

 Clique no botão Excluir para excluir ajustes efetuadas para um grupo de contas.

 Clique no botão Ok para efetivar o cadastramento dos ajustes efetuados para um grupo de contas.
