Fluxo de Operação - Executar

O fluxo de operação montado é acessado através do subitem Executar.

 

Quando o usuário entra nesse subitem, o sistema abre uma caixa de texto para que ele selecione o fluxo montado.

 

 Clique no botão Iniciar, para o sistema disponibilizar a primeira tela do fluxo.

 Utilize os botões Anterior e Seguinte, para navegar pelas telas pertencentes ao fluxo.

 Clique no botão Finalizar, para terminar a execução do fluxo.

 

É possível fazer com que a tela de execução do fluxo de operação apareça na barra de ferramentas, bastando apenas arrastá-la até a barra.

 

Note que ao executar um fluxo de operação, todos os menus da barra de ferramentas ficam desabilitados. Isso acontece porque só será permitida a manipulação das telas, pertencentes ao fluxo que o usuário determinou.
