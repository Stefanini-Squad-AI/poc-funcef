Atualização Automática de Versões

Nesta opção, faça a configuração do diretório centralizado, para que os sistemas da CMNet instalados no servidor sejam atualizados, automaticamente, para todas as estações de trabalho.

 

Sempre exibe esta tela ao iniciar a aplicação

Marque este campo, para que toda vez que você acessar o sistema, a tela de parâmetros do registro seja mostrada.

 

Habilita Database Trace

Marque este campo, para poder visualizar e enviar por e-mail o Database Trace do Orçamento.

 

O diretório centralizado deverá conter os seguintes subdiretórios:

 

 Bin – Sistemas instalados – *.exe + cmtraduz.mld

 Alt – Arquivos do tipo alt – *.alt

 Help – Ajudas on-line dos sistemas – *.chm

 Lib – Arquivos do InstalaCM, AtualizaCM e AtualizaCMFront – *.bpl

 

Observações:

 

A chave de atualização de versão deverá estar sempre apontada para o subdiretório Bin.

Para que o processo de atualização das versões se torne obrigatório, crie um arquivo qualquer chamado atuversaocm.auto, no subdiretório Bin.
