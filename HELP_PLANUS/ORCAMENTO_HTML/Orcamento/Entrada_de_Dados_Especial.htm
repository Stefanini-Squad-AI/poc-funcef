Entrada de Dados - Especial

Este ítem só deve ser utilizado por quem cadastrou o Plano de Contas Orçamentário através do ítem Cadastros - Contas Orçamentárias por Grupo ou Cadastros - Contas Orçamentárias por Grupo e Centro de Responsabilidade.

 

Neste ítem o usuário não leva em conta as diversas contas orçamentárias cadastradas internamente pelo sistema, e para as quais faz-se necessário informar valores, mas sim, o Grupo da conta orçamentária.

 

Através de um filtro para seleção das contas, baseado em Grupo, Centro de Responsabilidade, Patrocinadora e/ou Plano Previdenciário, o sistema faz o "input" de dotações para um determinado conjunto de contas por "centro de custo", baseado ou não num critério de rateio pré-estabelecido.

 

O critério de rateio, quando utilizado, facilitará a entrada de dados orçados, pois é possível indicar o valor total orçado e o sistema "rateará", automaticamente, este valor, para formar o orçamento de cada conta orçamentária individualmente.

 

Exemplos de Critérios de Rateio:

 

A sua empresa possui dois critérios de rateio: um chamado Número de Funcionários e outro chamado Metros Quadrados.

 

No critério Número de Funcionários, o rateio será feito em função do número de funcionários que estiverem alocados em cada centro de custo. Você só precisará orçar a despesa com transporte (ônibus da empresa), para que o sistema “divida” este valor, proporcionalmente, pelo número de funcionários alocados em cada centro de custo.

 

No critério Metros Quadrados, o rateio será feito em função da área ocupada por cada departamento. Você só precisará orçar a despesa com limpeza (empresa terceirizada), para que o sistema “divida” este valor, proporcionalmente, à área ocupada por cada departamento.

 

Para obter maiores informações sobre os critérios de rateio, consulte o item Cadastros – Critérios de Rateio.

 

Preencha os campos da tela conforme explicações a seguir:

 

Grupo Orçamentário

Clique no botão a direita do campo, para selecionar o Grupo de contas orçamentárias que se deseja filtrar.

 

Plano de Trabalho

Clique na seta a direita do campo, para informar o Plano de Trabalho ao qual está amarrado o Centro de Responsabilidade do conjunto de contas orçamentárias que se deseja filtrar.

 

Patrocinadora

Clique na seta a direita do campo, para informar a Patrocinadora do conjunto de contas orçamentárias que se deseja filtrar.

 

Plano Previdenciário

Clique na seta a direita do campo, para informar o Plano Previdenciário do conjunto de contas orçamentárias que se deseja filtrar.

 

Período

Clique na seta a direita do campo, para informar o período para o qual desejamos informar dotações orçamentárias.  Caso os valores se repitam para todos os períodos do exercício, é possível utilizar o "recurso" período "Anual".  Utilizando-se esse recursos, o sistema repetirá os valores digitados, para todos os períodos do exercício.

Também é possível utilizar esse recurso  e, posteriormente, alterar as dotações diferentes em períodos específicos.

 

Exercício

Digite o exercício no qual desejamos informar dotações orçamentárias.

 

 Clique no botão Selecionar Contas Orçamentárias para efetuar a filtragem.  Caso existam contas orçamentárias cadastradas por centro de custo, para os mesmos filtros informados acima, o sistema retornará esse conjunto de contas para que sejam informadas as dotações orçamentárias, manualmente ou através de rateio.

 

Sobrescrever as dotações já efetuadas pelo o valor novo informado

Marque essa caixa de verificação, para que o sistema sobrescreva dotações digitadas anteriormente, com as novas dotações digitadas.

 

Critério para rateio

Indique um critério para rateio do valor informado no campo Valor total para rateio.

 

Valor total para rateio

Digite um valor para ser rateado igualmente entre todos os registros do "grid", ou através do rateio informado no campo Critério para rateio.

 

 Clique no botão Calcular para que o valor informado seja rateado entre os registros do "grid".

 

 Linhas que não serão modificadas - Em caso de alteração, as linhas do "grid" realçadas em vermelho, não serão modificadas em função de já existirem processos - reserva, compromisso, transferência, dedução e/ou suplementação - para as mesmas.

 

Observação 1:  É possível operar essa tela digitando-se valores diretamente no "grid".

Observação 2:  Alterações nessa tela se dão no modo de "Inserção".
