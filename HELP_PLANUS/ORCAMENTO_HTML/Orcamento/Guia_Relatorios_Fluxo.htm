Guia - Relatórios

Nesta guia, faça a seleção dos relatórios que irão compor o fluxo.

 

Clique no botão Selecionar, para indicar o relatório desejado. Essa seleção poderá ser feita, tanto pelo nome do relatório como pelo nome do grupo do relatório. Se preferir, clique no botão Buscar, para visualizar todos os relatórios cadastrados no sistema.

Selecione o relatório desejado.

Clique no botão Ok localizado à direita da tela, para efetivar a associação.

Repita os passos acima para inserir os demais relatórios do fluxo.

Utilize o botão Cancelar, para sair do modo de inserção/alteração da guia.

 

Obs.: A seqüência de apresentação dos relatórios do fluxo respeitará a ordenação definida na montagem do mesmo.
