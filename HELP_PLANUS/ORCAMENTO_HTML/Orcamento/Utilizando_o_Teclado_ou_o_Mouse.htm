Utilizando o Teclado ou o Mouse

É recomendado que o usuário utilize um mouse para navegar no ambiente Windows. Caso não possua, ou mesmo que o mouse apresente um defeito momentâneo, será possível acessar tranqüilamente as janelas utilizando apenas o teclado.

 

Executando um Item de Menu

 

A partir da Barra de Menu:

 

 Posicione o ponteiro do mouse sobre o item desejado e clique com o botão esquerdo do mouse, ou

 Pressione a tecla Alt para tornar ativa a Barra de Menu. Movimente o cursor com as setas de movimentação até o item desejado e pressione Enter, ou

 Pressione simultaneamente as teclas Alt + Letra sublinhada do item.

 

A partir de Menus Verticais:

 

 Posicione o ponteiro do mouse sobre o item desejado e clique com botão esquerdo do mouse, ou

 Posicione o cursor usando as setas de movimentação e pressione Enter.

 Pressione a letra sublinhada referente ao item desejado.

 

Preenchendo as informações solicitadas

 

 Utilize o botão esquerdo do mouse para acesso aos campos onde deverão ser preenchidos ou para clicar em cima de botões de escolha ou botões de confirmação.

 Após o preenchimento de um campo, utilize a tecla Tab para acesso ao próximo campo, ou pressione simultaneamente Shift+Tab para retornar um campo.
