Guia Seqüência

Para saber como preencher os campos da guia Seqüência, leia as explicações abaixo:

 

Menus Existentes

Clique nos menus para selecionar as telas que comporão o fluxo de operação.

 

Telas Selecionadas

É a seqüência em que se deseja que as opções sejam apresentadas. Selecione ordenadamente as telas que farão parte da seqüência, em que o fluxo de operação será executado.

 

 Clique nos menus disponíveis na caixa de listagem Menus Existentes.

 Selecione um item e clique na seta vermelha, para que o menu escolhido passe para o campo Telas Selecionadas.

 Para inverter a ordem de execução das telas, selecione o item correspondente e clique nas setas verdes.

 

Nome do Passo

Este campo é preenchido automaticamente, quando um item, listado no campo Menus Existentes foi selecionado. É exatamente o nome do item escolhido. Ele aparece na tela quando o fluxo de operação é executado, para que seja identificado em que tela o fluxo está no momento.

 

Descrição do passo

Digite a descrição detalhada da operação, que será feita na tela correspondente ao Nome do Passo. Isso facilita a sua compreensão do que será executado nas etapas do fluxo de operação.
