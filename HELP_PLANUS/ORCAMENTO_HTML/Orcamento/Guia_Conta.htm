Guia - Conta

Nesta guia, informe a conta que será impressa em determinada célula, o cabeçalho das colunas e diversas outras propriedades.

 

Preencha os seguintes campos:

 

Código da Conta

Clique no botão Seleciona, para informar a conta orçamentária que fará parte do relatório.

 

Orçado/Realizado/Análise Vertical

Informe os valores que serão utilizados no relatório.

 

Acumulado

Marque este campo, para que sejam mostrados os valores acumulados.

 

Separador das Linhas

Informe o tipo de separador das linhas, ou seja, indique como o sistema irá separar a linha que está sendo cadastrada da linha anterior.

Você tem quatro opções:

 Com espaçamento entre as linhas.

 Desenha uma linha fina.

 Desenha uma linha grossa.

 Desenha uma linha dupla.

 

Cor

Clique neste campo, para indicar a cor em que essa linha será impressa.

 

Imprimir em negrito

Marque este campo, para que a linha fique em negrito.

 

Título

Digite o título da coluna.

 

Você deverá repetir esta operação, até inserir todas as linhas que você deseja incluir no relatório.
