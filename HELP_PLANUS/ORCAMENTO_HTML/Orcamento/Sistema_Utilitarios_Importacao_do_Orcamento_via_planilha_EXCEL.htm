Sistema - Utilitários - Importação do Orçamento via planilha EXCEL

Através deste utilitário, faça a importação das dotações orçamentárias a partir de uma planilha EXCEL.  

 

Esta funcionalidade minimiza o trabalho de cadastramento efetuado através dos ítens Entrada de Dados - Por Período e Entrada de Dados - Especial.

 

 Selecione o exercício para o qual se deseja importar as dotações orçamentárias.

 Indique qual é a primeira linha de dados na planilha EXCEL.

 Indique o caminho completo da planilha EXCEL que contém os dados a serem importados.

 Indique se, caso esteja sendo importado um valor para um período que já possua dotação, o valor atual deve ser sobrescrito.

 Indique a coluna da planilha EXCEL que contém os códigos das contas orçamentárias, para as quais queremos importar as dotações.

 Indique as colunas da planilha EXCEL, que contém os valores das dotações orçamentárias para o período de janeiro a dezembo.

 Clique no botão Continua para dar início à importação.  Na tela que segue será apresentado o resultado do processamento.
