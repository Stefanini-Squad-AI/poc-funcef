Usuários - Novo

Para cadastrar um usuário no sistema, clique com o botão direito do mouse e acesse o item Novo ou pressione a tecla Insert.

 

 Preencha os seguintes campos:

 

Nome do Usuário

Digite o nome que será utilizado para o login no sistema.

 

Nome Completo

Digite o nome completo do usuário.

 

E-mail

Digite o e-mail do usuário.

 

Descrição

Digite a descrição do usuário, se houver.

 

Senha

Digite a senha.

 

Confirmação

Digite novamente a senha para confirmação.

 

O Usuário Deve Mudar a Senha no Próximo Logon

Selecione este campo, para que o usuário seja obrigado a mudar a senha quando efetuar o seu próximo login ou quando for acessar o sistema pela primeira vez.

 

Usuário Não Pode Mudar a Senha

Marque este campo, para que o usuário não tenha permissão para modificar sua própria senha.

 

Senha Permanente

Selecione este campo, para que a conta do usuário não tenha prazo de expiração. Se a senha não for permanente, indique a validade da mesma.

 

Válida Até

Indique o prazo de validade da senha, clicando no botão Calendário.

 

Conta Desabilitada

Selecione este campo, para que o usuário seja impedido de entrar no sistema, sem precisar removê-lo do cadastro.

Ex.: Férias.

 

Conta Bloqueada

Este campo indica se a conta está bloqueada. O sistema bloqueia a conta, automaticamente, quando o usuário tenta efetuar o login três vezes seguidas, sem obter êxito.

Ao efetuar o login após o desbloqueio, será solicitado ao usuário a troca de senha, obrigatoriamente.

 

Botão Criar/Atualizar como

Clique neste botão, para que todos os direitos de acesso do usuário selecionado sejam replicados ao usuário que está sendo cadastrado.

 

Botão Grupos

Clique neste botão, para acessar a tela Manutenção de Grupos.

 

Botão Direitos

Clique neste botão, para consultar e/ou editar os Direitos do Usuário.

 

Botão Resetar Senha

Selecione este campo, para que a senha do usuário seja a senha padrão e ele possa alterá-la no próximo login.

 

 Clique com o mouse no botão Ok ou pressione a tecla Enter.
