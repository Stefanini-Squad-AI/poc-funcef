Sistema - Utilitários - Busca Dados Contábeis para Orçamento

Através deste subitem, faça a importação dos dados contábeis realizados, para formar o Orçamento.

 

 Selecione o exercício desejado, clicando na seta à direita do campo.

 Selecione o campo Busca para os Cenários, para que o sistema resgate todos os dados contábeis, também, para os orçamentos feitos nos diferentes cenários.

 Marque o campo Busca Saldo Anterior, para que o sistema resgate todos os saldos anteriores ao exercício selecionado. Esta opção calcula o saldo anterior das contas orçamentárias, que são compostas por outras contas orçamentárias que, por sua vez, recebem informações da Contabilidade.

 Indique o período limite para a busca de dados contábeis, clicando na seta à direita do campo.

 Conta para Encerramento – Para importar os dados contábeis de um exercício não encerrado, indique a conta que será utilizada pelo sistema Orçamento, para fazer a apuração de resultado necessária à importação.

 Para efetuar a transferência de resultado do saldo anterior, clique na guia Saldo Anterior - Transferência de Resultado e indique as contas de origem e de destino da transferência.

 Selecione o período inicial e final, para que o sistema “busque” os dados da Contabilidade para formar o orçamento.

 Indique os parâmetros de seleção das contas contábeis que serão atualizadas.

 Clique no botão Ok, para o sistema iniciar a busca de dados contábeis para o sistema de Orçamento.
