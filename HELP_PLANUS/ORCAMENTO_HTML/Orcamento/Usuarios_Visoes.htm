Usuários - Visões

O item Visões foi criado para que você possa definir quais consultas (visões, querys) o usuário poderá utilizar na configuração de relatórios.

 

Desta forma, especifique as consultas do sistema Gerador de Relatórios que o usuário poderá consultar.

 

Para acessá-lo, clique com o botão direito do mouse e acesse o item Visões ou pressione as teclas de atalho Ctrl+I.

 

 Selecione a visão, na listagem Não Selecionados, à direita da tela.

 Clique no botão Associa.

 Clique no botão Ok ou pressione a tecla Enter, para confirmar a associação.

 

Obs.: Se nenhuma visão for especificada, o usuário terá direito de utilizar todas as consultas cadastradas.
