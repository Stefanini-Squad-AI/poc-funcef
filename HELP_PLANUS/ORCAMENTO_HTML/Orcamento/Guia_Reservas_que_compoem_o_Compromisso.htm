Guia - Reservas que compõem o Compromisso

Nesta guia, indique a(s) reserva(s) que compõe(m) o compromisso orçamentário que está sendo lançado, ou seja, indique qual a reserva orçamentária que previa o desembolso a ser concretizado, através deste compromisso orçamentário.

 

 Selecione o Período de Datas de Referência, para filtrar as Reservas Orçamentárias pendentes (status “aguardando”) e que se deseja efetivar com o atual compromisso. Utilize os botões Calendário.

 Clique no botão Filtra, para o sistema disponibilizar todas as reservas pertencentes ao período informado, que tenham sido lançadas na conta orçamentária selecionada, na guia Compromisso.

 Para inserir uma reserva no compromisso, selecione a reserva desejada e clique no botão Inclui Reserva.

 Clique no botão Exclui Reserva, para desfazer a inclusão da reserva selecionada.
