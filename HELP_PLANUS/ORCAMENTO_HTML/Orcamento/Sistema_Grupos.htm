Sistema - Grupos

No item Grupos, cadastre os grupos de usuários, juntamente com seus respectivos direitos de acesso.

 

O grupo de usuários serve para você definir um determinado perfil de acesso e, também, enviar mensagens a diversos usuários pertencentes ao mesmo grupo.

 

Para efetuar a manutenção dos grupos de usuários, siga as instruções abaixo:

 

 Clique com o botão esquerdo do mouse sobre a tela.

 Acesse os itens do menu, clicando com o botão direito do mouse ou, simplesmente, pressionando as teclas de atalho.
