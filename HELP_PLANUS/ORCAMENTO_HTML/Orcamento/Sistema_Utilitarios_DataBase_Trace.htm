Sistema - Utilitários - Database Trace

Este é o mais novo utilitário dos sistemas CMNet.

 

O Database Trace foi criado nos sistemas de versão 4, para substituir o SQLMonitor.

 

Assim como o SQLMonitor, o Database Trace é uma ferramenta de suporte ao desenvolvedor, com a finalidade de monitorar as transações de banco de dados que estiverem sendo processadas, durante a execução do sistema.

 

Este utilitário é muito importante no auxílio à detecção de erros que possam estar relacionados às regras de integridade dos dados e à estrutura das tabelas, em consonância com o nosso modelo de dados, dentre outras.
