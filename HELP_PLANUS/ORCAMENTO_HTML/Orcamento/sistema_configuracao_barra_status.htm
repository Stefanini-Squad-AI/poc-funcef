Configuração - Barra de Status

O subitem Barra de Status, quando ativado, abre uma barra na parte inferior da tela, para que seja visualizado o nome da empresa que foi selecionada no item de menu Mudar Empresa.

 

Essa barra também identifica o usuário que está acessando o sistema, além de disponibilizar a data e a hora do computador.

 

Note que o subitem se encontra ativado, quando ao seu lado aparece um marcador preto.
