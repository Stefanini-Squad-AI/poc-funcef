Geração Dos Dados - Consolidados

Através deste item, realize a geração de dados para o grupo de empresas consolidadas, de acordo com os grupos cadastrados na Contabilidade.

 

Para fazer a geração dos dados de empresas consolidadas, preencha os seguintes campos:

 

Exercício

Clique na seta à direita do campo, para selecionar o exercício desejado.

 

Atualizar o saldo anterior

Marque este campo, para que o saldo anterior seja atualizado.

 

Períodos Inicial e Final

Clique na seta à direita dos campos, para selecionar a faixa de períodos em que os dados consolidados serão gerados.

 

Grupo

Indique o grupo de empresas consolidadas, para as quais os dados serão gerados.

 

Empresas

Mostra as empresas pertencentes ao grupo selecionado.

 

Botão Ok

Clique neste botão, para o sistema iniciar o processo de geração dos dados consolidados, conforme os parâmetros estabelecidos.
