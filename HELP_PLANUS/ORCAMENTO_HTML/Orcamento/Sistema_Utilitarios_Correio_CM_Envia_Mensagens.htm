Sistema - Utilitários - Envia Mensagens

Através do subitem Envia Mensagens, você pode encaminhar um comunicado para qualquer funcionário cadastrado ou para um grupo de funcionários.

 

 Preencha os seguintes campos:

 

Destinatário

Digite o nome do usuário que receberá a mensagem ou clique na seta à direita do campo, para selecioná-lo.

 

Grupo

Utilize este campo para enviar uma mesma mensagem para mais de um usuário. Para selecionar o grupo, clique na seta à direita do campo.

 

Assunto

Digite o assunto/título da mensagem.

 

Programada

Marque este campo, caso você queira que a mensagem seja recebida numa data específica. Digite a data programada para o recebimento da mensagem, seguindo o padrão dd/mm/aaaa ou clique na seta à direita do campo. Se este campo não for selecionado, a mensagem será recebida logo após o seu envio.

 

Enviar Cópia da Mensagem Para

Neste campo, será(ão) mostrado(s) o(s) usuário(s) e/ou o(s) grupo(s) selecionado(s) para receber(em) a mensagem, exceto o destinatário.

 

 Clique no botão Seleciona Usuários, para enviar uma cópia da mensagem para um usuário.

 Para enviar a cópia da mensagem para um grupo, utilize o botão Seleciona Grupos.

 Para desfazer a seleção de um usuário/grupo, clique no botão Exclui Item Selecionado.

 

Mensagem

Digite o conteúdo da mensagem que você deseja enviar.

 

 Clique no botão Enviar, para encaminhar sua mensagem.
