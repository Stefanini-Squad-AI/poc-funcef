Processos - Justificativa de divergências dos saldos

Através deste ítem é possível cadastrar justificativas para contas orçamentárias, cujo valor realizado, ultrapassou o valor orçado para a mesma.

 

Posteriormente é possível visualizar ou mesmo apresentar essas justificativas, a quem de direito, fazendo-se uso do relatório "Divergências entre saldos Orçados x Realizados".

 

Preencha os seguintes campos:

 

Conta Orçamentária

Clique no botão a direita do campo, para selecionar a conta orçamentária para a qual se deseja cadastrar uma justificativa.

 

Período

Clique na seta a direita do campo, para informar o período em que o saldo realizado da conta excedeu ao orçado.

 

Exercício

Informe o exercício em que o saldo realizado da conta excedeu ao orçado.
