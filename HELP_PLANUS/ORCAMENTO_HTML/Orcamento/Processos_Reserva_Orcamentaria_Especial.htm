Processos - Reserva Orçamentária - Especial

Neste item, cadastre as reservas orçamentárias, ou seja, comprometa a verba orçada, com despesas que se reconhece a necessidade de realizar, porém, ainda não se tem certeza sobre seu exato valor.  O ato de comprometer a verba através de uma reserva, evita que outro comprometa a mesma verba enquanto um processo de cotação da mercadoria/serviço está em andamento.

 

A principal diferença entre Reserva e Compromisso Orçamentário é o fato de que, para a primeira (reserva) não se conhece exatamente o valor nem a data de pagamento da despesa, porém, já se reconhece a necessidade de sua realização, ao passo que para o segundo (compromisso), já se sabe exatamente o valor e a data do pagamento da despesa.

 

Não existe a obrigatoriedade de se fazer uma reserva antes de um compromisso, embora seja mais correto dessa forma.  Também é possível comprometer o valor orçado para a conta, diretamente com um Compromisso Orçamentário.

 

É importante ter conhecimento que, tanto reserva quanto compromisso orçamentário, comprometem o saldo orçado para a conta, portanto, deve-se tomar cuidado para não esquecer de efetivar reserva(s), quando houver, na criação de um compromisso.

 

Este ítem só deve ser utilizado por quem cadastrou o Plano de Contas Orçamentário através do ítem Cadastros - Contas Orçamentárias por Grupo ou Cadastros - Contas Orçamentárias por Grupo e Centro de Responsabilidade.

 

Neste ítem o usuário não leva em conta as diversas contas orçamentárias cadastradas internamente pelo sistema, e para as quais faz-se necessário informar valores, mas sim, o Grupo da conta orçamentária.

 

Através de um filtro para seleção das contas, baseado em Grupo, Centro de Responsabilidade, Patrocinadora e/ou Plano Previdenciário, o sistema faz o "input" de reservas para um determinado conjunto de contas por "centro de custo", baseado ou não num critério de rateio pré-estabelecido.

 

O critério de rateio, quando utilizado, facilitará o cadastramento de reservas, pois é possível indicar o valor total da reserva e o sistema "rateará", automaticamente, este valor, para formar a reserva de cada conta orçamentária individualmente.

 

Para obter maiores informações sobre os critérios de rateio, consulte o item Cadastros – Critérios de Rateio.

 

Preencha os campos da tela conforme explicações a seguir:

 

Grupo Orçamentário

Clique no botão a direita do campo, para selecionar o Grupo de contas orçamentárias que se deseja filtrar.

 

Plano de Trabalho

Clique na seta a direita do campo, para informar o Plano de Trabalho ao qual está amarrado o Centro de Responsabilidade do conjunto de contas orçamentárias que se deseja filtrar.

 

Patrocinadora

Clique na seta a direita do campo, para informar a Patrocinadora do conjunto de contas orçamentárias que se deseja filtrar.

 

Plano Previdenciário

Clique na seta a direita do campo, para informar o Plano Previdenciário do conjunto de contas orçamentárias que se deseja filtrar.

 

Período

Clique na seta a direita do campo, para informar o período para o qual desejamos efetuar reservas.  

 

Exercício

Digite o exercício no qual desejamos efetuar reservas.

 

Observação

Digite, caso desejado, uma observação para as reservas.

 

 

 Clique no botão Selecionar Contas Orçamentárias para efetuar a filtragem.  Caso existam contas orçamentárias cadastradas por centro de custo, para os mesmos filtros informados acima, o sistema retornará esse conjunto de contas para que sejam cadastradas as reservas, manualmente ou através de rateio.

 

Critério para rateio

Indique um critério para rateio do valor informado no campo Valor total para rateio.

 

Valor total para rateio

Digite um valor para ser rateado igualmente entre todos os registros do "grid", ou através do rateio informado no campo Critério para rateio.

 

 Clique no botão Calcular para que o valor informado seja rateado entre os registros do "grid".

 

Observação 1:  É possível operar essa tela digitando-se valores diretamente no "grid".

Observação 2:  Alterações nessa tela se dão no modo de "Inserção".  

 

 Clique no botão Cancelar Reserva para cancelar reservas efetuadas para um grupo de contas.

 

 Clique no botão Ok para efetivar o cadastramento das reservas efetuadas para um grupo de contas.
