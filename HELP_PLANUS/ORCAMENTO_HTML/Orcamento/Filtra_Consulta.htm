Filtra Consulta

A tela Filtra Consulta permite que o usuário filtre os dados desejados para a impressão do relatório, que tenha sido montado pelo sistema Gerador.

 

Obs.: Nem todos os relatórios nativos do sistema apresentam o filtro de dados. Nos relatórios criados através do sistema Gerador, o usuário poderá definir se o filtro deverá ser habilitado ou não.

 

Para visualizar o relatório, sem optar por nenhum tipo de filtro, clique no botão Ok.

 

Preencha os seguintes campos:

 

Campos Para Pesquisa

Essa caixa de listagem dá condições ao usuário de selecionar o objeto da pesquisa.

Ex.: NUMAGENCIA, NOMEBANCO, CODIGO, etc.

 

Comparadores

Este campo permite que o usuário defina os filtros para a pesquisa. São eles:

 Igual a

 Diferente de

 Menor que

 Menor ou Igual a

 Maior que

 Maior ou Igual a

 Começando com

 

Texto

Digite nesse campo a condição, de acordo com o campo para pesquisa e o comparador que o usuário selecionou.

Ex.: No relatório de agência bancária:

 No Campo Para Pesquisa, selecione “NUMAGENCIA”.

 No campo Comparadores, selecione “Maior que”.

 No campo Texto, digite “200”.

O resultado da pesquisa será, então, todos os números de agência maiores que 200.

 

Junções

Para efetuar mais de uma condição dentro de uma mesma pesquisa, utilize as junções E e OU.

 E – Apenas os registros que satisfazerem as duas condições serão selecionados.

 OU – O sistema disponibilizará os registros que satisfazerem a pelo menos uma das condições estabelecidas.

 

Parênteses

Utilize este campo para definir a prioridade das condições da pesquisa.

 

Sensível a Caixa

Selecione este campo, para o sistema diferenciar os registros digitados com letras maiúsculas, mistas ou minúsculas.

Ex.: Usuários: CM. Se você digitar Cm ou cm, o sistema não encontrará o usuário CM.

 

Gera relatório direto para impressora

Selecione este campo, para imprimir o relatório diretamente na impressora.

 Clique no botão Add, para adicionar as condições de pesquisa que você definiu.

 Utilize o botão Del, para excluir uma condição de pesquisa.

 

Condições para Pesquisa

Esse campo mostra as condições anteriormente definidas, para a filtragem de dados do relatório.

Ex.: (NUMAGENCIA > ‘200’) – Número de agência, no relatório que lista o cadastro de agências bancárias, maior que 200.
