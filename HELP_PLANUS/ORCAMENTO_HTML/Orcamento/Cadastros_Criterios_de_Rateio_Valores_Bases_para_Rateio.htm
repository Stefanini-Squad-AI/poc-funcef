Cadastros - Critérios de Rateio - Valores Base para Rateio

Neste item, indique os valores base para rateio de cada centro de custo.

 

Este subitem só estará disponível para os critérios de rateio, cujo tipo de rateio for digitado manualmente.

 

Preencha os seguintes campos:

 

Critério de Rateio

Clique na seta à direita do campo, para selecionar o critério de rateio, cujas informações serão digitadas. Só estarão disponíveis os critérios de rateio que, no cadastro de Tipo de Critério, tenham sido definidos como Pré-Definido .

 

Exercício Inicial / Final

Selecione os exercícios inicial e final, no qual serão informados os valores base de rateio.

 

Período Inicial / Final

Selecione os períodos inicial e final, no qual serão informados os valores base de rateio.

 

 Clique no botão Inserir para que os centros de custo sejam exibidos no "grid".

 Indique, na coluna Valor Base, o valor/percentual do rateio para aquele centro de custo.

 Repita a operação até concluir o rateio para todos os centros de custos.

 Clique no botão Ok para concluir o cadastramento.
