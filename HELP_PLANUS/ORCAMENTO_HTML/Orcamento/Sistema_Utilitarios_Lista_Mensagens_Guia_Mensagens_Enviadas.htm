Lista Mensagens - Guia Mensagens Enviadas

Nesta guia são mostradas todas as mensagens que foram enviadas pelo usuário logado no sistema.

 

Para ler o conteúdo de uma mensagem enviada, dê um clique sobre a mesma.

 

 Clique nos botões Próximo e Anterior, para navegar pelas mensagens enviadas.

 Para reenviar uma mensagem, clique no botão Encaminhar.

 Clique no botão Atualizar, para atualizar as mensagens enviadas.

 Clique no botão Excluir, para apagar a mensagem selecionada.
