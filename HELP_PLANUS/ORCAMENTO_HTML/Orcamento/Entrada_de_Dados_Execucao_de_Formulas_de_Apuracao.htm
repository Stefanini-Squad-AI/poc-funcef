Entrada de Dados - Execução de Fórmulas de Apuração

Nesse ítem é feita a execução das fórmulas cadastradas em Cadastros - Fórmulas para apurar o Orçamento.  

 

Essa funcionalidade permite a elaboração de um orçamento futuro, baseado em uma experiência passada.  Ex.:  É possível cadastrar o orçado do próximo exercício, baseado no realizado do exercício atual.

 

Informe os seguintes campos:

 

 Origem.

 

Exercício

Indique o exercício de origem dos dados orçados/realizados, a partir do qual a Forma de Operação, definida no cadastro da Fórmula de Apuração, se baseará.  Clique Cadastros - Fórmulas para apurar o Orçamento - Guia Fórmula para entender melhor Forma de Operação.

Atenção:  O exercício indicado aqui não terá nenhuma função para as seguintes Formas de Operação:  Período a Período / Orçado do Mês anterior.

 

Período

Indique o período de origem dos dados orçados/realizados, a partir do qual a Forma de Operação, definida no cadastro da Fórmula de Apuração, se baseará.  Clique Cadastros - Fórmulas para apurar o Orçamento - Guia Fórmula para entender melhor Forma de Operação.

Atenção:  O período indicado aqui não terá nenhuma função para as seguintes Formas de Operação:  Período a Período / Orçado do Mês anterior.

 

 Destino.

 

Exercício

Indique o exercício de destino, para cópia dos dados orçados/realizados do exercício de origem.

 

Período Ini

Indique o período inicial de destino, para cópia dos dados orçados/realizados a partir do período de origem.

 

Período Fim

Indique o período final de destino, para cópia dos dados orçados/realizados a partir do período de origem.

 

Atenção:  Caso os períodos início e fim indicados aqui, estejam incompatíveis com os períodos início e fim indicados no cadastro da fórmula, não haverá geração de orçamento para os períodos não contemplados pela fórmula.

 

 Calcular as Contas - Posição.

Esse componente possibilita especificar uma cadeia de caracteres específica.  Utilizado quando desejamos apurar as fórmulas apenas para um grupo de contas, por exemplo, do centro de custo ADMINISTRAÇÃO, representado pela cadeia de caracteres 02.06.10 e iniciando a partir da quinta posição.  Procederíamos da seguinte forma:

 

 Inicial - Posição, na cadeia de caracteres, onde se inicia o código correspondente ao centro de custo. No nosso exemplo deve ser preenchido com 5, pois o centro de custo começa na quinta posição.

 Dígitos - A partir da quinta posição, indica quantos caracteres queremos considerar para contemplar o centro de custo.  No nosso exemplo deve ser preenchido com 6, pois, 020610 têm 6 caracteres.

 Conteúdo - Aqui especificamos a cadeia de caracteres exata que representa o centro de custo desejado.  No nosso exemplo, 020610.

 

Resumindo, informamos ao sistema que desejamos aplicar a fórmula a todas as contas que, com seis caracteres iniciando na quinta posição, possuem a cadeia de caracteres 020610.

 

Exemplo de contas que "seriam"/ "não seriam" contempladas nesse processamento:

 

010202062001011 - Não seria

010202061001011 - Seria

 

Fórmula

Clique na seta a direita do campo para indicar a fórmula a ser utilizada.

 

 Apenas Simulação

Com essa caixa de verificação marcada, clicando-se no botão Continuar, será exibida uma tela com uma prévia do resultado da geração para simples conferência.  Nenhuma alteração será efetivada na base de dados.

As opções a seguir somente estarão habilitadas caso essa caixa de verificação esteja "desmarcada".

 Exclui orçamento no destino

Caso exista algum orçamento para o período especificado no destino, o mesmo será excluído, apenas isso.  Um novo orçamento "não" será gerado a partir da marcação dessa caixa de verificação.  Essa opção existe para que se possa apagar uma apuração de fórmula ocorrida anteriormente, caso desejado.

 Calcula Novo Orçamento

Essa opção deve ser marcada em conjunto com a anterior, pois, caso a opção anterior esteja desmarcada, o processamento resultará em erro, em função de já existirem dados anteriores para o período especificado.  Essa opção vai, efetivamente, gerar um orçamento a partir da apuração da fórmula.
