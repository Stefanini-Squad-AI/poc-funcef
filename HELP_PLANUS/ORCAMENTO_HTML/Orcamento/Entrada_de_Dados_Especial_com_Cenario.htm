Entrada de Dados - Especial com Cenário

Este item foi desenvolvido especialmente para a Funcef, que não queria utilizar o campo Conta Orçamentária.

 

Eles preferem digitar o grupo, a atividade/projeto, etc., e o sistema identifica quais as contas orçamentárias que existem para este grupo, atividade/projeto, etc.

 

O sistema faz o lançamento em uma só tela, para todos os centros de custo ao mesmo tempo. Internamente, é como se o Planejamento e Orçamento estivesse usando cada conta.
