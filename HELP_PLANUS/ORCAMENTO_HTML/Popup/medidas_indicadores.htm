Medidas/Indicadores

Indique através de quais medidas/indicadores você deseja fazer a análise das dimensões marcadas.

O sistema traz, como padrão, todos os indicadores marcados. Caso não deseje algum deles, desmarque para aumentar a performance do sistema.

 

Para fazer uma nova seleção, clique no botão Filtro e repita todos os processos acima.

 

Você pode ordenar as dimensões para análise a qualquer hora, simplesmente arrastando para à esquerda, a dimensão que deseja tornar prioritária
