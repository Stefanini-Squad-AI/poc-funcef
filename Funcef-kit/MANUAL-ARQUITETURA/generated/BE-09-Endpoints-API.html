BE-09 — Endpoints da API

9.1 Convenções gerais

> Todos os endpoints de domínio exigem JWT Bearer ([FuncefAuthorize]).

> Endpoints de /health/*, /info são públicos.

> Endpoints de /auth/* são auto-registrados pelo FUNCEF.Autenticacao via AddFuncefAuthControllers().

Rotas e verbos HTTP

OperaçãoVerboRota típicaMediatorSucesso
Listar (paginado)GET`/{Entidades}``Receive(Get{Entidade}PagedQuery)`200 `PaginatedResult<{Entidade}Resume>`
Obter por IDGET`/{Entidades}/{id}``Receive(Get{Entidade}ByIdQuery)`200 `{Entidade}Response`
Obter por critérioGET`/{Entidades}/{criterio}/{valor}``Receive(Get{Entidade}By{Criterio}Query)`200
CriarPOST`/{Entidades}``Send(Create{Entidade}Command)`201 `{Entidade}Response`
Atualizar (completo)PUT`/{Entidades}/{id}``Send(Update{Entidade}Command)`200
Atualizar (parcial / campo específico)PATCH`/{Entidades}/{id}/{campo}``Send(Update{Entidade}{Campo}Command)`200
ExcluirDELETE`/{Entidades}/{id}``Send(Delete{Entidade}Command)`204

Controller — padrão

[Route("[controller]")]
[ApiController]
public class {Entidades}Controller : BaseController
{
    private readonly IMediator _mediator;

    public {Entidades}Controller(ITelemetry telemetry, IMediator mediator) : base(telemetry)
        => _mediator = mediator;

    [HttpGet]
    [FuncefAuthorize]
    [ProducesResponseType(typeof(PaginatedResult<{Entidade}Resume>), StatusCodes.Status200OK)]
    public async Task<IActionResult> GetAll(
        [FromQuery] int pagina = 1,
        [FromQuery] int tamanhoPagina = 10,
        [FromQuery] string? termoBusca = null,
        [FromQuery] string? ordenarPor = null,
        [FromQuery] string direcaoOrdenacao = "asc",
        CancellationToken ct = default)
    {
        var result = await _mediator.Receive(new Get{Entidade}PagedQuery
        {
            Pagina = pagina, TamanhoPagina = tamanhoPagina,
            TermoBusca = termoBusca,
            OrdenarPor = ordenarPor, DirecaoOrdenacao = direcaoOrdenacao
        }, ct);
        return ApiOk(result);
    }

    [HttpGet("{id:long}")]
    [FuncefAuthorize]
    [ProducesResponseType(typeof({Entidade}Response), StatusCodes.Status200OK)]
    [ProducesResponseType(StatusCodes.Status404NotFound)]
    public async Task<IActionResult> Get(long id, CancellationToken ct = default)
    {
        var result = await _mediator.Receive(new Get{Entidade}ByIdQuery { Id = id }, ct);
        return ApiOk(result);
    }

    [HttpPost]
    [FuncefAuthorize]
    [ProducesResponseType(typeof({Entidade}Response), StatusCodes.Status201Created)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status409Conflict)]
    public async Task<IActionResult> Create(
        [FromBody] {Entidade}Request request, CancellationToken ct = default)
    {
        var result = await _mediator.Send(new Create{Entidade}Command { Request = request }, ct);
        return ApiCreated(result);
    }

    [HttpPut("{id:long}")]
    [FuncefAuthorize]
    public async Task<IActionResult> Update(
        long id, [FromBody] {Entidade}Request request, CancellationToken ct = default)
    {
        var result = await _mediator.Send(
            new Update{Entidade}Command { Id = id, Request = request }, ct);
        return ApiOk(result);
    }

    [HttpDelete("{id:long}")]
    [FuncefAuthorize]
    [ProducesResponseType(StatusCodes.Status204NoContent)]
    [ProducesResponseType(StatusCodes.Status404NotFound)]
    public async Task<IActionResult> Delete(long id, CancellationToken ct = default)
    {
        await _mediator.Send(new Delete{Entidade}Command { Id = id }, ct);
        return ApiNoContent();
    }
}
```

Helpers de BaseController retornam ObjectResults padronizados:

MétodoHTTPUso
`ApiOk(result)`200Leitura ou update bem-sucedido
`ApiCreated(result)`201Recurso criado
`ApiNoContent()`204Operação sem corpo (delete típico)

9.2 Query parameters padronizados

Listagem paginada

ParâmetroTipoDefaultDescrição
`pagina`int`1`Página atual (>= 1)
`tamanhoPagina`int`10`Tamanho da página
`termoBusca`string?`null`Busca textual (case-insensitive, contém)
`ordenarPor`string?(depende do recurso)Campo de ordenação

Filtros adicionais (status, datas, FK) variam por recurso. Validar valores permitidos via RuleForRequiredAllowedValues/RuleForSortField no Validator da Query (quando criado).

Inclusão de navegação

ParâmetroTipoDefaultDescrição
`incluir{Navegacao}`bool`false`Quando `true`, usa `GetByIdWithAutoIncludesAsync` para carregar navegação marcada com `[AutoInclude]`
```

```
9.4 Códigos de status HTTP — padronização

CódigoSignificadoQuando ocorreExceção/origem
200OKGET com sucesso · PUT/PATCH retornando recurso atualizado`ApiOk(result)`
201CreatedPOST que cria recurso (resposta inclui o recurso)`ApiCreated(result)`
204No ContentDELETE com sucesso`ApiNoContent()`
400Bad RequestValidação falhou; body malformado`ValidationException`
400Bad RequestRegra de negócio violada`BusinessException` (de `FUNCEF.Essenciais`)
401UnauthorizedToken ausente/inválidoPipeline `UseAuthentication`
403ForbiddenToken válido mas sem permissão`UseAuthorization` + `[FuncefAuthorize]`
404Not FoundRecurso inexistente`NotFoundException`
409ConflictUnicidade ou estado conflitante`ConflictException` (de `FUNCEF.Essenciais`, herda `BusinessException`; mapeada a 409 nativamente)
429Too Many RequestsRate limit estourado`UseRateLimiting` (`FUNCEF.Essenciais`)
500Internal Server ErrorFalha inesperada (mascarada)`GlobalExceptionMiddleware`

> ✅ FUNCEF.Essenciais expõe BusinessException (→ 400), NotFoundException, ValidationException e ConflictException (→ 409, herda BusinessException e é mapeada nativamente pelo GlobalExceptionMiddleware — sem classe local nem CustomExceptionMappings). Detalhes em BE-06-Validacao-Excecoes §6.8.

9.5 Convenção JSON

Configurada em Program.cs:

builder.Services.AddControllers()
    .AddJsonOptions(options =>
    {
        options.JsonSerializerOptions.PropertyNamingPolicy = JsonNamingPolicy.CamelCase;
        options.JsonSerializerOptions.DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull;
        options.JsonSerializerOptions.Converters.Add(new JsonStringEnumConverter());
    });
```
ComportamentoEfeito
`PropertyNamingPolicy = CamelCase`Propriedades em camelCase no JSON, PascalCase no C#
`DefaultIgnoreCondition = WhenWritingNull`Propriedades null **omitidas** da resposta
`JsonStringEnumConverter`Enums serializados como string (`"Pendente"`, não `0`)

Não usar [JsonPropertyName] campo a campo — configuração global cobre. Decisão registrada em Decisoes-Arquiteturais ADR-016.

9.8 Versionamento de API

> O padrão FUNCEF não implementa versionamento preventivo (/v1/...). A rota usa [Route("[controller]")] direto. A primeira versão não leva prefixo.

Quando versionar (critérios do Decisoes-Arquiteturais ADR-017):

  • Breaking change em contrato público consumido por cliente externo/terceiro que não pode ser migrado simultaneamente.
  • Mudanças internas (mesmo time, mesmo deploy) → deprecar endpoint antigo e migrar; não versionar.

Como versionar (quando inevitável):

CenárioMecanismoExemplo
API pública/externaPath`[Route("v2/[controller]")]` + `Microsoft.AspNetCore.Mvc.Versioning`
API interna (raro)Header`X-API-Version: 2`

Registrar ADR de serviço justificando a necessidade e documentar no README.

9.9 Exemplos curl

# Autenticar (interativo no browser primeiro; aqui assume Bearer já obtido)
TOKEN="eyJ0eXAiOiJKV1Qi..."
BASE="https://localhost:{PORTA}"

# Listar com paginação
curl -k -H "Authorization: Bearer $TOKEN" \
  "$BASE/{Entidades}?pagina=1&tamanhoPagina=10&termoBusca=joao&ordenarPor=Nome&direcaoOrdenacao=asc"

# Obter por ID com inclusão de navegação
curl -k -H "Authorization: Bearer $TOKEN" \
  "$BASE/{Entidades}/11111111-1111-1111-1111-111111111111?incluir{Navegacao}=true"

# Criar
curl -k -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"nome":"Exemplo","email":"exemplo@dominio.com.br"}' \
  "$BASE/{Entidades}"

# Atualizar
curl -k -X PUT -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"nome":"Exemplo Atualizado","email":"exemplo@dominio.com.br"}' \
  "$BASE/{Entidades}/11111111-1111-1111-1111-111111111111"

# Excluir
curl -k -X DELETE -H "Authorization: Bearer $TOKEN" \
  "$BASE/{Entidades}/11111111-1111-1111-1111-111111111111"

# Health
curl -k "$BASE/health/live"
curl -k "$BASE/health/ready"
curl -k "$BASE/health/version"

9.11 Documentação Swagger

AddSwaggerDocumentation (FuncefEssenciais) gera Swagger UI a partir dos:

  • [ProducesResponseType(typeof(...), StatusCodes.Status...)] no controller.
  • XML doc comments quando IncludeXmlComments = true e true no .csproj.
  • AddSwaggerBearerAuthentication adiciona campo de Bearer token na UI.

Recomendação: anotar todos os endpoints com ProducesResponseType para os status codes esperados — facilita consumo por clientes e geração de SDK.

9.12 Anti-padrões

Anti-padrãoPor quê é proibidoCorreção
`return BadRequest("erro")`Bypassa middlewareLançar `ValidationException`
`return NotFound()` no controllerLógica fora do HandlerLançar `NotFoundException.ForResource(...)`
Controller "fat" (regra de negócio)Quebra Clean ArchitectureMover para Service via Handler
Rota com verbos (`POST /CreateCliente`)Não-RESTUsar `[HttpPost] /{Entidades}`
`[JsonPropertyName]` em todos os camposRedundanteConfig global de CamelCase cobre
Sem `[ProducesResponseType]`Swagger pobreAnotar pelo menos sucessos + 400/404/409 quando aplicável
Versionamento `v1` "preventivo"Complexidade desnecessáriaImplementar só quando precisar
