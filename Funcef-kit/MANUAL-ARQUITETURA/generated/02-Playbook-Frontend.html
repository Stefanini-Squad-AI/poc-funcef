02 — Playbook Frontend

Importante **Precedência**

Em qualquer dúvida de FE, o repositório **`funcef/web-template`** vence (código + `ARCHITECTURE.md` + `README.md`).

[!CAUTION]

**Sem segredos**

`.env.local` nunca vai para o Git nem para este pacote. Aqui só aparecem **nomes de variáveis** e placeholders.

2. Quatro camadas

app/        → orquestração de rotas (o que mostrar)
features/   → domínio (como funciona)
core/       → api, auth, providers, config
shared/     → UI genérica, utils, env, query-keys
```

Import **one-way**: `app` → `features` → `core` → `shared`.

**Features nunca importam outras features** — promover para `shared/` ou `core/`.

Enforced por `eslint-plugin-boundaries` — não suprimir.

CertoErrado
`import { api } from '@/core/api'``import axios from 'axios'`
`import { useAllTasks } from '@/features/tasks'``import { x } from '@/features/other'`
página importa barrel da featurecomponente chama `api.get` direto

3. Contrato de feature

features/<domínio>/
├── api/
│   ├── endpoints.ts   # URLs puras — sem HTTP
│   ├── client.ts      # api.get/post via @/core/api
│   └── index.ts
├── hooks/             # React Query
├── components/
├── types.ts
├── validators.ts      # Zod (se houver form)
└── index.ts           # barrel público
```

Fluxo: `components → hooks → api/{endpoints,client} → types/validators`.

**Não existe `service.ts`.**

3.1 Exemplo vivo — `tasks` (template)

**endpoints.ts**

export const endpoints = {
  list: () => '/tasks',
  create: () => '/tasks',
};
```

**client.ts**

import { api } from '@/core/api';
import { endpoints } from './endpoints';
import type { CreateTaskData, Task } from '../types';

export const tasksApi = {
  getAll: () => api.get<Task[]>(endpoints.list()),
  create: (data: CreateTaskData) =>
    api.post<Task, CreateTaskData>(endpoints.create(), data),
};
```

**Hook query**

export function useAllTasks() {
  const query = useQuery({
    queryKey: queryKeys.tasks.list(),
    queryFn: () => tasksApi.getAll(),
  });
  return {
    tasks: query.data?.data ?? null, // envelope normalizado pela lib
    isTasksLoading: query.isLoading,
    error: query.error,
  };
}
```

**Hook mutation**

export function useCreateTask() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (data: CreateTaskData) => tasksApi.create(data),
    onSuccess: () =>
      queryClient.invalidateQueries({ queryKey: queryKeys.tasks.all }),
    meta: { globalErrorToast: true },
  });
}
```

**Query keys** — sempre em `src/shared/lib/query-keys.ts`:

export const queryKeys = {
  tasks: {
    all: ['tasks'] as const,
    list: () => [...queryKeys.tasks.all, 'list'] as const,
    detail: (id: string | number) =>
      [...queryKeys.tasks.all, 'detail', id] as const,
  },
} as const;
```

**Naming:** `useAllTasks` / `useTaskById` / `useCreateTask` — nunca `useGet*`.

**Validators (PT):**

export const createTaskSchema = z.object({
  title: z.string().trim().min(3, 'Informe um título com ao menos 3 caracteres'),
});
```

4. BFF e `api`

// src/core/api.ts (conceito — ver arquivo no template)
export const api = createApi({
  baseURL: `${envClient.APP_URL}${envClient.BASE_PATH}/api/bff`,
});
```
  • Browser → `/api/bff/*` only.
  • Route handler `createBffHandler` anexa Bearer no **servidor**.
  • Não reimplementar parsing do envelope `{ resultado, mensagem, qtdRegistros }`.
  • `401` → teardown de sessão (lib) — não tratar auth expiry ad hoc na feature.

5. Auth e rotas

CenárioLoginSessão
**2 — Full BA** (default do template)Entra local `/api/auth`cookie better-auth
**1 — Consumidor TKF2**Portal externocookie TKF2 (conversão via CLI do ecossistema)
  • Guard de cookie: `src/proxy.ts` (`createSessionProxy`) — **não** é boundary de segurança.
  • Layout autenticado: `getServerSession()`; sem sessão → sign-in.
  • Shell: `AppShell` da lib auth.
  • Next.js 16 neste template: **`proxy.ts`**, não `middleware.ts`.

6. UI e idioma

  • Preferir `@funcef-componentes/react` **v3**: prop **`render`** (não `asChild`), `data-state`, `LoadingFuncef`.
  • **Código EN** (arquivos, rotas, identificadores); **UI PT** (labels, toasts, Zod).
  • Env: só via `src/shared/config/env.ts` e `env-client.ts` (exceção: `process.env.NODE_ENV`).
  • Duas mocks: **dev** = `pnpm mock`; **testes** = MSW — nunca misturar.

7. Página e rota

  • Página em `app/(authenticated)/...` **orquestra** (smart): chama hooks, passa props.
  • Componentes da feature são apresentacionais.
  • Exemplo: rota `/tasks` + `features/tasks`.
  • Sem páginas stub — rota sem UI → `not-found`.

8. Testes

  • Vitest + Testing Library + MSW (`src/__tests__/msw/`).
  • Hook tests: `renderHookWithProviders` (padrão do template).
  • Sem rede real; sem Jest.

9. Checklist — primeira feature de domínio

  • [ ] Pasta `features//` no contrato completo
  • [ ] `queryKeys` registrados
