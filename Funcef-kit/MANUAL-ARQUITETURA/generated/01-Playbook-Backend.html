01 — Playbook Backend

Nota **Objetivo**

Deixar o time BE apto a criar um microserviço a partir de `funcef/api-template-base` e adicionar um recurso de domínio no padrão FUNCEF.

[!CAUTION]

**Sem segredos**

Não cole connection strings, URLs reais de Key Vault, Client Secrets ou Tenant IDs neste material de trabalho compartilhado. Use placeholders; valores vêm do kickoff.

4. Padrão de código — nova entidade (exemplo Produto)

Substitua `Produto` / `{SCHEMA}` / `{Servico}` pelos nomes reais. Trechos alinhados ao guia interno *Adicionando Nova Entidade*.

4.1 Domain

[Table("TB_PRODUTOS", Schema = "{SCHEMA}")]
[Auditable("Produto")]
public class Produto
{
    [Key]
    [Column("PRODUTO_ID")]
    [DatabaseGenerated(DatabaseGeneratedOption.Identity)]
    public long Id { get; set; }

    [Required, Column("NOME"), MaxLength(200)]
    public string Nome { get; set; } = string.Empty;

    [Required, Column("FLAG_ATIVO", TypeName = "NUMBER(1)")]
    public bool Ativo { get; set; } = true;

    [Required, Column("DATA_CRIACAO")]
    public DateTime DataCriacao { get; set; } = DateTime.UtcNow;
}
```

Regras: PK `long` IDENTITY · coluna `{ENTIDADE}_ID` · tabela `TB_` + plural · boolean `NUMBER(1)` · sem `BaseEntity`.

Registrar `DbSet` em `AppDbContext`.

4.2 DTOs + mapeamento

public class ProdutoRequest
{
    public string Nome { get; set; } = string.Empty;
    public bool Ativo { get; set; } = true;
}

public class ProdutoResponse
{
    [MapFrom("Id")] public long Id { get; set; }
    [MapFrom("Nome")] public string Nome { get; set; } = string.Empty;
    [MapFrom("Ativo")] public bool Ativo { get; set; }
}
```

Usar `[MapFrom]` / `MapTo<>` — **não** AutoMapper.

4.3 Service (regra + dados; sem SaveChanges)

public async Task<Produto> CreateAsync(ProdutoRequest request, CancellationToken ct = default)
{
    if (await _repository.ExistsAsync(p => p.Nome == request.Nome, cancellationToken: ct))
        throw new ConflictException("Produto", "Já existe um produto com este nome");

    var entity = request.MapTo<ProdutoRequest, Produto>(p =>
    {
        p.DataCriacao = DateTime.UtcNow;
    });

    await _repository.AddAsync(entity, ct);
    return entity;
}
```

4.4 Command + Validator + Handler

public class CreateProdutoCommand : ICommand<ProdutoResponse>
{
    public ProdutoRequest Request { get; set; } = new();
}

public class CreateProdutoValidator : AbstractValidator<CreateProdutoCommand>
{
    public CreateProdutoValidator()
    {
        this.RuleForRequiredText(x => x.Request.Nome, "nome", 200);
    }
}

public class CreateProdutoHandler : ICommandHandler<CreateProdutoCommand, ProdutoResponse>
{
    private readonly IProdutoService _service;
    private readonly IUnitOfWork _unitOfWork;

    public async Task<ProdutoResponse> Handle(CreateProdutoCommand command, CancellationToken ct)
    {
        var produto = await _service.CreateAsync(command.Request, ct);
        await _unitOfWork.SaveChangesAsync(ct);
        return produto.MapTo<Produto, ProdutoResponse>();
    }
}
```
  • Validators no **Command**, não no controller.
  • Handler controla transação (`SaveChangesAsync`).
  • Sem `try/catch` defensivo — exceções tipadas sobem ao middleware.

4.5 Query (leitura)

public class GetProdutoByIdQuery : IQuery<ProdutoResponse>

    public long Id { get; set; }

```
4.6 Controller fino

[ApiController]
[Route("api/v1/produtos")]
[FuncefAuthorize]
public class ProdutosController : BaseController
{
    private readonly IMediator _mediator;

    [HttpPost]
    public Task<IActionResult> Create([FromBody] ProdutoRequest request, CancellationToken ct)
        => ApiCreated(_mediator.Send(new CreateProdutoCommand { Request = request }, ct));

    [HttpGet("{id:long}")]
    public Task<IActionResult> GetById(long id, CancellationToken ct)
        => ApiOk(_mediator.Receive(new GetProdutoByIdQuery { Id = id }, ct));
}
```

Registrar `IProdutoService` em `AddApplicationServices`. Envelope de resposta segue o padrão do template (`ApiOk` / `ApiCreated`).

5. Catálogo `FUNCEF.*` (quando usar)

Pin: `[3.0.0,4.0.0)` no feed do kickoff.

Quero…LibExtensão típica
Mediator, BaseController, exceções, validação`FUNCEF.Essenciais``AddMediatorWithDefaults`
EF + Dapper, `IRepository`, `IUnitOfWork`, `[MapFrom]``FUNCEF.ORM` (+ `.Dapper`, `.Audit`)`AddFuncefORM*`
Entra + `[FuncefAuthorize]` / GAP`FUNCEF.Autenticacao``AddFUNCEFAuthentication`
Redis / Mongo`FUNCEF.NoSql``AddRedisCache` / `AddMongoDocuments`
Key Vault`FUNCEF.Cofre``AddVaultComplete`
Blob/Queue/Service Bus`FUNCEF.Armazenamentos``AddStorageServices`
Contratos (`ITelemetry`, paginação)`FUNCEF.Abstractions`—
Analisadores de build`FUNCEF.Build``PrivateAssets=all`

**Não usar** (sem ADR): MediatR nuget, AutoMapper, Serilog standalone, Polly direto na Application, Newtonsoft.Json, `ILogger` no lugar de `ITelemetry`.

6. Segurança na API

  • Endpoints de domínio: `[FuncefAuthorize]` (e `Acao = "..."` quando o produto usar GAP).
  • Não reimplementar JWT/login — usar stack `FUNCEF.Autenticacao`.
  • Health/version públicos conforme template.
  • Ordem de middleware: seguir o `Program.cs` do template (não inventar pipeline).

7. Testes

  • MSTest + NSubstitute (+ EF InMemory quando fizer sentido).
  • Cobrir Validators e Handlers do novo recurso.
  • `dotnet test` deve passar no CI do fornecedor / PR.

8. Checklist — primeiro endpoint de domínio

  • [ ] Solution renomeada; `dotnet build` OK
  • [ ] Schema `` aplicado nas entidades novas
  • [ ] Entity + DbSet + DTOs + Service + Command/Query + Handler + Validator + Controller
  • [ ] `[FuncefAuthorize]` no controller
  • [ ] Tabela criada via Liquibase (playbook Dados)
  • [ ] Testes do Create/Get verdes
  • [ ] Smoke autenticado acordado no kickoff (sem colar tokens em issues/PRs)
  • [ ] Nenhum secret no repositório
