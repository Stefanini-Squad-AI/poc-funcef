Relação com o Web Empréstimo

  • As duas aplicações tratam do mesmo negócio e usam o mesmo banco Oracle (schema CM). O Web Empréstimo lê e grava tabelas que o EMPRESTIMO Delphi 5 também usa, como CONTRATOEMPTMO, HISTMOVEMPTMO e PARAMEMPTMO, e chama a package CM.PCK_EMPRESTIMO (listada também na página do módulo Delphi).
  • Não há referência de código entre elas: o Web Empréstimo não usa units nem BPLs Delphi, e o Delphi 5 não chama os serviços WCF do Web Empréstimo. A integração é pelo banco.
  • Consequência para versões: a atualização do .NET Framework do Web Empréstimo não exige mudança no Delphi 5, e vice-versa. O que afeta as duas é mudança de estrutura no Oracle (tabelas, procedures, packages) e a versão do servidor Oracle, que precisa continuar compatível com o cliente nativo usado pelo BDE e com o Oracle.ManagedDataAccess 21.x do Web.

O que mudou na atualização 4.6 → 4.8 (Web Empréstimo)

  • <TargetFrameworkVersion> mudou de v4.6 para v4.8 nos projetos da solução.

  • Acesso a dados migrado de Oracle.DataAccess (ODP.NET não gerenciado) para Oracle.ManagedDataAccess (pacote 21.13.0, assembly 4.122.x), com binding redirects.
  • Handler WCF (*.svc) declarado para o pipeline Integrado do IIS (Web.config, linha 124).
  • Executáveis de utilidade: app.config com <supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8"/>.

🧩 Análise de Migração Funcional — Delphi 5 × .NET 4.8
Estratégia do projeto (regra governante): o FUNCEF.WebEmprestimo em .NET Framework 4.8 é a base da nova aplicação. Tudo o que já está implementado nele é aproveitado e apenas modernizado para .NET 10 + React 19. Somente as funcionalidades do módulo Delphi EMPRESTIMO sem implementação equivalente comprovada no .NET 4.8 entram na migração funcional a partir do Delphi. O esforço de modernização do WebEmprestimo e o esforço de migração de funcionalidades exclusivas do Delphi são contados separadamente e não se misturam.

Card: PFC-15. O enunciado cita Funcef/EMPRESTIMO; no repositório a pasta Delphi é EMPRESTIMO/ (a pasta FUNCEF/ é outra aplicação Delphi e não faz parte desta análise). Caminhos Delphi abaixo são relativos à raiz do repositório; caminhos .NET são relativos a FUNCEF.WebEmprestimo/.

Dependências seguidas fora de EMPRESTIMO/

  • EMPRESTIMOBPL/ (208 arquivos; 88 .pas, 78 .dfm): grande parte das regras de negócio do executável está nos pacotes CMObjetosEP50, CMIntegraEP50 e CMExecEP50 compilados a partir dessa pasta e carregados em runtime (UsePackages=1). As units centrais — EMPRESTIMOBPL/Integra/Source/UCalcEmptmo.pas, EMPRESTIMOBPL/Integra/Source/UIntegraEmptmo.pas, EMPRESTIMOBPL/Integra/Source/UIntegraReceb.pas, EMPRESTIMOBPL/Integra/Source/dAtualizacaoDiaria.pas, EMPRESTIMOBPL/Integra/Source/DDividaEP.pas, EMPRESTIMOBPL/Objetos/Source/uObjetoVerba.pas — e telas como FExecQuitacao, FExecAmortizacao, FCadInscricao e FCadBenefSeguro (EMPRESTIMOBPL/Interface/Source/) foram lidas como dependência. Quando a mesma unit existe nas duas pastas, a versão do BPL é a que vale em runtime (ver pendência P6).
  • Framework comum CM (CM/Forms/Source): forms-base, molduras e utilitários. Sem regra de negócio do Empréstimo; não foram analisados em profundidade.
