O que mudou na atualização 4.6 → 4.8 (Web Empréstimo)

  • <TargetFrameworkVersion> mudou de v4.6 para v4.8 nos projetos da solução.
  • Web.config ativo: <httpRuntime targetFramework="4.8"> e <compilation targetFramework="4.8"> (linhas 39 e 41). O ServicosWeb/Web.config também usa 4.8 (linhas 135 e 144).
  • Acesso a dados migrado de Oracle.DataAccess (ODP.NET não gerenciado) para Oracle.ManagedDataAccess (pacote 21.13.0, assembly 4.122.x), com binding redirects.
  • Handler WCF (*.svc) declarado para o pipeline Integrado do IIS (Web.config, linha 124).
  • Executáveis de utilidade: app.config com <supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8"/>.
A próxima atualização do Web Empréstimo (de 4.8 para outra versão) ainda não está definida. Pelo Roadmap de Migração, a stack de destino da FUNCEF é .NET 10 + React 19. Levar Web Forms e WCF para .NET 10 exige reescrever a aplicação, não só trocar a versão. Ver Pendências.

🔍 Como Verificar este Inventário

Para conferir se o documento continua correto, rode na raiz do repositório (Git Bash / Linux). O total precisa bater com a seção Resumo. Projetos com TF=[] herdam a versão do Directory.Build.props da pasta do template.

find . \( -name "*.csproj" -o -name "*.vbproj" -o -name "*.fsproj" \) | sort | while read f; do
  tf=$(grep -oE '<(TargetFrameworkVersion|TargetFrameworks?)>[^<]*' "$f" | sed 's/.*>//' | tr '\n' ' ')
  echo "$f | TF=[$tf]"
done
find . -name "*.csproj" | wc -l                     # esperado: 35
find . \( -name Directory.Build.props -o -name global.json \) -not -path "*/node_modules/*"

Ao criar, remover ou atualizar um projeto .NET, atualize este documento no mesmo PR.
