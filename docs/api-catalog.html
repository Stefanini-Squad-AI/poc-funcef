Catálogo de APIs

Não há API HTTP/REST explícita; a exposição funcional observada é via COM/DCOM AppServer e rotinas remotas de negócio.

As operações remotas centralizam persistência, importação, processamento, encerramento e geração de arquivos regulatórios. Para a migração, essas operações são os candidatos diretos a serviços C#.

Leitura funcional

  • API necessária: operações de gravação, importação e encerramento.
  • API provavelmente necessária: consultas de apoio para telas, relatórios e validação.
  • API dependente de decisão arquitetural: geração de arquivos legados e integração com componentes externos.
