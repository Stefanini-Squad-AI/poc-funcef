🏗️ Arquitetura de Alto Nível

Stack Tecnológica

  • Frontend/Interface: VCL Forms (Delphi 5), padrão Mestre-Detalhe MT
  • Lógica de Negócio: CtrlObjects (controllers) + Units Pascal
  • Acesso a Dados: DbObjects (TCmDbObject) + DataModules + MIDAS remoto
  • Banco de Dados: Oracle (compartilhado entre módulos)
  • Framework: pasta CM/ (forms base, autorização, report manager)

Padrões Arquiteturais Identificados

  • Separação Form / CtrlObject / DbObject (evidência em CONTAB e CMCONTABOBJ50)
  • Forms herdam de FCadastroMT, FCMPrincipal (framework CM)
  • Pacotes BPL de negócio (CMCONTABOBJ50, etc.)
  • Acesso remoto via Sistema.AppRemoteServer (MIDAS)
  • Relatórios ReportBuilder com pipelines BDE

Diagrama de Arquitetura

flowchart LR Usuario["Usuário"] VCL["Interface VCL\n(Forms Delphi 5)"] CTRL["CtrlObjects\n(Lógica de Negócio)"] DBOBJ["DbObjects\n(TCmDbObject)"] MIDAS["AppServer MIDAS"] BD["Banco Oracle"] Usuario --> VCL VCL --> CTRL CTRL --> DBOBJ CTRL --> MIDAS DBOBJ --> MIDAS MIDAS --> BD

Fluxo textual: Usuário → Forms VCL → CtrlObjects → DbObjects/MIDAS → Banco Oracle.

Contabilidade

ID: contab | Confiança: Alta

Propósito: Gestão contábil completa: plano de contas, períodos, planilhas, lançamentos, saldos, demonstrativos, rateios, segregação por plano/patrocinadora, encerramentos e exportações regulatórias (SIPC-CAP/SICADI).

Responsabilidades:

  • Cadastro de plano de contas, históricos, subcontas e parâmetros contábeis
  • Lançamentos manuais e automáticos via planilhas
  • Atualização de saldos analíticos e sintéticos
  • Encerramento de período, contas de resultado e exercício
  • Demonstrativos, balancetes, diário, razão e balanço
  • Importações (Excel, SAF, Fidélio, Folha RM/Dinâmica/SRH) e exportações (SPC/SIPC-CAP, Posadas)
  • Rateios (atividade/projeto, programa, administrativo, plano/patrocinadora) e segregação de recursos
