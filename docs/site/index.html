Banco de Dados

O núcleo contábil utiliza Oracle e acesso legado via BDE, com persistência concentrada em tabelas como PLANOCONTA, LANCAMENTO, PLANOSALDO e PARAMCONTAB.

Há evidência de conexão BaseDados, uso de TDatabase/TSession no servidor remoto e rastros de sqlnet.log com SID ORCL.

Catálogo de Regras de Negócio

As regras críticas cobrem bloqueio de períodos, validação de contas, importação, encerramento, segregação e permissões de relatórios.

Guia para User Stories

Estrutura sugerida

Como perfil, quero objetivo, para benefício.

  • Identificar o perfil real na interface ou na regra.
  • Preservar validações, mensagens e efeitos em banco.
  • Registrar dependências externas e transversais.
