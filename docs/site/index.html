📝 Guia para User Stories
  • Operador / Contador — lançamentos, consultas, importações
  • Supervisor — encerramentos, segregação, consistência
  • Administrador — parâmetros, dias bloqueados, de-para
  • Consultor — relatórios (somente leitura quando aplicável)
